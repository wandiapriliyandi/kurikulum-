Kelas 12

Fase F (Kelas 11–12)

Semester 1

CP

Label: Fase F (Kelas 11–12)

Fase F (kelas 11–12): peserta didik menguasai algoritma dan pemrograman tingkat lanjut (fungsi, struktur data, pemrograman berorientasi objek pengantar), merancang dan mengelola basis data dengan SQL, serta merencanakan, membangun, menguji, mendokumentasikan, dan mempresentasikan proyek perangkat lunak dan proyek informatika terapan bagi masalah nyata di lingkungannya — sebagai bekal studi lanjut dan karier di bidang informatika.

TP

  • TP-1 · Pertemuan 1–18: Peserta didik mampu memahami wawasan arsitektur sistem modern (komputasi terdistribusi, web, mobile) serta menganalisis kebutuhan sistem digital untuk memecahkan masalah nyata di lingkungan pesantren atau sekolah.
  • TP-2 · Pertemuan 3–18: Peserta didik mampu merancang antarmuka dan pengalaman pengguna (UI/UX) berbasis kemudahan pakai (usability) serta membuat kerangka desain (wireframing dan prototyping) menggunakan alat bantu digital.
  • TP-3 · Pertemuan 5–18: Peserta didik mampu memahami wawasan pengembangan web (peran HTML, CSS, JavaScript) dan backend/API (komunikasi antarsistem) secara konseptual dalam ekosistem aplikasi modern.
  • TP-4 · Pertemuan 7–18: Peserta didik mampu memahami konsep pengujian perangkat lunak (black-box testing dan User Acceptance Testing/UAT) serta menyusun dokumentasi teknis dan buku petunjuk pengguna (user manual) yang komunikatif.
  • TP-5 · Pertemuan 9–18: Peserta didik mampu memahami konsep keamanan siber lanjutan (Zero Trust, manajemen kerentanan, kriptografi kunci publik) dan infrastruktur komputasi awan modern (virtualisasi, kontainer Docker pengantar, skalabilitas).
  • TP-6 · Pertemuan 11–18: Peserta didik mampu memahami perkembangan sains data dan kecerdasan artifisial modern (Big Data, jaringan saraf tiruan, Large Language Models/LLM) beserta tata kelola TI dan etika profesional (HAKI, lisensi perangkat lunak, audit sistem).
  • TP-7 · Pertemuan 13–18: Peserta didik mampu memetakan peluang karier dan studi lanjut bidang informatika, menyusun portofolio digital profil keahlian santri, serta mempresentasikan peta jalan pemanfaatan teknologi untuk kemaslahatan umat.

ATP

  • TP-1: Peserta didik mampu memahami wawasan arsitektur sistem modern (komputasi terdistribusi, web, mobile) serta menganalisis kebutuhan sistem digital untuk memecahkan masalah nyata di lingkungan pesantren atau sekolah.
  • TP-2: Peserta didik mampu merancang antarmuka dan pengalaman pengguna (UI/UX) berbasis kemudahan pakai (usability) serta membuat kerangka desain (wireframing dan prototyping) menggunakan alat bantu digital.
  • TP-3: Peserta didik mampu memahami wawasan pengembangan web (peran HTML, CSS, JavaScript) dan backend/API (komunikasi antarsistem) secara konseptual dalam ekosistem aplikasi modern.
  • TP-4: Peserta didik mampu memahami konsep pengujian perangkat lunak (black-box testing dan User Acceptance Testing/UAT) serta menyusun dokumentasi teknis dan buku petunjuk pengguna (user manual) yang komunikatif.
  • TP-5: Peserta didik mampu memahami konsep keamanan siber lanjutan (Zero Trust, manajemen kerentanan, kriptografi kunci publik) dan infrastruktur komputasi awan modern (virtualisasi, kontainer Docker pengantar, skalabilitas).
  • TP-6: Peserta didik mampu memahami perkembangan sains data dan kecerdasan artifisial modern (Big Data, jaringan saraf tiruan, Large Language Models/LLM) beserta tata kelola TI dan etika profesional (HAKI, lisensi perangkat lunak, audit sistem).
  • TP-7: Peserta didik mampu memetakan peluang karier dan studi lanjut bidang informatika, menyusun portofolio digital profil keahlian santri, serta mempresentasikan peta jalan pemanfaatan teknologi untuk kemaslahatan umat.
PertemuanTPMateriIndikator
P1TP-1Wawasan Arsitektur Sistem Modern: Konsep komputasi terdistribusi, arsitektur web modern (client-server), dan aplikasi bergerak (mobile) serta interaksi komponen-komponennya.Menjelaskan konsep dasar sistem terdistribusi dan model client-server; membedakan karakteristik arsitektur aplikasi web dan aplikasi mobile
P2TP-1Analisis Kebutuhan Sistem: Identifikasi masalah digital nyata di lingkungan pesantren/sekolah, perumusan kebutuhan fungsional dan non-fungsional, serta penentuan solusi perangkat lunak yang relevan.Mengidentifikasi permasalahan alur kerja atau kebutuhan digital di lingkungan pesantren/sekolah; merumuskan daftar kebutuhan fungsional sederhana untuk usulan solusi sistem
P3TP-2Perancangan Antarmuka Pengguna (UI/UX Design): Prinsip kemudahan pakai (usability), hierarki visual, tata letak antarmuka, konsistensi elemen visual, dan aksesibilitas bagi pengguna.Menjelaskan perbedaan peran UI dan UX serta prinsip utama usability; menganalisis tata letak antarmuka aplikasi berdasarkan kemudahan navigasi pengguna
P4TP-2Pembuatan Kerangka Desain (Wireframing & Prototyping) Menggunakan Alat Digital: Konsep wireframe low-fidelity hingga prototipe interaktif sederhana menggunakan perangkat lunak desain digital.Merancang sketsa kerangka antarmuka (wireframe) halaman aplikasi sederhana; membuat simulasi alur prototipe interaktif dasar antarmuka pengguna
P5TP-3Wawasan Pengembangan Web Sederhana: Peran dan integrasi teknologi pembangun web meliputi HTML untuk struktur konten, CSS untuk tata gaya/tampilan, dan JavaScript untuk interaktivitas dasar.Membedakan peran fungsi HTML, CSS, dan JavaScript dalam halaman web modern; menjelaskan keterkaitan struktur dokumen, gaya visual, dan perilaku interaktif
P6TP-3Wawasan Pengembangan Backend dan API (Application Programming Interface): Konsep server-side logic, fungsi Application Programming Interface (API) sebagai jembatan komunikasi data antar-aplikasi, dan format pertukaran data umum (JSON).Menjelaskan fungsi sisi server (backend) dalam memproses logika bisnis dan data; menguraikan mekanisme kerja API sebagai perantara komunikasi antar-sistem
P7TP-4Pengujian Perangkat Lunak (Software Testing): Prinsip penjaminan mutu perangkat lunak, pelaksanaan pengujian fungsional (black-box testing berbasis skenario input-output), dan User Acceptance Testing (UAT).Menyusun skenario pengujian fungsional (black-box testing) sederhana; menjelaskan tujuan dan tahapan pengujian penerimaan pengguna (UAT) sebelum sistem dirilis
P8TP-4Penulisan Dokumentasi Teknis dan Buku Petunjuk Pengguna (User Manual) secara Efektif: Kaidah penyusunan dokumentasi teknis sistem, petunjuk instalasi/penggunaan bagi pengguna awam, dan kejelasan instruksi panduan.Menjelaskan struktur penting dalam dokumentasi sistem dan buku panduan; menulis petunjuk langkah penggunaan aplikasi (user manual) secara lugas, runtut, dan mudah dipahami
P9TP-5Keamanan Siber Lanjutan: Paradigma pertahanan Zero Trust ('never trust, always verify'), manajemen kerentanan sistem, serta prinsip dasar kriptografi kunci publik (asymmetric encryption dan tanda tangan digital).Menjelaskan prinsip arsitektur keamanan Zero Trust; membedakan konsep enkripsi simetris dan asimetris (kunci publik) dalam pertukaran data yang aman
P10TP-5Komputasi Awan Tingkat Lanjut: Konsep virtualisasi mesin, isolasi lingkungan aplikasi melalui kontainer (pengantar Docker), serta prinsip skalabilitas sistem di cloud (scale up vs scale out).Membedakan konsep Virtual Machine dan Containerisasi (Docker); menjelaskan konsep skalabilitas sistem komputasi awan saat menghadapi peningkatan beban pengguna
P11TP-6Sains Data dan Kecerdasan Artifisial Modern: Karakteristik Big Data (volume, velocity, variety), konsep dasar jaringan saraf tiruan (neural networks), dan cara kerja pengantar Model Bahasa Besar (LLM).Menguraikan karakteristik ekosistem Big Data dan cabang kecerdasan artifisial; menjelaskan konsep dasar cara kerja model bahasa besar (LLM) serta pemanfaatannya secara kritis
P12TP-6Tata Kelola TI dan Etika Profesional: Hak Kekayaan Intelektual (HAKI) di bidang perangkat lunak, jenis-jenis lisensi software (open-source vs proprietary), kepatuhan hukum siber, dan pengantar audit sistem informasi.Membedakan jenis lisensi perangkat lunak terbuka (open source) dan berpemilik (proprietary); menjelaskan pentingnya audit sistem serta kepatuhan etika dan hukum dalam pemanfaatan TI
P13TP-7Pemetaan Karier Informatika: Spektrum profesi TI modern (Software Engineer, Data Analyst/Scientist, Cyber Security Specialist, DevOps Engineer), kualifikasi keahlian, dan peluang berkarya di era digital.Memetakan berbagai peran dan tanggung jawab profesi di industri teknologi informasi modern; mengidentifikasi keterampilan teknis dan non-teknis yang dibutuhkan pada bidang karier tertentu
P14TP-7Jalur Pendidikan Lanjut: Ragam program studi rumpun komputasi di perguruan tinggi (Ilmu Komputer, Sistem Informasi, Teknik Informatika, Rekayasa Perangkat Lunak) dan fokus keilmuannya.Membedakan orientasi dan fokus keilmuan antar-jurusan komputer di perguruan tinggi; merencanakan pilihan program studi lanjut yang selaras dengan minat dan potensi diri
P15TP-7Penyusunan Portofolio Digital dan Profil Keahlian Teknologi bagi Lulusan Pesantren: Strategi merangkum karya, proyek komputasi, dan rekam jejak keterampilan digital ke dalam profil portofolio daring yang profesional dan berkarakter santri.Mengidentifikasi artefak hasil karya dan keterampilan teknologi untuk ditampilkan; merancang profil portofolio digital yang representatif, profesional, dan mencerminkan nilai integritas santri
P16TP-7Presentasi Reflektif: Peta Jalan (Roadmap) Pemanfaatan Teknologi untuk Kemaslahatan Umat: Perancangan dan penyampaian gagasan peta jalan penerapan solusi digital berkelanjutan bagi pemberdayaan pesantren dan masyarakat.Menyusun gagasan rencana aksi (roadmap) pemanfaatan teknologi untuk kemaslahatan lingkungan sekitar; mempresentasikan ide proyek/solusi teknologi secara persuasif, beretika, dan reflektif
P17TP-1, TP-2, TP-3, TP-4, TP-5, TP-6, TP-7Ujian Sumatif Akhir Semester: Asesmen sumatif semester menguji pemahaman wawasan arsitektur sistem, UI/UX, rekayasa perangkat lunak dasar, keamanan siber, komputasi awan, kecerdasan artifisial, etika TI, serta kesiapan karier dan studi lanjut.Mengerjakan instrumen asesmen tertulis pilihan ganda dan analisis studi kasus terpadu; mengukur penguasaan wawasan komputasi modern dan tata kelola teknologi informasi semester 1
P18TP-1, TP-2, TP-3, TP-4, TP-5, TP-6, TP-7Muraja'ah, Pembahasan Ujian, dan Refleksi Hasil Belajar: Pembahasan menyeluruh butir soal asesmen sumatif, penguatan konsep-konsep kunci yang masih keliru, serta refleksi komitmen pemanfaatan teknologi untuk kemaslahatan umat.Mengevaluasi kelemahan dan kekeliruan pemahaman materi pada lembar jawaban ujian; merumuskan refleksi akhir pembelajaran mengenai peran strategis santri dalam perkembangan teknologi informasi

Semester 2

CP

Label: Fase F (Kelas 11–12)

Semester genap kelas 12 bukan semester KBM reguler: seluruh semester adalah musim ujian (pendalaman intensif mandiri dan ujian akhir jenjang / Uji Benchmark).

TP

  • TP-1 — Peserta didik mengulang dan memperdalam seluruh tujuan pembelajaran Informatika dari semester-semester sebelumnya secara mandiri dan terbimbing (pendalaman intensif).
  • TP-2 — Peserta didik menyelesaikan rangkaian latihan dan try out/Uji Benchmark Informatika dengan capaian mencapai KKTP.
  • TP-3 — Peserta didik membuktikan ketuntasan seluruh tujuan pembelajaran melalui ujian akhir jenjang; tujuan yang belum terbukti tuntas diselesaikan melalui pendalaman lanjutan sesuai peta ketuntasan.

ATP
