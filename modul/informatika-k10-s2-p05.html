Tujuan Pembelajaran

  • TP-2: Peserta didik mampu menerapkan dasar pemrograman Python untuk membaca berkas CSV, mengelola struktur data kamus (dictionary), membersihkan data anomali, dan menghasilkan visualisasi data sederhana.

Materi Pokok

Materi berfokus pada pengenalan struktur berkas teks CSV dan teknik dasar membaca serta mem-parsing baris demi baris menggunakan modul pustaka bawaan `csv` pada Python:

  1. Struktur Berkas CSV (Comma-Separated Values)
  • Berkas CSV adalah format berkas teks polos terstruktur untuk pertukaran data antaraplikasi, spreadsheet, dan basis data.
  • Format: Setiap baris mewakili satu baris rekaman data, dan antarnilai kolom dipisahkan karakter delimiter (standar tanda koma `,`, titik koma `;`, atau tab `\t`). Baris teratas umumnya merupakan baris tajuk (header) yang mendefinisikan nama atribut.
  1. Membuka Berkas dengan Konstruksi `with open()`
  • Menggunakan fungsi bawaan `open(nama_berkas, mode='r', encoding='utf-8')`.
  • Konstruksi manajer konteks `with open(...) as f:` memastikan berkas otomatis tertutup rapat begitu blok pembacaan selesai, sehingga mencegah kebocoran memori atau penguncian berkas.
  1. Modul Standar `csv` dan Fungsi `csv.reader()`
  • Modul `csv` adalah pustaka bawaan Python (cukup dipanggil dengan `import csv`).
  • Fungsi `csv.reader(berkas, delimiter=',')` menghasilkan iterator pembaca yang otomatis memotong teks tiap baris menjadi daftar string (list).
  • Fungsi `next(reader)` digunakan untuk mengekstrak baris tajuk (header) dan memajukan kursor sebelum perulangan data.
  • Perulangan `for baris in reader:` membaca data baris demi baris secara efisien, di mana nilai kolom diakses melalui nomor indeks list (misal: `baris[0]`, `baris[1]`).

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru membuka pembelajaran dengan salam, memimpin doa bersama santri, dan memeriksa kehadiran serta kesiapan kelas.
  2. Guru memberikan apersepsi kontekstual: "Setiap awal semester, bendahara pesantren mengunduh data pembayaran syahriah ratusan santri dari spreadsheet ke format teks CSV. Bagaimana cara program Python membaca berkas tersebut baris demi baris secara otomatis tanpa perlu diketik ulang?"
  3. Santri diajak berdiskusi singkat mengenai efisiensi pengolahan data terstruktur.
  4. Guru menyampaikan tujuan pembelajaran, indikator, dan alur kegiatan belajar (mode lab komputer maupun simulasi unplugged).

Inti (±40 menit)

Kegiatan dirancang fleksibel untuk mode laboratorium komputer (plugged) maupun mode simulasi tanpa komputer (unplugged):

  1. Eksplorasi Konsep (10 menit)
  • Guru memperlihatkan struktur data `santri.csv` di proyektor atau papan tulis:

```text

NIS,Nama,Asrama

101,Ahmad Fauzi,Al-Falah

102,Bilal Ramadhan,An-Nur

```

  • Guru mendemonstrasikan skrip dasar Python membaca CSV:

```python

import csv

with open('santri.csv', mode='r', encoding='utf-8') as berkas:

pembaca = csv.reader(berkas)

header = next(pembaca)

for baris in pembaca:

print("Nama:", baris[1], "| Asrama:", baris[2])

```

  1. Praktik Terbimbing (15 menit)
  • Mode Komputer (Plugged): Santri membuat berkas `infaq_jumat.csv`, lalu menulis skrip Python dengan modul `csv` untuk membaca isi berkas, memisahkan header dengan `next()`, dan menampilkan kolom tertentu berdasarkan indeks.
  • Mode Tanpa Komputer (Unplugged): Santri berpasangan mensimulasikan alur kerja program. Santri A bertindak sebagai `open()` yang membuka amplop kartu rekaman data santri, Santri B bertindak sebagai `csv.reader()` yang memotong baris teks menjadi kartu elemen list terpisah berdasarkan tanda koma, dan Santri C bertindak sebagai `print()` yang mengambil kartu pada indeks tertentu.
  1. Latihan Mandiri dan Pemecahan Masalah (15 menit)
  • Santri menyelesaikan tugas mandiri: membaca berkas `jadwal_piket.csv` (kolom: `Hari,Petugas,Bagian`) dan mencetak nama petugas khusus untuk bagian `"Masjid"`.
  • Santri menerapkan percabangan `if baris[2] == "Masjid":` di dalam perulangan `for`.
  • Guru berkeliling memberikan pendampingan teknis terkait penulisan sintaks, indentasi blok kode, dan penomoran indeks yang dimulai dari angka 0.

Penutup (±10 menit)

  1. Guru bersama santri menyimpulkan materi: berkas CSV sebagai teks berpemisah karakter, penggunaan manajer konteks `with open()`, serta pemanfaatan `csv.reader()` dan `next()`.
  2. Refleksi singkat bersama santri mengenai manfaat otomasi pembacaan data untuk kemaslahatan administrasi pesantren.
  3. Guru menyampaikan apresiasi atas keaktifan santri dan menginformasikan topik pertemuan berikutnya (membaca CSV ke format dictionary dengan `DictReader`).

Asesmen

1. Soal dan Tugas Singkat

  • Soal 1 (Konsep): Jelaskan apa itu berkas CSV dan mengapa format ini menjadi standar populer untuk pertukaran data antarsistem!
  • Soal 2 (Analisis Kode): Perhatikan kode berikut:

```python

import csv

with open('kitab.csv', mode='r', encoding='utf-8') as f:

reader = csv.reader(f)

header = next(reader)

for baris in reader:

print(baris[0])

```

a. Apa kegunaan fungsi `next(reader)` pada baris ke-5?

b. Jika baris data pertama setelah header berbunyi `"K01,Jurumiyyah,Nahwu"`, apa keluaran dari perintah `print(baris[0])`?

  • Soal 3 (Praktik Skrip): Tuliskan skrip program Python lengkap menggunakan modul `csv` untuk membaca berkas `tahfidz.csv` (kolom: `NIS,Nama,Juz`) dan mencetak teks `"Santri [Nama] menghafal Juz [Juz]"` untuk setiap baris data tanpa mencetak tajuk!

2. Rambu dan Kunci Jawaban

  • Kunci Soal 1: Berkas CSV (Comma-Separated Values) adalah format teks polos terstruktur di mana tiap baris mewakili satu data dan kolom dipisahkan oleh karakter tertentu (seperti koma). Populer karena ringan, mudah dibuat, dibaca manusia, serta didukung hampir seluruh aplikasi dan bahasa pemrograman.
  • Kunci Soal 2:

a. Fungsi `next(reader)` mengambil dan memproses baris pertama yang berisi tajuk kolom (header) sekaligus menggeser iterator ke baris data berikutnya agar header tidak ikut terbaca dalam perulangan.

b. Keluaran yang dicetak adalah: `K01`.

  • Kunci Soal 3:

```python

import csv

with open('tahfidz.csv', mode='r', encoding='utf-8') as f:

pembaca = csv.reader(f)

header = next(pembaca)

for baris in pembaca:

print(f"Santri {baris[1]} menghafal Juz {baris[2]}")

```
