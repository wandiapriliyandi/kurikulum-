  1. Menjelaskan fungsi diagram batang dan diagram garis dalam penyajian data.
  2. Menghasilkan plot grafik sederhana dari data yang telah diolah.

Materi Pokok

Visualisasi data merupakan teknik menyajikan data numerik dan kategori dalam bentuk grafik agar pola, perbandingan, dan tren lebih mudah dianalisis.

  1. Perbedaan Fungsi Diagram Dasar:
  • Diagram Batang (*Bar Chart*): Berfungsi memperbandingkan nilai diskret antarkategori yang terpisah. Contoh di pesantren: perbandingan jumlah santri antarkamar atau perolehan kas infaq mingguan antarkelas. Pada pustaka Python, diagram ini dibuat dengan fungsi `plt.bar(kategori, nilai)`.
  • Diagram Garis (*Line Chart*): Berfungsi menampilkan perubahan nilai berkelanjutan atau tren data dari waktu ke waktu (*time series*). Contoh di pesantren: perkembangan hafalan juz Al-Qur'an santri tiap bulan atau grafik penggunaan daya listrik pesantren selama sepekan. Pada Python, diagram ini dibuat dengan fungsi `plt.plot(waktu, nilai)`.
  1. Pustaka Visualisasi Python (`matplotlib.pyplot`):
  • Pustaka standar yang umum digunakan adalah Matplotlib melalui modul antarmuka `pyplot` (lazim disingkat `plt`).
  • Komponen penting pembuatan grafik:
  • Impor pustaka: `import matplotlib.pyplot as plt`
  • Perintah grafik: `plt.bar()` untuk diagram batang atau `plt.plot()` untuk diagram garis.
  • Anotasi dan kelengkapan:
  • `plt.title("Judul Grafik")` untuk judul grafik.
  • `plt.xlabel("Label Sumbu X")` untuk keterangan sumbu horizontal.
  • `plt.ylabel("Label Sumbu Y")` untuk keterangan sumbu vertikal.
  • `plt.grid(True)` untuk menampilkan garis kisi-kisi pembantu.
  • Penampil grafik: `plt.show()` untuk merender visualisasi ke layar.
  1. Prinsip Integritas Data:
  • Skala sumbu vertikal harus proporsional dan dimulai dari angka nol untuk mencegah kesimpulan yang keliru. Label sumbu wajib jelas agar data tersaji secara akurat (*itqan*).

  3. Penyampaian Tujuan: Guru menjelaskan tujuan pertemuan ke-8, yaitu memahami fungsi diagram batang dan garis serta membuat plot grafik sederhana dengan Python (atau simulasi kertas berpetak bagi kelas *unplugged*).

Inti (±40 menit)

Kegiatan dirancang fleksibel untuk mode laboratorium komputer maupun tanpa perangkat (*unplugged*):

  1. Telaah Kasus dan Diskusi Jenis Diagram (10 menit):
  • Guru mengulas skenario data pesantren:
  • Kasus 1: Membandingkan total setoran tabungan santri antar-asrama (cocok menggunakan diagram batang).
  • Kasus 2: Memantau capaian hafalan santri dari bulan Muharram hingga Rabiul Awal (cocok menggunakan diagram garis).
  • Santri menanggapi dan menyimpulkan alasan pemilihan jenis grafik berdasarkan sifat datanya.
  1. Demonstrasi Pembuatan Grafik (10 menit):
  • Guru mencontohkan skrip grafik tren hafalan santri:

```python

import matplotlib.pyplot as plt

bulan = ["Muharram", "Safar", "Rabiul Awal"]

halaman = [15, 28, 42]

plt.plot(bulan, halaman, marker="o")

plt.title("Tren Hafalan Santri")

plt.xlabel("Bulan")

plt.ylabel("Jumlah Halaman")

plt.grid(True)

plt.show()

```

  • Guru berkeliling mendampingi santri mengatasi galat sintaksis atau ketidaktepatan skala gambar.
  1. Pembahasan dan Reviu (5 menit):
  • Satu kelompok mempresentasikan grafik hasil kerja mereka di depan kelas.

Asesmen

Soal / Tugas Singkat

Diberikan data nilai rata-rata ujian tahsin santri selama 4 pekan berturut-turut:

  • Pekan: `["Pekan 1", "Pekan 2", "Pekan 3", "Pekan 4"]`
  • Nilai: `[65, 72, 80, 88]`

Tugas:

  1. Tentukan jenis diagram yang tepat untuk menyajikan data di atas beserta alasannya.
  2. Tuliskan kode program Python lengkap dengan pustaka `matplotlib` untuk menampilkan diagram tersebut lengkap dengan judul dan label sumbu.

Kunci / Rambu Jawaban

  1. Jenis Diagram: Diagram Garis (*Line Chart*).
  • *Alasan*: Data merupakan data berurutan waktu (*time series*) yang memperlihatkan pola kenaikan atau fluktuasi nilai dari pekan ke pekan.
  1. Kode Program Python:

```python

import matplotlib.pyplot as plt

pekan = ["Pekan 1", "Pekan 2", "Pekan 3", "Pekan 4"]

nilai = [65, 72, 80, 88]

plt.plot(pekan, nilai, marker="o")

plt.title("Perkembangan Nilai Tahsin Santri")

plt.xlabel("Waktu")

plt.ylabel("Nilai Rata-rata")

plt.grid(True)

plt.show()

```
