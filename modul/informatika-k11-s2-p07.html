Modul Ajar — Informatika

Identitas

KomponenKeterangan
Mata PelajaranInformatika

PertemuanKe-7
FaseFase F
Alokasi Waktu60 menit (2 JP × 30 menit)

Tujuan Pembelajaran

  • TP-4: Peserta didik mampu menerapkan Data Manipulation Language (DML) dengan SQL untuk mengambil, memfilter, mengurutkan, membatasi, menyisipkan, memperbarui, dan menghapus data secara terstruktur dan aman.

Indikator Ketercapaian Pembelajaran:

  1. Menerapkan klausa `WHERE` untuk menyaring baris data berdasarkan kriteria tertentu.
  2. Mengombinasikan dua atau lebih kondisi menggunakan operator logika AND dan OR.

Materi Pokok

1. Fungsi Klausa WHERE

Klausa `WHERE` digunakan bersama perintah `SELECT` untuk menyaring baris data dalam tabel basis data. Hanya data yang memenuhi kriteria (bernilai `TRUE`) yang ditampilkan.

Sintaks dasar:

```sql

SELECT kolom1, kolom2 FROM nama_tabel WHERE kondisi;

```

2. Operator Perbandingan

Digunakan untuk membandingkan nilai kolom dengan nilai acuan:

  • `=` : Sama dengan (contoh: `status = 'Aktif'`)
  • `!=` : Tidak sama dengan (contoh: `kamar != 'A-01'`)
  • `<` : Kurang dari (contoh: `usia < 17`)
  • `>` : Lebih dari (contoh: `poin > 0`)
  • `<=` : Kurang dari atau sama dengan (contoh: `juz <= 10`)
  • `>=` : Lebih dari atau sama dengan (contoh: `nilai >= 80`)

3. Operator Logika

Digunakan untuk mengombinasikan beberapa kondisi:

  • `AND`: Benar jika seluruh kondisi terpenuhi.

*Contoh:* `SELECT nama FROM santri WHERE kelas = 11 AND asrama = 'Al-Ghazali';`

  • `OR`: Benar jika salah satu atau semua kondisi terpenuhi.

*Contoh:* `SELECT nama FROM santri WHERE kota = 'Jombang' OR kota = 'Kediri';`

  • `NOT`: Membalikkan kondisi logika.

*Contoh:* `SELECT nama FROM santri WHERE NOT status = 'Alumni';`

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru memberi salam, memimpin doa bersama, dan memeriksa presensi santri.
  2. Apersepsi: Guru mengaitkan materi dengan situasi pesantren.
  • *Pemantik:* "Jika lurah pondok ingin mencari santri asrama Abu Bakar yang belum setor hafalan Juz 30 dari ribuan santri, bagaimana komputer memfilternya dengan cepat?"
  1. Penyampaian Tujuan: Guru menjelaskan indikator pembelajaran, yaitu memfilter baris data memakai klausa `WHERE`, operator perbandingan, dan logika AND/OR.

Inti (±40 menit)

Langkah 1: Eksplorasi Konsep (±10 menit)
  • Guru menampilkan contoh tabel `santri` (kolom: `nis`, `nama`, `asrama`, `nilai_tahfidz`, `status_spp`).
  • Guru mendemonstrasikan cara kerja klausa `WHERE` ibarat pos keamanan pondok yang menyeleksi santri keluar komplek sesuai izin.
  • Guru mencontohkan kueri perbandingan nilai dan kombinasi logika AND/OR.
Langkah 2: Praktik Berpasangan / Unplugged (±20 menit)

*Disesuaikan dengan ketersediaan sarana:*

  • Opsi Lab / Perangkat Komputer:
  1. Santri berpasangan membuka aplikasi SQL (seperti DB Browser for SQLite atau SQL Online).
  2. Santri mengeksekusi kueri filter pada data santri (misal: mencari santri kelas 11 yang nilainya kurang dari 75).
  3. Santri menguji variasi operator logika AND dan OR.
  • Opsi Unplugged (Tanpa Komputer):
  1. Santri berkelompok (3–4 orang) menerima lembar kerja tabel data santri dan kartu instruksi filter SQL.
  2. Santri berperan sebagai mesin database yang menandai dan menyaring baris data yang cocok dengan instruksi klausa `WHERE`.
  3. Kelompok membandingkan hasil data yang lolos seleksi filter.
Langkah 3: Diskusi dan Konfirmasi (±10 menit)
  • Perwakilan santri memaparkan hasil filter data dan kueri yang dibuat.
  • Guru memberi klarifikasi kritis, misalnya mengapa kueri `WHERE asrama = 'A' AND asrama = 'B'` menghasilkan data kosong.

Penutup (±10 menit)

  1. Rangkuman: Guru bersama santri menyimpulkan fungsi klausa `WHERE`, sifat ketat operator `AND`, serta sifat alternatif operator `OR`.
  2. Refleksi Santri: Santri menyampaikan kesan pembelajaran dan kendala logika yang dihadapi.
  3. Pesan Nilai Pesantren: Guru mengingatkan pentingnya ketelitian memfilter data sebagai cerminan sikap tabayyun dan amanah.
  4. Penutup: Kelas diakhiri dengan doa kafaratul majlis dan salam.

Asesmen

1. Soal Latihan Mandiri

Gunakan tabel `santri` dengan kolom: `nama`, `asrama`, `juz_tuntas`, `kehadiran_kajian` (%).

  1. Tuliskan kueri SQL untuk menampilkan `nama` dan `juz_tuntas` santri yang hafalannya lebih dari atau sama dengan 5 juz!
  2. Tuliskan kueri SQL untuk mencari santri di `asrama` 'An-Nur' yang `kehadiran_kajian` miliknya kurang dari 80%!
  3. Tuliskan kueri SQL untuk menampilkan santri yang tinggal di asrama 'Al-Ikhlas' ATAU tinggal di asrama 'Al-Falah'!
  4. Jelaskan perbedaan hasil kueri berikut:
  • Kueri A: `SELECT * FROM santri WHERE juz_tuntas >= 3 AND kehadiran_kajian >= 90;`
  • Kueri B: `SELECT * FROM santri WHERE juz_tuntas >= 3 OR kehadiran_kajian >= 90;`

2. Kunci dan Rambu Jawaban

  1. ```sql

SELECT nama, juz_tuntas FROM santri WHERE juz_tuntas >= 5;

```

  1. ```sql

SELECT * FROM santri WHERE asrama = 'An-Nur' AND kehadiran_kajian < 80;

```

  1. ```sql

SELECT * FROM santri WHERE asrama = 'Al-Ikhlas' OR asrama = 'Al-Falah';

```

  1. Rambu Jawaban:
  • Kueri A (`AND`) menyaring data secara ketat; baris hanya muncul bila santri memenuhi kedua kriteria sekaligus.
  • Kueri B (`OR`) menyaring data secara fleksibel; baris muncul bila santri memenuhi salah satu atau kedua kriteria.

3. Kriteria Ketuntasan

Rentang NilaiKategoriTindak Lanjut
0 – 69Belum TuntasRemedial konsep dasar operator logika dan latihan filter kriteria tunggal.
70 – 84TuntasLatihan pengayaan logika gabungan AND/OR.
85 – 100Sangat TuntasPengayaan kueri kompleks (tanda kurung logika atau operator `IN`/`BETWEEN`).

  • Apakah santri sudah mampu membedakan logika seleksi `AND` dan `OR` dengan tepat?
  • Apakah alokasi waktu kegiatan inti (40 menit) cukup untuk praktik plugged maupun unplugged?
  • Kesalahan apa yang paling dominan (sintaks teks/string atau nalar logika gabungan)?
  • Apa tindak lanjut untuk pertemuan selanjutnya mengenai pengurutan data (`ORDER BY`)?
