Modul Ajar — Informatika

Alokasi Waktu60 menit (2 JP × 30 menit)

Tujuan Pembelajaran

  • TP-4: Peserta didik mampu menerapkan Data Manipulation Language (DML) dengan SQL untuk mengambil, memfilter, mengurutkan, membatasi, menyisipkan, memperbarui, dan menghapus data secara terstruktur dan aman.
  • Indikator:
  1. Mengurutkan data hasil kueri secara alfabetis atau numerik menggunakan klausa `ORDER BY` menaik (`ASC`) maupun menurun (`DESC`).
  2. Membatasi banyaknya baris data yang ditampilkan dengan klausa `LIMIT`.

Materi Pokok

Dalam SQL, hasil perintah `SELECT` secara baku tidak tersusun rapi. Agar informasi tersaji teratur dan efisien, digunakan klausa `ORDER BY` dan `LIMIT`.

1. Klausa `ORDER BY`

Klausa ini mengurutkan baris data berdasarkan kolom tertentu.

  • `ASC` (Ascending): Mengurutkan nilai terkecil ke terbesar (0–9 atau A–Z). Merupakan urutan baku jika kata kunci tidak ditulis.
  • `DESC` (Descending): Mengurutkan nilai terbesar ke terkecil (9–0 atau Z–A).

Sintaks dasar:

```sql

SELECT kolom1, kolom2 FROM nama_tabel ORDER BY kolom1 ASC|DESC;

```

2. Klausa `LIMIT`

Klausa ini membatasi jumlah baris yang ditampilkan dalam hasil kueri, menghemat memori sistem, dan mempercepat akses data.

Sintaks dasar:

```sql

SELECT kolom1 FROM nama_tabel LIMIT jumlah_baris;

```

3. Kombinasi `ORDER BY` dan `LIMIT`

Kombinasi ini digunakan untuk menyaring peringkat teratas (*ranking*). Urutan penulisan klausa SQL adalah:

```sql

SELECT nama_santri, nilai_tahfiz FROM santri ORDER BY nilai_tahfiz DESC LIMIT 3;

```

*Kueri di atas menampilkan 3 santri dengan nilai tahfiz tertinggi.*

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembiasaan Islami: Guru membuka kelas dengan salam, memeriksa kesiapan dan presensi santri, serta memimpin doa.
  2. Apersepsi: Guru mengaitkan materi dengan situasi pesantren: *"Bagaimana sekretariat pondok menampilkan 3 santri peraih nilai tahfiz tertinggi tanpa memeriksa berkas satu per satu?"*
  3. Penyampaian Tujuan: Guru menjelaskan materi pertemuan ini, yaitu pengurutan data (`ORDER BY`) dan pembatasan baris (`LIMIT`).

Inti (±40 menit)

1. Pemaparan Konsep (±10 menit)
  • Guru menjelaskan fungsi dan perbedaan sintaks `ORDER BY (ASC/DESC)` serta `LIMIT`.
  • Menjelaskan aturan susunan SQL: `SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT ...`.
  • *Opsi Unplugged*: Jika komputer atau listrik padam, guru menyajikan tabel data santri di papan tulis dan memperagakan simulasi kartu data secara visual.
2. Praktik Berpasangan (±20 menit)
  • Santri berpasangan menyelesaikan kasus data pesantren:
  • Mengurutkan daftar nama santri berdasarkan abjad A–Z (`ORDER BY nama ASC`).
  • Menampilkan 3 santri dengan hafalan terbanyak (`ORDER BY juz DESC LIMIT 3`).
  • Menampilkan 5 santri dengan poin pelanggaran paling sedikit.
  • Santri mengeksekusi kueri di komputer atau menyusun kartu data fisik (moda *unplugged*). Guru berkeliling membimbing santri yang keliru menempatkan posisi klausa `LIMIT`.
3. Diskusi & Konfirmasi (±10 menit)
  • Perwakilan santri mempresentasikan kueri yang dibuat dan hasilnya.
  • Santri lain menanggapi mengapa klausa `LIMIT` harus diletakkan setelah `ORDER BY`.
  • Guru mengonfirmasi ketepatan struktur kueri santri.

Penutup (±10 menit)

  1. Rangkuman: Guru bersama santri menyimpulkan kegunaan `ORDER BY` untuk keteraturan data dan `LIMIT` untuk pembatasan jumlah baris.
  2. Refleksi: Santri menyampaikan pemahaman baru serta kendala sintaks yang dialami.
  3. Doa Penutup: Guru mengingatkan nilai keteraturan dalam Islam, lalu menutup kelas dengan doa kafaratul majlis dan salam.

Asesmen

1. Soal Latihan Singkat

Diberikan tabel `santri_prestasi` (kolom: `nis`, `nama`, `kamar`, `nilai_imtihan`):

  1. Tuliskan kueri SQL untuk menampilkan kolom `nama` dan `kamar` yang diurutkan sesuai abjad A ke Z!
  2. Tuliskan kueri SQL untuk menampilkan 3 santri dengan `nilai_imtihan` tertinggi!
  3. Apakah urutan kueri `SELECT nama FROM santri_prestasi LIMIT 3 ORDER BY nilai_imtihan DESC;` benar menurut aturan SQL? Jelaskan!

2. Kunci Jawaban

  1. ```sql

SELECT nama, kamar FROM santri_prestasi ORDER BY nama ASC;

```

  1. ```sql

SELECT nama, nilai_imtihan FROM santri_prestasi ORDER BY nilai_imtihan DESC LIMIT 3;

```

  1. Salah. Urutan klausa SQL tidak tepat karena `LIMIT` ditulis sebelum `ORDER BY`. Aturan baku SQL mengharuskan pengurutan data (`ORDER BY`) dilakukan sebelum membatasi jumlah baris (`LIMIT`). Kueri tersebut akan menyebabkan galat (*syntax error*).

3. Kriteria Ketuntasan (KKTP)

  • Tuntas (Skor ≥ 75): Santri mampu menuliskan kueri `ORDER BY` (ASC/DESC) dan `LIMIT` secara tepat serta runtut tanpa kesalahan sintaks.
  • Belum Tuntas (Skor < 75): Santri masih keliru membedakan urutan ASC/DESC atau terbalik meletakkan posisi klausa `LIMIT` sebelum `ORDER BY`. Santri yang belum tuntas diberikan bimbingan perbaikan mandiri.

Media dan Sumber Belajar

  • Media: Komputer/laptop, aplikasi basis data (MariaDB/MySQL/SQLite atau kompilator daring), proyektor, serta kartu data fisik santri (untuk moda *unplugged*).
  • Sumber Belajar: Buku Panduan Guru dan Siswa Informatika Kelas 11 Fase F Kurikulum Madrasah serta dokumentasi SQL daring.

Catatan Refleksi Guru

  • Apakah santri sudah memahami bahwa `ORDER BY` dieksekusi sebelum data dipotong oleh `LIMIT`?
  • Apakah kegiatan *unplugged* dengan kartu data membantu pemahaman santri saat komputer tidak tersedia?
  • Santri yang tuntas lebih cepat diberi materi pengayaan kueri pengurutan dua kolom, sedangkan yang belum tuntas didampingi menyusun urutan kata kunci SQL secara benar.
