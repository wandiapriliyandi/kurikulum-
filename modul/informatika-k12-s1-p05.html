Modul Ajar — Informatika

Identitas

KomponenKeterangan
Mata PelajaranInformatika
Kelas12
Semester1 (Ganjil)
Pertemuan5
FaseFase F
Alokasi Waktu60 menit (2 JP × 30 menit)

Tujuan Pembelajaran

  • Peserta didik mampu memahami wawasan pengembangan web (peran HTML, CSS, JavaScript) dan backend/API (komunikasi antarsistem) secara konseptual dalam ekosistem aplikasi modern (TP-3).

Indikator Ketercapaian Tujuan Pembelajaran:

  1. Membedakan peran dan fungsi HTML, CSS, dan JavaScript dalam halaman web modern.
  2. Menjelaskan keterkaitan antara struktur dokumen, gaya visual, dan perilaku interaktif pada aplikasi web.

Materi Pokok

Pengembangan web modern pada sisi klien (*front-end*) ditopang oleh trilogi teknologi inti yang saling melengkapi:

  1. HTML (*HyperText Markup Language*) — Struktur dan Konten
  • Berfungsi sebagai kerangka dasar dokumen web.
  • Mengatur struktur teks, heading, paragraf, daftar (*list*), tabel, gambar, tautan (*hyperlink*), dan formulir.
  • Analogi fisik: Bangunan dasar gedung atau kerangka tulang manusia.
  1. CSS (*Cascading Style Sheets*) — Tata Gaya dan Tampilan Visual
  • Mengatur estetika, tata letak (*layout*), warna latar, jenis huruf (*font*), spasi, margin, ukuran elemen, serta adaptasi tampilan pada berbagai layar (*responsiveness*).
  • Analogi fisik: Cat dinding, dekorasi interior, busana, atau pakaian yang memperindah rupa fisik.
  1. JavaScript (JS) — Perilaku dan Interaktivitas Dinamis
  • Menjadikan halaman web responsif terhadap aksi pengguna (misalnya klik tombol, validasi formulir langsung tanpa *refresh*, manipulasi konten DOM secara *real-time*, dan animasi interaktif).
  • Analogi fisik: Instalasi listrik, sakelar lampu, sensor pintu otomatis, atau sistem saraf/otot yang memungkinkan terjadinya aksi dan gerak.
  1. Integrasi Ketiga Teknologi
  • Web modern memisahkan struktur isi (*content/structure*), presentasi (*presentation*), dan tingkah laku (*behavior*).
  • Dokumen HTML dimuat pertama kali oleh peramban (*browser*), CSS kemudian merias dan menata elemen-elemen tersebut, sementara JavaScript memberikan respon logis ketika santri atau pengguna berinteraksi dengan elemen-elemen tersebut.

Kegiatan Pembelajaran

Catatan Kegiatan: Pembelajaran dirancang fleksibel. Jika laboratorium komputer/perangkat gawai tersedia, santri dapat melihat simulasi inspeksi elemen (*DevTools*). Apabila perangkat terbatas atau tidak tersedia, pembelajaran menggunakan metode *unplugged* (permainan peran fisik dan lembar simulasi kertas).

Pendahuluan (±10 menit)

  1. Pembukaan dan Muqaddimah: Guru mengucap salam, mengajak santri membaca basmalah dan doa belajar bersama, serta mengecek kehadiran santri.
  2. Apersepsi Kontekstual Pesantren:
  • Guru mengaitkan materi dengan media pesantren, misalnya website pendaftaran santri baru atau portal pengumuman jadwal kajian pondok.
  • Guru bertanya: *"Pernahkah antum membuka situs web pengumuman pondok? Mengapa teksnya rapi, warnanya selaras dengan lambang pesantren, dan ketika tombol 'Lihat Jadwal' diklik, jadwalnya muncul seketika tanpa membuka halaman baru?"*
  1. Penyampaian Tujuan & Motivasi: Guru menyampaikan tujuan pertemuan hari ini, yaitu memahami peran HTML, CSS, dan JavaScript secara konseptual beserta perpaduannya.

Inti (±40 menit)

Langkah 1: Eksplorasi Konsep & Analogi "Papan Mading Pesantren" (10 menit)
  • Guru menjelaskan konsep HTML, CSS, dan JavaScript dengan analogi pembuatan papan mading (*majalah dinding*) digital santri:
  • HTML: Menuliskan naskah teks, judul tajuk rencana, tabel jadwal imsakiyah, dan foto kegiatan di atas kertas karton (isi murni).
  • CSS: Memilih jenis tulisan kaligrafi, mewarnai bingkai hijau khas pesantren, menata jarak antarartikel agar sedap dipandang.
  • JavaScript: Menempelkan mekanisme tombol putar atau katup geser fisik yang dapat membuka tirai informasi saat disentuh tangan santri.
  • Guru menguraikan keterkaitan ketiganya dalam membentuk ekosistem halaman web utuh.
Langkah 2: Kegiatan Kolaboratif / Roleplay Unplugged (20 menit)

Santri dibagi menjadi kelompok kecil beranggotakan 3 orang untuk memainkan peran tri-teknologi (*Roleplay Front-End Web*):

  • Santri 1 (Peran HTML / Struktur):
  • Diberi tugas menuliskan kerangka teks murni pada kartu indeks/kertas polos: Judul Berita Pesantren, Paragraf Pembuka, dan satu kotak bertuliskan "Tombol Baca Selengkapnya".
  • Santri 2 (Peran CSS / Tampilan):
  • Diberi tugas menambahkan aturan gaya visual: Memberikan garis bingkai berhias kaligrafi, memilih warna spidol hijau lumut untuk judul, dan menata kotak tombol menjadi melengkung rapi di tengah halaman.
  • Santri 3 (Peran JavaScript / Interaktivitas):
  • Diberi tugas menentukan aksi interaksi: Mengatur logika respon. Ketika teman kelompoknya menyentuh atau menunjuk tombol "Baca Selengkapnya", santri peran JS membuka lipatan kertas rahasia yang berisi kelanjutan teks berita.
  • *(Opsi Plugged / Berperangkat):* Bila laptop santri/lab madrasah tersedia, guru mendemonstrasikan fungsi *Inspect Element* pada peramban web: menonaktifkan CSS (web menjadi polos berantakan), serta mematikan JS (tombol menu tidak merespon saat diklik).
Langkah 3: Diskusi dan Refleksi Kelompok (10 menit)
  • Setiap kelompok menyampaikan temuan dari simulasi:
  • Apa yang terjadi jika hanya ada HTML? (Halaman ada isinya, tapi kaku dan tidak menarik).
  • Apa yang terjadi jika CSS dihilangkan? (Struktur tetap terbaca tetapi tata letak berantakan dan monoton).
  • Apa yang terjadi jika tanpa JavaScript? (Halaman statis, tidak ada respon langsung terhadap interaksi santri).
  • Guru memberikan penguatan konseptual terhadap hasil kerja santri.

Penutup (±10 menit)

  1. Rangkuman Bersama: Guru bersama santri menyimpulkan intisari pertemuan: HTML membentuk kerangka, CSS mempercantik busana tampilan, dan JavaScript menghidupkan interaksi.
  2. Asesmen Cepat (Refleksi Lisan): Guru mengajukan 1-2 pertanyaan konfirmasi pemahaman santri.
  3. Pesan Moral & Rencana Pertemuan Depan: Guru berpesan tentang pentingnya literasi digital di era modern untuk dakwah Islam. Guru memberikan gambaran singkat pertemuan berikutnya mengenai backend dan pengenalan API sederhana.
  4. Doa Kafaratul Majelis dan Salam: Kegiatan ditutup dengan doa kafaratul majelis dan salam penutup.

Asesmen

1. Tugas / Kuis Singkat

Instrumen Soal:

  1. Di sebuah portal madrasah, terdapat formulir pendaftaran santri baru. Sebutkan masing-masing 1 (satu) contoh peran nyata dari HTML, CSS, dan JavaScript pada halaman formulir tersebut!
  2. Jika sebuah halaman web kehilangan berkas CSS-nya karena gangguan server, bagaimana kondisi informasi dan tampilan halaman web tersebut saat dibuka santri? Jelaskan alasannya!

2. Kunci / Rambu Jawaban

  1. Contoh peran pada formulir pendaftaran santri:
  • HTML: Menyediakan kotak input teks nama, kolom pilihan kamar/asrama, dan tombol bertuliskan "Kirim Pendaftaran".
  • CSS: Mengatur agar kotak input berbaris rapi di tengah layar, memberi warna hijau lembut pada tombol, dan memperjelas jenis huruf agar nyaman dibaca.
  • JavaScript: Memeriksa apakah kolom nomor telepon santri sudah diisi dengan benar sebelum dikirim, atau menampilkan jendela konfirmasi *"Apakah data santri sudah yakin benar?"* saat tombol diklik.
  1. Kondisi halaman tanpa CSS:
  • Informasi teks, gambar, dan tombol tetap dapat dibaca/diakses karena struktur HTML masih utuh.
  • Namun, tampilan visual menjadi sangat polos, teks rata kiri dengan warna bawaan hitam-putih, ukuran gambar tidak teratur, dan tata letak menjadi acak-acakan ke bawah tanpa penataan gaya estetika.

Media dan Sumber Belajar

  1. Media Pembelajaran:
  • Papan tulis, spidol aneka warna, kertas karton / kertas HVS / kartu indeks (untuk kegiatan *unplugged*).
  • Laptop/Komputer dan proyektor LCD (opsional, jika lab komputer tersedia).
  • Peramban web (*Google Chrome* / *Mozilla Firefox*) dengan fitur *Developer Tools* / *Inspect Element*.
  1. Sumber Belajar:
  • Buku Teks Informatika SMA/MA Kelas 12 Kurikulum Merdeka (Kementerian Pendidikan / Kementerian Agama).
  • Dokumentasi *MDN Web Docs* (*Mozilla Developer Network*): *Getting started with the Web*.
  • Lembar Kerja Santri (LKS) perancangan antarmuka web.

Catatan Refleksi Guru

  • Apakah analogi "Papan Mading / Kerangka-Pakaian-Saraf" berhasil mempermudah pemahaman santri terhadap perbedaan HTML, CSS, dan JavaScript?
  • Seberapa aktif santri madrasah/pesantren berpartisipasi dalam kegiatan simulasi peran (*roleplay*) kelompok?
  • Apakah waktu 60 menit (2 JP × 30 menit) mencukupi untuk memadukan konsep teori dan simulasi sederhana, atau perlu penyesuaian durasi pada langkah inti?
  • Bagian konsep mana yang masih sering membingungkan santri (misalnya pembedaan batas tanggung jawab antara manipulasi CSS dan interaksi logika JavaScript)?
