Modul Ajar — Informatika

Identitas

KomponenKeterangan
Mata PelajaranInformatika

FaseFase D
Alokasi Waktu60 menit (2 JP × 30 menit)

Tujuan Pembelajaran

  • TP-5: Peserta didik mampu mengolah data lanjutan pada aplikasi lembar kerja menggunakan fungsi logika bersyarat (IF tunggal dan IF majemuk sederhana).

Indikator:

  1. Memahami struktur penulisan formula IF tunggal (tes logika, nilai jika benar, nilai jika salah).
  2. Menerapkan formula IF tunggal untuk menentukan status kelulusan santri atau ketuntasan belajar secara otomatis.

Materi Pokok

Fungsi logika bersyarat IF tunggal digunakan untuk menghasilkan output berbeda berdasarkan pemenuhan kriteria nilai angka maupun teks. Jika kondisi terpenuhi (bernilai benar/TRUE), aplikasi menghasilkan nilai pertama; jika tidak terpenuhi (bernilai salah/FALSE), dihasilkan nilai kedua.

1. Struktur Formula IF Tunggal

Sintaksis dasar penulisan formula IF:

`=IF(tes_logika; nilai_jika_benar; nilai_jika_salah)`

*(Catatan: Tanda pemisah argumen menggunakan titik koma (;) atau koma (,) tergantung pengaturan regional komputer).*

Komponen formula:

  • tes_logika: Pernyataan perbandingan menggunakan operator (=, >, <, >=, <=, <>).
  • nilai_jika_benar: Output bila tes logika terpenuhi. Data teks wajib diapit tanda petik dua ("...").
  • nilai_jika_salah: Output bila tes logika tidak terpenuhi. Data teks wajib diapit tanda petik dua ("...").

2. Contoh Penerapan

  • Kriteria Nilai Angka: Menentukan ketuntasan nilai Fiqih dengan KKM 75 pada sel B2:

`=IF(B2>=75; "TUNTAS"; "REMIDIAL")`

  • Kriteria Teks: Menentukan status kelulusan setoran hafalan Qur'an pada sel C2:

`=IF(C2="LANCAR"; "LULUS"; "PENDING")`

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru mengucap salam, menyapa santri, memeriksa kehadiran, dan memimpin doa.
  2. Apersepsi: Guru mengaitkan materi dengan rekapitulasi nilai setoran nadzam atau tahsin santri di pondok pesantren: *"Bagaimana merekap status kelulusan ratusan santri secara cepat dan otomatis?"*
  3. Guru menyampaikan tujuan pembelajaran, indikator, dan alur kegiatan hari ini (praktik komputer atau simulasi unplugged).

Inti (±40 menit)

  1. Penjelasan Konsep (±10 menit):
  • Guru menguraikan analogi logika keputusan santri: *"JIKA nilai ujian kitab mencapai 75, MAKA dinyatakan lulus, JIKA TIDAK harus remidial."*
  • Guru membedah struktur argumen formula IF di papan tulis/layar proyektor.
  1. Praktik Mandiri & Terbimbing (±20 menit):
  • Santri menerima lembar data nilai santri (Nama: Ahmad, Zaid, Fatimah, Maryam; Nilai: 80, 70, 85, 65).
  • *Aktivitas Digital*: Santri membuka aplikasi pengolah angka, memasukkan data, lalu mengetikkan rumus `=IF(B2>=75; "TUNTAS"; "REMIDIAL")` di sel C2 dan menyalin rumus ke bawah.
  • *Aktivitas Unplugged (bila perangkat tidak tersedia)*: Santri menggambar format tabel lembar kerja di buku tulis, menganalisis kondisi logika per baris, dan menuliskan formula lengkap yang tepat di kolom status.
  • Latihan dilanjutkan dengan kriteria teks pada kolom setoran hafalan: `=IF(D2="MUTQIN"; "SYAHADAH"; "MURAJAAH")`.
  • Guru berkeliling membimbing santri yang mengalami galat penulisan rumus.
  1. Uji Coba & Diskusi (±10 menit):
  • Santri menguji fleksibilitas formula dengan mengubah angka nilai pada sel untuk melihat perubahan output otomatis.
  • Perwakilan santri menuliskan logika rumusnya di papan tulis dan dibahas bersama.

Penutup (±10 menit)

  1. Guru bersama santri menyimpulkan aturan penulisan formula IF tunggal serta fungsi tanda petik ganda untuk teks.
  2. Guru memberikan apresiasi dan umpan balik atas latihan yang diselesaikan santri.
  3. Guru menyampaikan topik pertemuan berikutnya (IF majemuk/bertingkat).
  4. Kelas diakhiri dengan doa kafarotul majelis dan salam penutup.

Asesmen

1. Soal / Tugas Singkat

Data nilai santri MTs:

  • Salman: Nilai Ujian = 72 (sel B3), Setoran Hafalan = "LENGKAP" (sel C3).
  • Aisyah: Nilai Ujian = 88 (sel B4), Setoran Hafalan = "BELUM" (sel C4).
  • Batas KKM kelulusan adalah nilai 75.

Tugas santri:

  1. Tuliskan formula IF pada sel D3 untuk menentukan ketuntasan nilai Salman ("TUNTAS" atau "REMIDIAL")!
  2. Tuliskan formula IF pada sel E3 untuk mengecek status sertifikat ("BERHAK" jika sel C3 bernilai "LENGKAP", dan "BELUM" jika sebaliknya)!
  3. Tuliskan hasil output yang muncul pada sel D3, D4, E3, dan E4!

2. Kunci dan Rambu Jawaban

  1. Formula sel D3: `=IF(B3>=75; "TUNTAS"; "REMIDIAL")` *(pemisah koma `,` juga dibenarkan)*.
  2. Formula sel E3: `=IF(C3="LENGKAP"; "BERHAK"; "BELUM")`.
  3. Output yang tampil:
  • Sel D3: REMIDIAL (72 < 75)
  • Sel D4: TUNTAS (88 >= 75)
  • Sel E3: BERHAK
  • Sel E4: BELUM

Media dan Sumber Belajar

  1. Media: Komputer PC/Laptop (aplikasi pengolah angka), proyektor LCD, papan tulis, lembar kerja santri cetak/buku catatan (skema unplugged).
  2. Sumber Belajar: Buku Teks Informatika Kelas 8 Kurikulum Madrasah/Kemenag, modul ajar pengolah angka, lembar rekap data santri pondok pesantren.
