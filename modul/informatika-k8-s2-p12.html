Modul Ajar — Informatika

Identitas

KomponenKeterangan
Mata PelajaranInformatika
Kelas / Semester8 / Genap (Semester 2)
Pertemuan ke-12
FaseFase D
Alokasi Waktu60 menit (2 JP × 30 menit)

Tujuan Pembelajaran

  • TP-5: Peserta didik mampu mengolah data lanjutan pada aplikasi lembar kerja menggunakan fungsi logika bersyarat (IF tunggal dan IF majemuk sederhana).

Indikator Ketercapaian

  1. Menjelaskan alur penulisan rumus fungsi IF bertingkat/majemuk sederhana.
  2. Mengimplementasikan formula IF majemuk untuk menentukan predikat nilai (misal: Mumtaz, Jayyid, Maqbul).

Materi Pokok

Pengolah Angka Lanjutan: Fungsi Bersyarat Ganda (IF Majemuk Sederhana)

Fungsi logika bersyarat IF digunakan untuk menghasilkan nilai berdasarkan pengujian kondisi tertentu. Pada fungsi IF tunggal, hasil evaluasi hanya mencakup dua kemungkinan (TRUE atau FALSE). Dalam praktiknya, sering dihadapi situasi pengelompokan data dengan lebih dari dua kategori hasil. Untuk kebutuhan tersebut, digunakan IF majemuk sederhana (nested IF), yaitu menyisipkan fungsi IF berikutnya ke dalam argumen nilai jika salah (*value_if_false*).

1. Alur Logika Percabangan Bertingkat

Logika pengujian diperiksa secara berurutan:

  • Kondisi 1: Diuji pertama kali. Jika bernilai benar, sistem mengeluarkan Hasil 1.
  • Kondisi 2: Jika Kondisi 1 salah, sistem menguji kondisi berikutnya. Jika benar, mengeluarkan Hasil 2.
  • Kondisi Akhir: Jika seluruh kondisi salah, sistem mengeluarkan Hasil Terakhir.

Bagan alur logika penentuan 3 predikat:

```

[Nilai Ujian]

│

▼

Apakah Nilai >= 85? ──(Ya)──> Hasil: "Mumtaz"

│ (Tidak)

▼

Apakah Nilai >= 70? ──(Ya)──> Hasil: "Jayyid"

│ (Tidak)

▼

Hasil Akhir: "Maqbul"

```

2. Sintaks Rumus

Bentuk umum penulisan formula IF majemuk untuk 3 kategori hasil:

`=IF(tes_logika1; nilai_jika_benar1; IF(tes_logika2; nilai_jika_benar2; nilai_jika_salah2))`

Penerapan rumus menentukan predikat dari sel nilai B4:

`=IF(B4>=85; "Mumtaz"; IF(B4>=70; "Jayyid"; "Maqbul"))`

Keterangan:

  • Kriteria nilai: Nilai 85 ke atas memperoleh predikat "Mumtaz", nilai 70 sampai 84 berpredikat "Jayyid", dan nilai di bawah 70 berpredikat "Maqbul".
  • Tanda pemisah argumen menggunakan titik koma `;` atau koma `,` sesuai pengaturan bahasa komputer.
  • Penulisan diakhiri dua kurung tutup `))` karena terdapat dua fungsi IF yang dibuka.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru membuka kelas dengan salam, menyapa santri, dan memimpin doa belajar.
  2. Guru memeriksa presensi serta kesiapan sarana belajar santri.
  3. Guru melakukan apersepsi dengan mengaitkan materi IF tunggal: *"Jika predikat imtihan pesantren terdiri atas Mumtaz, Jayyid, dan Maqbul, bagaimana cara komputer menentukannya secara otomatis?"*
  4. Guru menyampaikan tujuan pembelajaran mengenai logika IF majemuk sederhana dan relevansinya dalam administrasi data nilai santri.

Inti (±40 menit) — Kontekstual Kehidupan Pesantren

Kegiatan inti dirancang kontekstual dengan kehidupan pesantren dan dapat dijalankan dengan komputer (plugged) maupun tanpa komputer (unplugged).

1. Pemodelan Logika Bersyarat (10 menit)
  • Guru menyajikan kasus pengelompokan predikat nilai ujian kitab/tahfidz santri: nilai 85-100 (Mumtaz), 70-84 (Jayyid), dan di bawah 70 (Maqbul).
  • Guru menggambarkan diagram percabangan bertingkat di papan tulis, memperlihatkan alur bertahap dari batas nilai tertinggi ke batas berikutnya.
  • Guru menguraikan struktur penulisan rumus, fungsi tanda petik pada teks predikat, serta letak kurung tutup penutup rumus.
2. Praktik Terbimbing (15 menit)
  • Moda dengan Komputer (Plugged):
  • Santri membuka program lembar kerja dan menginput tabel contoh berisi nama santri dan nilai ujian imtihan.
  • Santri mengetikkan formula pada kolom predikat:

`=IF(B2>=85; "Mumtaz"; IF(B2>=70; "Jayyid"; "Maqbul"))`

  • Santri menarik fill handle ke bawah untuk menerapkan formula pada baris data lainnya.
  • Moda Tanpa Komputer (Unplugged):
  • Santri menyalin format tabel pada buku tulis berpetak.
  • Santri berperan sebagai mesin pemroses logika, menuliskan rumus lengkap pada kolom predikat dan menelusuri pengujian nilai santri satu per satu secara manual.
3. Latihan Terarah dan Pendampingan (15 menit)
  • Santri mencoba menyelesaikan latihan penentuan predikat secara mandiri berdasarkan data nilai yang berbeda (termasuk nilai uji batas seperti 85, 70, dan 69).
  • Guru berkeliling mendampingi santri, membantu memperbaiki kesalahan sintaks umum seperti kekurangan kurung tutup, kekeliruan tanda pemisah, atau penulisan operator perbandingan.

Penutup (±10 menit)

  1. Santri bersama guru menyimpulkan aturan penulisan IF majemuk (tiga kategori memerlukan dua lapis fungsi IF).
  2. Santri melakukan refleksi singkat mengenai ketelitian dalam merangkai logika bertingkat.
  3. Guru memberikan apresiasi atas ketekunan santri, menyampaikan pentingnya amanah ketelitian data, dan menutup pertemuan dengan doa kafaratul majelis serta salam.

Asesmen

1. Soal dan Tugas Singkat

  • Soal 1 (Alur Logika): Sel B2 berisi angka 78. Jika ditulis rumus `=IF(B2>=85; "Mumtaz"; IF(B2>=70; "Jayyid"; "Maqbul"))`, jelaskan langkah evaluasi logika yang terjadi hingga diperoleh predikat!
  • Soal 2 (Penyusunan Formula): Buatlah formula IF majemuk untuk menentukan predikat hafalan santri di sel C3 berdasarkan skor di sel B3 dengan kriteria: skor 90 ke atas "Mumtaz", skor 75 sampai 89 "Jayyid", dan skor di bawah 75 "Maqbul"!

2. Kunci dan Rambu Jawaban

  • Rambu Jawaban Soal 1:
  1. Komputer menguji kondisi pertama: `78 >= 85` bernilai FALSE.
  2. Komputer melanjutkan ke pengujian kedua: `78 >= 70` bernilai TRUE.
  3. Komputer menetapkan hasil dari kondisi benar kedua, yaitu teks "Jayyid".
  • Kunci Jawaban Soal 2:

`=IF(B3>=90; "Mumtaz"; IF(B3>=75; "Jayyid"; "Maqbul"))`

*(Tanda titik koma dapat disesuaikan dengan tanda koma sesuai pengaturan perangkat).*

Media dan Sumber Belajar

  1. Media Belajar: Perangkat komputer/laptop, proyektor/papan tulis, serta lembar kerja/buku catatan berpetak (untuk moda unplugged).
  2. Sumber Belajar: Buku Siswa Informatika Kelas VIII Kurikulum Merdeka, panduan referensi fungsi lembar kerja, dan arsip format daftar nilai santri.

Catatan Refleksi Guru

  • Sejauh mana santri dapat memahami bahwa rentang kondisi kedua (`70 <= B2 < 85`) otomatis terpenuhi tanpa harus menulis rumus ganda?
  • Apakah kesalahan penulisan sintaks lebih banyak bersumber dari pemisah argumen atau kekurangan kurung tutup?
  • Bagaimana efektivitas simulasi unplugged dalam membantu pemahaman logika santri yang belum memegang perangkat komputer?
  • Rencana tindak lanjut: pendampingan terbimbing bagi santri yang belum tuntas, dan pemberian tantangan 4 kategori predikat bagi santri yang telah tuntas.
