Tujuan Pembelajaran

Peserta didik mampu memahami lingkungan pemrograman berbasis teks bahasa Python, mengenali sintaks dasar, fungsi masukan-keluaran (input-print), variabel, tipe data primitif, serta konversi tipe data secara tepat (TP-1).

Materi Pokok

  1. Mengapa Belajar Python: Python merupakan bahasa pemrograman berbasis teks tingkat tinggi yang sintaksisnya menyerupai bahasa Inggris sederhana, ringkas, dan sangat ramah bagi pemula. Di dunia industri dan sains, Python banyak digunakan untuk kecerdasan buatan (AI), analisis data, hingga pengembangan web.
  2. Lingkungan Pengembangan (IDE dan Editor Daring):
  • *Plugged*: Menggunakan editor daring seperti Replit, Programiz Python Online Compiler, Google Colab, atau aplikasi luring seperti VS Code / IDLE Python di laboratorium komputer.
  • *Unplugged*: Menggunakan lembar kertas kerja "Dry Run / Parser Santri" untuk mencatat struktur logika dan baris kode instruksi manual bila fasilitas gawai/komputer terbatas.
  1. Sintaks Dasar dan Aturan Penulisan Baris Kode:
  • Fungsi keluaran dasar: `print()` digunakan untuk menampilkan data/teks ke layar terminal. Teks diapit oleh tanda petik tunggal (`'...'`) atau ganda (`"..."`).
  • Sifat *Case-Sensitive*: Huruf besar dan kecil dibedakan secara ketat. Penulisan `Print()` atau `PRINT()` akan menyebabkan galat (*NameError*).
  • Indentasi (*Indentation*): Penataan spasi pada awal baris menjadi penanda blok kode. Pada baris instruksi mandiri di awal program, tidak boleh ada spasi kosong di paling kiri agar terhindar dari *IndentationError*.
  • Komentar program: Menggunakan tanda pagar (`#`) untuk baris keterangan yang diabaikan oleh penerjemah bahasa (*interpreter*).

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru membuka pertemuan dengan salam, memimpin doa bersama, serta memeriksa kehadiran santri di kelas/laboratorium.
  2. Guru memberikan apersepsi kontekstual santri:
  • "Bayangkan pengurus pondok memberikan maklumat tertulis tentang jadwal ronda malam. Jika bahasa maklumatnya rancu, para santri akan bingung menjalankannya. Begitu pula komputer; komputer membutuhkan bahasa instruksi yang pasti dan terstruktur. Hari ini kita belajar bahasa Python untuk memberi perintah kepada komputer."
  1. Guru menyampaikan tujuan pembelajaran, indikator pencapaian, serta manfaat praktis belajar koding teks bagi santri era digital.
  2. Guru membagi santri ke dalam kelompok berpasangan (*pair programming* / teman sebangku) untuk saling memeriksa ketepatan penulisan kode.

Inti (±40 menit)

Langkah 1: Eksplorasi Konsep dan Lingkungan Editor (10 menit)
  • Santri menyimak penjelasan interaktif guru mengenai antarmuka editor Python daring (area penulisan kode/skrip, tombol *Run*, dan panel konsol hasil eksekusi).
  • Bila moda *unplugged* digunakan, guru membagikan lembar berpetak yang memvisualisasikan "Layar Editor" dan "Layar Monitor Terminal".
  • Guru mendemonstrasikan eksekusi kode perdana:

```python

Program pertamaku di pesantren

print("Bismillah, belajar Python!")

```

  • Santri mengamati bahwa apa yang ditulis di dalam tanda petik akan muncul persis pada layar terminal.
Langkah 2: Praktik Terbimbing dan Eksperimen Sintaks (15 menit)
  • Santri mempraktikkan penulisan beberapa baris teks bertema aktivitas harian santri, misalnya:

```python

print("Jadwal Santri Kelas 9")

print("Kajian Kitab: Ba'da Subuh")

print("Pelajaran Madrasah: Pukul 07.30")

```

  • Guru menantang santri melakukan uji coba kesalahan (*error simulation*):
  1. Menghapus tanda petik penutup pada teks.
  2. Mengganti `print` menjadi `Print`.
  3. Menambahkan 2 spasi kosong di depan kata `print`.
  • Santri mendiskusikan pesan galat yang muncul (*SyntaxError*, *NameError*, *IndentationError*) dan memperbaikinya secara langsung bersama teman sebangku.
Langkah 3: Penerapan Mandiri / Berpasangan (15 menit)
  • Santri menyusun program kartu pengenal digital sederhana yang menampilkan identitas diri dan asrama:
  • Baris 1: Judul biodata santri
  • Baris 2: Nama lengkap
  • Baris 3: Kamar / Asrama pondok
  • Baris 4: Kalimat motivasi belajar
  • Bagi kelompok *unplugged*, santri menuliskan baris kode pada lembar kerja, kemudian menukarkan lembar tersebut kepada rekan di sebelahnya yang bertindak sebagai "mesin pemeriksa (*compiler manusia*)" untuk memvalidasi apakah ada tanda petik atau tanda kurung yang tertinggal.
  • Guru berkeliling memberikan pendampingan, mengamati kerja santri, serta memfasilitasi santri yang masih menemukan kendala penulisan.

Penutup (±10 menit)

  1. Guru mengajak perwakilan santri membacakan atau memperlihatkan program yang berhasil berjalan tanpa galat di depan kelas.
  2. Bersama santri, guru merangkum simpulan pelajaran:
  • Bahasa Python bersifat mudah dibaca namun membutuhkan ketelitian tinggi.
  • Huruf kapital dan tanda petik sangat menentukan keberhasilan eksekusi kode.
  1. Guru memberikan apresiasi atas kesungguhan santri selama praktik.
  2. Guru menyampaikan gambaran materi pekan berikutnya, yaitu mengenalkan variabel dan fungsi masukan (`input()`) untuk membuat program interaktif.
  3. Pembelajaran ditutup dengan doa kafaratul majelis dan salam.

Asesmen

1. Tugas Praktik / Lembar Kerja

Tuliskan dan jalankan program Python berikut:

```python

Tugas Pertemuan 1

print("================================")

print(" SANTRI DIGITAL INDONESIA ")

print("================================")

print("Nama : [Tulis Nama Santri]")

print("Hobi : Membaca & Koding")

print("Cita : Ahli Teknologi Muslim")

print("================================")

```

2. Kunci / Rambu Jawaban

  • Struktur sintaks fungsi `print()` ditulis dengan huruf kecil seluruhnya (`print`).
  • Setiap parameter teks diapit oleh tanda petik tunggal (`'...'`) atau tanda petik ganda (`"..."`) secara konsisten dan berpasangan.
  • Setiap buka kurung `(` diakhiri dengan tutup kurung `)`.
  • Tidak ada spasi tak teratur di awal baris kode (tanpa indentasi liar).
  • Hasil eksekusi pada konsol menampilkan format kartu nama yang rapi sesuai isi string.

*Kriteria Ketercapaian Tujuan Pembelajaran (KKTP):*

  • 0 - 69: Perlu bimbingan remedial dalam mengenali struktur fungsi dan pengetikan tanda baca.
  • 70 - 84: Mencapai ketuntasan, mampu menuliskan dan menjalankan program dasar dengan sedikit asistensi.
  • 85 - 100: Sangat tuntas, mampu menuliskan kode secara mandiri, rapi, dan mampu mendiagnosis jenis galat pengetikan secara mandiri.

  • Materi rangkuman sintaks dasar Python madrasah.

Catatan Refleksi Guru

  • Keterlibatan Santri: Apakah seluruh santri aktif mencoba menuliskan instruksi program dan mengenali pesan kesalahan (*error message*) tanpa rasa takut salah?
  • Kendala Teknis: Apakah sarana gawai, sambungan internet, atau lembar kerja *unplugged* berjalan lancar selama 60 menit?
  • Tindak Lanjut: Bagi santri yang masih sering keliru menuliskan huruf besar pada kata kunci (`Print`) atau lupa menutup tanda kurung, siapkan kartu pengingat sintaks (*syntax cheat-sheet*) saku di pertemuan berikutnya. Santri yang sudah mahir dapat ditugaskan menjadi tutor sebaya bagi rekan yang memerlukan asistensi ekstra.
