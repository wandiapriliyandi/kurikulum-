Tujuan Pembelajaran

  • TP-1: Peserta didik mampu memahami lingkungan pemrograman berbasis teks bahasa Python, mengenali sintaks dasar, fungsi masukan-keluaran (input-print), variabel, tipe data primitif, serta konversi tipe data secara tepat.
  • Indikator Pencapaian:
  1. Mendeklarasikan dan memberi nilai variabel sesuai kaidah penamaan Python.
  2. Membedakan dan menentukan tipe data primitif (integer, float, string, dan boolean) secara tepat pada contoh kasus sehari-hari santri.

Materi Pokok

1. Konsep Variabel

Variabel dalam pemrograman adalah nama atau label yang digunakan untuk merujuk ke lokasi memori komputer yang menyimpan suatu nilai data. Analogi sederhana: variabel ibarat sebuah kotak atau toples di asrama/pesantren yang diberi label nama barang, misalnya toples berlabel "gula" berisi gula pasir atau loker berlabel nama santri yang berisi perlengkapan kitab.

Di Python, pembuatan variabel sangat praktis karena tidak memerlukan deklarasi tipe data secara eksplisit (*dynamic typing*). Variabel langsung tercipta saat pertama kali diberi nilai menggunakan operator penugasan (*assignment*) berupa tanda sama dengan (`=`).

Contoh:

```python

nama_santri = "Ahmad"

jumlah_juz = 5

```

2. Aturan Penamaan Variabel (Identifier Rules di Python)

  • Karakter pertama harus berupa huruf (a-z, A-Z) atau garis bawah (*underscore* `_`). Tidak boleh diawali angka (contoh salah: `1santri`, contoh benar: `santri1` atau `_santri`).
  • Karakter berikutnya dapat berupa huruf, angka, atau garis bawah.
  • Tidak boleh mengandung spasi atau karakter khusus simbol matematika/pungtuasi seperti `-`, `@`, `!`, `#`, `%`, `&`.
  • Bersifat peka huruf besar-kecil (*case-sensitive*): variabel `hafalan`, `Hafalan`, dan `HAFALAN` adalah tiga variabel berbeda.
  • Tidak boleh menggunakan kata kunci bawaan (*reserved keywords*) Python, seperti `for`, `while`, `if`, `True`, `False`, `class`, `import`.
  • Konvensi penamaan yang dianjurkan dalam Python adalah *snake_case* (huruf kecil semua dipisahkan garis bawah), contoh: `uang_saku`, `nomor_kamar`.

3. Tipe Data Primitif Python

Tipe data menentukan jenis nilai yang disimpan dan operasi apa saja yang dapat dilakukan terhadap nilai tersebut:

  1. Integer (`int`): Tipe data bilangan bulat positif, negatif, atau nol tanpa pecahan.
  • Contoh konteks santri: Jumlah kitab yang dipelajari (`jumlah_kitab = 7`), nomor kamar (`kamar = 12`), usia santri (`usia = 14`).
  1. Float (`float`): Tipe data bilangan riil atau desimal yang ditandai dengan tanda titik (`.`) sebagai pemisah desimal.
  • Contoh konteks santri: Nilai rata-rata ujian nahwu (`nilai_rata = 87.5`), berat beras infak santri dalam kilogram (`berat_beras = 2.5`).
  1. String (`str`): Tipe data berupa kumpulan karakter teks yang diapit oleh tanda petik tunggal (`'...'`) atau tanda petik ganda (`"..."`).
  • Contoh konteks santri: Nama santri (`nama = "Fathir"`), nama asrama (`asrama = 'Ibnu Sina'`), judul kitab (`kitab = "Safinah"`).
  1. Boolean (`bool`): Tipe data logika yang hanya memiliki dua kemungkinan nilai kebenaran: `True` (benar) atau `False` (salah). Huruf pertama wajib kapital.
  • Contoh konteks santri: Status kehadiran salat berjamaah (`hadir_jamaah = True`), status izin keluar pondok (`izin_keluar = False`).

Untuk memeriksa tipe data dari sebuah variabel di Python, digunakan fungsi bawaan `type()`, contoh: `print(type(nama_santri))` akan menghasilkan output `<class 'str'>`.

Fase 3: Diskusi dan Konfirmasi (±10 menit)

Penutup (±10 menit)

  1. Rangkuman Bersama: Guru memandu santri menyimpulkan poin-poin utama materi:
  • Variabel adalah wadah penyimpanan nilai di memori komputer.
  • Aturan penamaan: tidak boleh diawali angka, tidak boleh ada spasi, peka huruf besar-kecil.
  • 4 tipe data dasar: `int` (bulat), `float` (desimal), `str` (teks berpetik), `bool` (`True`/`False`).
  1. Kuis Cepat (Check for Understanding): Guru menyebutkan data lisan (contoh: "Nilai rata-rata 8,5", "Kata 'Bismillah'", "Angka 40 hari"), lalu santri serentak menjawab tipe datanya dalam bahasa Python.
  2. Doa & Salam Penutup: Guru memberikan apresiasi atas antusiasme santri, menugaskan santri mengulang bacaan materi, dan menutup pembelajaran dengan membaca doa kafaratul majelis serta salam.

Asesmen

1. Instrumen Tugas / Latihan Singkat

Kerjakan soal berikut pada buku catatan atau editor Python:

  1. Perhatikan lima nama variabel berikut. Tentukan manakah nama variabel yang sah (valid) dan tidak sah (invalid) menurut aturan bahasa Python beserta alasannya:

a. `3_buku_tulis`

b. `uang_saku`

c. `nama lengkap`

d. `total#harga`

e. `_status_hadir`

  1. Tentukan tipe data primitif (`int`, `float`, `str`, atau `bool`) yang paling tepat untuk menyimpan data pesantren berikut:

a. Nama kitab fiqih: `"Fathul Qorib"`

b. Banyaknya bait Alfiyah yang telah dihafal: `350`

c. Suhu ruangan asrama saat malam: `24.5`

d. Keterangan apakah santri sudah mandi: `True`

  1. Tuliskan sebaris kode Python untuk membuat variabel bernama `berat_beras` bernilai `5.0` dan tentukan tipe data variabel tersebut!

2. Kunci / Rambu Jawaban

  1. Validasi nama variabel:
  • a. `3_buku_tulis`: Tidak sah (invalid) — diawali dengan angka.
  • b. `uang_saku`: Sah (valid) — menggunakan huruf dan garis bawah, tanpa spasi.
  • c. `nama lengkap`: Tidak sah (invalid) — mengandung spasi.
  • d. `total#harga`: Tidak sah (invalid) — mengandung karakter khusus `#`.
  • e. `_status_hadir`: Sah (valid) — boleh diawali dengan tanda garis bawah (*underscore*).
  1. Penentuan tipe data:
  • a. `"Fathul Qorib"`: Tipe data `str` (String), karena berupa kumpulan karakter teks di dalam tanda petik.
  • b. `350`: Tipe data `int` (Integer), karena berupa bilangan bulat.
  • c. `24.5`: Tipe data `float`, karena berupa bilangan desimal dengan tanda titik.
  • d. `True`: Tipe data `bool` (Boolean), karena berupa nilai kebenaran logika.
  1. Kode Python:

```python

berat_beras = 5.0

```

Tipe data variabel `berat_beras` adalah `float` (karena memiliki nilai desimal `.0`).

3. Kriteria Ketuntasan

Santri dinyatakan mencapai ketuntasan tujuan pembelajaran apabila memenuhi kriteria berikut:

  • Perlu Bimbingan (0 - 59): Belum mampu membedakan aturan penamaan variabel yang sah serta sering keliru mengenali tipe data string dan integer.
  • Cukup (60 - 74): Mampu mengidentifikasi aturan penamaan variabel, namun masih bingung membedakan antara float dengan integer atau salah menuliskan nilai boolean (misal menulis huruf kecil `true`).
  • Baik (75 - 89): Mampu mengidentifikasi aturan penamaan variabel dengan benar dan menentukan 4 tipe data primitif secara tepat pada kasus santri.
  • Sangat Baik (90 - 100): Mampu mendeklarasikan variabel, menentukan tipe data dengan tepat, memahami fungsi `type()`, serta mampu menganalisis penyebab sintaks eror pada penamaan variabel secara mandiri.
