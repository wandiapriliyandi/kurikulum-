Tujuan Pembelajaran

  • TP-4: Peserta didik mampu mengimplementasikan struktur kontrol perulangan (for dengan range, while, dan perintah break) serta memanfaatkan struktur data koleksi List untuk menyimpan dan mengelola data beruntun.
  • Indikator: Menerapkan struktur perulangan bersyarat while dengan pembaruan kondisi batas yang aman; menggunakan perintah break untuk menghentikan putaran loop saat suatu syarat terpenuhi.

Materi Pokok

Materi pertemuan ke-8 ini mengkaji perulangan bersyarat (while) dan perintah henti seketika (break) menggunakan bahasa Python:

  1. Konsep Perulangan Bersyarat (`while`):
  • Menjalankan blok instruksi secara berulang selama kondisi logika bernilai benar (*True*).
  • Bentuk sintaks dasar:

```python

pencacah = 1

while pencacah <= batas:

instruksi yang diulang

pencacah += 1

```

  • Pengujian kondisi dilakukan di awal putaran. Jika kondisi bernilai salah (*False*), blok perulangan langsung dilewati.
  1. Pencegahan Perulangan Tanpa Henti (*Infinite Loop*):
  • Terjadi bila kondisi `while` terus bernilai *True* dan tak pernah berubah menjadi *False*. Program akan macet (*hang*).
  • Dicegah dengan memperbarui variabel pencacah secara berkala di dalam badan perulangan (misal: `pencacah += 1`).
  1. Perintah Henti Seketika (`break`):
  • Menghentikan paksa perulangan seketika tanpa menunggu kondisi `while` bernilai *False*.
  • Umumnya dipadukan dengan pernyataan `if` untuk menangani kondisi darurat atau sasaran yang tercapai lebih awal.
  1. Konteks Kehidupan Pesantren:
  • Simulasi hitungan dzikir atau putaran thowaf.
  • Pengecekan lampu asrama atau setoran hafalan santri yang dihentikan mendadak saat terjadi kendala tajwid.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru memberi salam, memimpin doa bersama, dan memeriksa presensi santri.
  2. Apersepsi Kontekstual:
  • Guru mengaitkan materi dengan amaliah pesantren:

*"Saat berdzikir tasbih ba'da shalat, kita menghitung 1 hingga 33. Jika santri berdzikir tanpa menghitung di jari, hitungan tak pernah usai (infinite loop). Lalu, bagaimana jika bel pondok berbunyi darurat sehingga dzikir harus disudahi segera? Kita memakai perintah break untuk menghentikan perulangan seketika."*

  1. Penyampaian Tujuan: Guru menjelaskan indikator capaian dan alur aktivitas belajar.
  2. Pembagian Kelompok: Santri berpasangan (*pair programming*) dengan teman sebangku.

Inti (±40 menit)

1. Eksplorasi Konsep (10 menit)
  • Guru mendemonstrasikan kode perulangan di papan tulis atau proyektor:

```python

hitungan = 1

while hitungan <= 5:

print("Dzikir ke-", hitungan)

hitungan += 1

```

  • Guru menjelaskan risiko menghapus baris `hitungan += 1` yang memicu *infinite loop*.
  • Guru mengenalkan fungsi pernyataan `break` di dalam percabangan `if`.
2. Praktik Terbimbing dan Simulasi (15 menit)
  • Aktivitas Plugged (Laboratorium/Komputer):
  • Santri mengetik dan menjalankan kode simulasi setoran hafalan:

```python

ayat = 1

while ayat <= 10:

print(f"Membaca ayat ke-{ayat}")

if ayat == 4:

print("Setoran dihentikan ustadz pada ayat ke-4!")

break

ayat += 1

print("Selesai.")

```

  • Santri mengamati bahwa perulangan berhenti di ayat ke-4 akibat perintah `break`.
  • Aktivitas Unplugged (Tanpa Komputer):
  • Tiga santri memerankan simulasi di depan kelas:
  • Santri 1 sebagai "Pencacah" memegang kartu angka bertahap (1, 2, 3, ...).
  • Santri 2 sebagai "Penguji While" memeriksa apakah angka ≤ 7.
  • Santri 3 sebagai "Penyimak" memegang kartu `BREAK`. Pada angka ke-4, Santri 3 mengangkat kartu `BREAK`, sehingga seluruh santri berhenti membaca.
  • Santri lain mencatat alur penelusuran (*trace table*) di buku catatan.
3. Tantangan Kasus Mandiri (15 menit)
  • Santri menyelesaikan kasus "Pengisian Bak Mandi Asrama":
  • Bak bervolume 10 liter, terisi air 2 liter per detik (`air += 2`).
  • Loop `while air <= 10` berjalan, namun jika pipa bocor di volume 6 liter (`air == 6`), jalankan `break`.
  • Guru berkeliling membimbing santri yang menemui kendala sintaks atau alur logika.

Penutup (±10 menit)

  1. Rangkuman: Perwakilan santri menyimpulkan fungsi `while`, bahaya *infinite loop*, dan kegunaan `break`.
  2. Penguatan: Guru menegaskan kembali pentingnya ketelitian (*itqan*) dalam memperbarui variabel batas perulangan.
  3. Tindak Lanjut: Guru memberikan tugas rumah singkat dan menyampaikan topik pertemuan ke-9 (struktur data List).
  4. Penutup: Pembelajaran ditutup dengan doa kafaratul majelis dan salam.

Asesmen

1. Soal Latihan

Soal 1 (Analisis Alur Kode):

```python

x = 2

while x <= 10:

print(x, end=" ")

if x == 6:

print("[Henti]", end=" ")

break

x += 2

print("Selesai")

```

a. Tuliskan luaran (*output*) program tersebut di layar!

b. Jelaskan fungsi baris `x += 2` dalam mencegah *infinite loop*!

c. Mengapa angka 8 dan 10 tidak dicetak?

Soal 2 (Tugas Kode):

Santri piket menyalakan lampu lorong asrama nomor 1 hingga 8 secara berurutan. Jika lampu nomor 5 korsleting, proses harus langsung dihentikan. Tuliskan program Python menggunakan `while`, variabel `lampu`, dan perintah `break` saat `lampu == 5`!

2. Kunci dan Rambu Jawaban

Kunci Soal 1:

a. Luaran: `2 4 6 [Henti] Selesai`

b. Baris `x += 2` memperbarui nilai pencacah tiap putaran agar mendekati kondisi akhir `x <= 10`. Tanpa baris ini, nilai `x` tetap 2 dan timbul *infinite loop*.

c. Angka 8 dan 10 tidak dicetak karena saat `x` bernilai 6, kondisi `if x == 6` terpenuhi sehingga `break` langsung memutus perulangan.

Kunci Soal 2:

```python

Program Lampu Asrama

lampu = 1

while lampu <= 8:

if lampu == 5:

print(f"Lampu {lampu} rusak! Dihentikan.")

break

print(f"Menyalakan lampu {lampu}")

lampu += 1

print("Piket selesai.")

```

  • Ketercapaian Santri: Apakah seluruh santri memahami peran pembaruan pencacah untuk mencegah *infinite loop*?
