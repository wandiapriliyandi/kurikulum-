Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas10
Semester1
Pertemuan5
FaseFase E
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-2: Menggambar grafik fungsi eksponensial y = a^x dengan a > 1 melalui tabel nilai, menganalisis kurva monoton naik, serta menentukan domain, kodomain, titik potong sumbu Y, dan asimtot datar sumbu X.

Materi Pokok

1. Pengertian Fungsi Eksponensial Basis a > 1

Bentuk umum: f(x) = y = a^x dengan a > 1 (seperti a = 2 atau a = 3) dan x ∈ R. Karena nilai basis a > 1, nilai y selalu membesar seiring bertambahnya x, sehingga fungsi bersifat monoton naik: jika x1 < x2, maka f(x1) < f(x2).

2. Pembuatan Tabel Nilai

Grafik digambar melalui titik bantu x bulat di sekitar nol:

Contoh f(x) = 2^x:

  • x = -3 → y = 2^(-3) = 1/8 → (-3; 0,125)
  • x = -2 → y = 2^(-2) = 1/4 → (-2; 0,25)
  • x = -1 → y = 2^(-1) = 1/2 → (-1; 0,5)
  • x = 0 → y = 2^0 = 1 → (0, 1)
  • x = 1 → y = 2^1 = 2 → (1, 2)
  • x = 2 → y = 2^2 = 4 → (2, 4)
  • x = 3 → y = 2^3 = 8 → (3, 8)

3. Penggambaran Kurva Mulus

Titik-titik koordinat dihubungkan kurva lengkung mulus kontinu (bukan garis patah). Kurva melesat naik dari kiri bawah ke kanan atas.

4. Analisis Karakteristik Grafik

  • Domain (daerah asal): Seluruh bilangan real, x ∈ R.
  • Kodomain / Range: Bilangan real positif, y > 0.
  • Titik potong sumbu Y: Di (0, 1) karena a^0 = 1.
  • Titik potong sumbu X: Tidak ada, nilai a^x tidak pernah bernilai nol.
  • Asimtot datar: Garis y = 0 (sumbu X). Kurva mendekati sumbu X ke arah kiri tanpa memotongnya.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Salam, doa bersama, dan presensi santri.
  2. Apersepsi: Mengingat aturan bilangan berpangkat bulat negatif dan nol.
  3. Drill Cepat (3 Menit):
  • Guru menuliskan 4 soal kilat di papan tulis:
  • 2^3 = ... (Jawaban: 8)
  • 3^(-2) = ... (Jawaban: 1/9)
  • 5^0 = ... (Jawaban: 1)
  • 2^(-3) = ... (Jawaban: 1/8)
  • Santri menjawab lisan serempak dan guru memberi umpan balik langsung.
  1. Orientasi: Menjelaskan tujuan belajar dan contoh kontekstual di pesantren, seperti pelipatgandaan setoran hafalan santri secara istikamah.

Inti (±100 menit)

Fase 1: Eksplorasi Konsep (25 menit)
  1. Guru memperagakan pembuatan tabel nilai f(x) = 2^x di papan tulis.
  2. Guru memplot titik koordinat dan menarik kurva lengkung mulus.
  3. Guru menguraikan titik potong (0, 1), sifat kurva monoton naik, dan garis asimtot datar y = 0.
Fase 2: Pemecahan Masalah Kontekstual Santri (35 menit)
  1. Santri berkelompok dalam halaqah (3-4 orang) berbekal kertas berpetak.
  2. Guru membagikan lembar kerja kontekstual pesantren:
  • Kasus 1 (Rantai Syiar Tadarus Kitab):

Hari ke-0 ada 1 santri perintis. Jumlah santri bertambah tiga kali lipat setiap hari menurut fungsi N(t) = 3^t (t dalam hari). Buat tabel nilai t = -2, -1, 0, 1, 2, 3, gambarkan kurva mulusnya, serta tentukan titik potong sumbu Y dan asimtot datarnya.

  • Kasus 2 (Tabungan Kas Santri):

Perkembangan tabungan santri dimodelkan f(x) = 2^(x+1) (dalam ratus ribu rupiah, x dalam periode). Tentukan nilai f(x) untuk x = -1, 0, 1, 2 dan tentukan titik potong sumbu vertikal saat x = 0.

  1. Guru berkeliling mendampingi kelompok yang membutuhkan bimbingan teknis skala grafik.
Fase 3: Diskusi dan Pembahasan (25 menit)
  1. Perwakilan halaqah menggambar grafik N(t) = 3^t di papan tulis: titik (-2, 1/9), (-1, 1/3), (0, 1), (1, 3), (2, 9), (3, 27), titik potong (0, 1), dan asimtot y = 0.
  2. Guru membandingkan kurva f(x) = 2^x dan N(t) = 3^t: grafik basis 3 lebih curam saat t > 0 karena kenaikan nilainya lebih cepat.
  3. Guru meluruskan kekeliruan seperti menghubungkan titik dengan garis patah atau kurva memotong sumbu X.
Fase 4: Latihan Mandiri (15 menit)
  1. Santri menyelesaikan soal latihan mandiri di buku catatan untuk mengukur ketuntasan individu.

Penutup (±10 menit)

  1. Rangkuman: Guru bersama santri menyimpulkan sifat f(x) = a^x (a > 1): monoton naik, memotong sumbu Y di (0, 1), dan berasimtot y = 0.
  2. Refleksi Singkat: Santri mengaitkan konsep kurva eksponensial dengan buah keistiqamahan menuntut ilmu.
  3. Doa & Penutup: Menyampaikan materi pertemuan berikutnya, membaca doa kafaratul majelis, dan salam.

Asesmen

1. Soal Formatif Individu

  1. Buat tabel nilai fungsi f(x) = 2^x untuk x ∈ {-2, -1, 0, 1, 2, 3}!
  2. Gambarkan kurva mulus f(x) = 2^x pada bidang Kartesius berdasarkan tabel tersebut!
  3. Tentukan domain, range, titik potong sumbu Y, dan asimtot datar dari f(x) = 2^x!
  4. Diketahui g(x) = 4^x. Tentukan nilai g(-1), g(0), g(2), dan jelaskan alasan kurvanya lebih curam dibanding f(x) = 2^x untuk x > 0!
  5. Model santri mahir bertambah menurut K(t) = 2^t. Secara teori, apakah K(t) pernah bernilai 0? Jelaskan kaitannya dengan asimtot datar!

2. Kunci Jawaban dan Rambu Penskoringan

  1. x = -2 → 1/4; x = -1 → 1/2; x = 0 → 1; x = 1 → 2; x = 2 → 4; x = 3 → 8. Titik: (-2, 1/4), (-1, 1/2), (0, 1), (1, 2), (2, 4), (3, 8). (Skor: 20)
  2. Sumbu koordinat terskala rapi, pemetaan titik tepat, kurva mulus kontinu monoton naik tidak menyentuh sumbu X. (Skor: 20)
  3. Domain: {x | x ∈ R}; Range: {y | y > 0, y ∈ R}; Titik potong sumbu Y: (0, 1); Asimtot datar: sumbu X atau garis y = 0. (Skor: 20)
  4. g(-1) = 1/4; g(0) = 1; g(2) = 16. Basis 4 > 2 membuat pertambahan nilai fungsi lebih cepat sehingga grafik lebih tegak. (Skor: 20)
  5. K(t) tidak pernah bernilai 0 karena 2^t selalu positif. Kurva hanya mendekati garis y = 0 tanpa menyentuhnya (asimtot datar). (Skor: 20)
  • Total Skor Maksimal = 100.

3. Kriteria Ketuntasan (KKTP)

  • 85 - 100: Sangat Mahir (Tuntas membuat tabel, kurva mulus, serta analisis sifat dan asimtot grafik).
  • 75 - 84: Mahir (Tuntas membuat tabel dan grafik, memahami konsep asimtot datar).
  • 60 - 74: Cukup (Tabel benar, tetapi grafik patah-patah atau menembus sumbu X).
  • < 60: Perlu Bimbingan (Belum terampil menghitung pangkat negatif dan belum memahami grafik koordinat).

Media dan Sumber Belajar

  • Papan tulis berpetak dan spidol berwarna.
  • Lembar kerja kontekstual santri dan kertas milimeter blok.
  • Kartu angka drill hitung cepat eksponen.
  • Buku Siswa Matematika Kelas X Kurikulum Merdeka (Kemendikbudristek/Kemenag).

Catatan Refleksi Guru

  1. Apakah drill hitung cepat 3 menit di awal efektif menyiapkan pemahaman eksponen negatif santri?
  2. Apakah santri dapat memplot nilai pecahan dan menarik kurva asimtot dengan tepat?
  3. Tindak lanjut: Pendampingan intensif bagi santri yang belum lancar menarik kurva lengkung.
