Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas10
Semester1
Pertemuan6
FaseFase E
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-2: Menggambar kurva fungsi eksponensial monoton turun y = a^x dengan 0 < a < 1 melalui tabel nilai, serta menganalisis pengaruh perubahan basis dan pergeseran vertikal y = a^x + c terhadap posisi grafik dan asimtot datarnya.

Materi Pokok

1. Karakteristik Kurva Basis Pecahan (0 < a < 1)

Bentuk umum: f(x) = y = a^x dengan 0 < a < 1 (misal a = 1/2) dan x ∈ R.

Karakteristik grafik:

  • Monoton Turun: Nilai y mengecil saat x membesar (jika x1 < x2, maka f(x1) > f(x2)).
  • Domain: x ∈ R.
  • Range: y > 0.
  • Titik potong sumbu Y: Di (0, 1) karena a^0 = 1.
  • Asimtot datar: Garis y = 0 (sumbu X). Kurva mendekati sumbu X ke kanan tanpa memotongnya.

Tabel nilai f(x) = (1/2)^x:

  • x = -2 → y = 4 → (-2, 4)
  • x = -1 → y = 2 → (-1, 2)
  • x = 0 → y = 1 → (0, 1)
  • x = 1 → y = 1/2 → (1; 0,5)
  • x = 2 → y = 1/4 → (2; 0,25)

2. Pengaruh Nilai Basis

Perbandingan f(x) = (1/2)^x dan g(x) = (1/3)^x:

  • Keduanya melalui (0, 1) dan monoton turun.
  • Untuk x > 0, kurva g(x) = (1/3)^x turun lebih curam menuju sumbu X karena nilainya mengecil lebih cepat.
  • Untuk x < 0, kurva g(x) = (1/3)^x lebih tinggi karena (1/3)^(-x) = 3^x > 2^x.

3. Pergeseran Vertikal Sederhana (y = a^x + c)

Grafik y = a^x + c diperoleh dengan menggeser kurva y = a^x vertikal:

  • Nilai c > 0 menggeser kurva ke atas sejauh c satuan; c < 0 menggeser ke bawah sejauh |c| satuan.
  • Titik potong sumbu Y bergeser menjadi (0, 1 + c).
  • Asimtot datar berpindah ke garis y = c, dengan range y > c.
  • Contoh: Kurva y = (1/2)^x + 2 memotong sumbu Y di (0, 3) dan berasimtot datar y = 2.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Salam, doa bersama, dan presensi santri.
  2. Apersepsi: Mengingat kembali kurva monoton naik dan aturan pangkat negatif.
  3. Drill Cepat (3 Menit):
  • Guru memberikan 4 soal kilat di papan tulis:
  • (1/2)^(-2) = ... (Jawaban: 4)
  • (1/3)^(-1) = ... (Jawaban: 3)
  • (1/2)^3 = ... (Jawaban: 1/8)
  • (1/2)^0 + 2 = ... (Jawaban: 3)
  • Santri menjawab lisan serempak dan guru memberi umpan balik langsung.
  1. Orientasi: Menyampaikan tujuan belajar dan konteks pesantren, seperti penyusutan sisa logistik poskestren atau aroma wewangian di asrama.

Inti (±100 menit)

Fase 1: Eksplorasi Konsep (25 menit)
  1. Guru membuat tabel nilai f(x) = (1/2)^x untuk x = -2 sampai 2 di papan tulis berpetak.
  2. Guru memplot titik koordinat dan menarik kurva lengkung mulus monoton turun.
  3. Guru mendemonstrasikan y = (1/2)^x + 2: titik dinaikkan 2 satuan, titik potong baru di (0, 3), dan asimtot datar menjadi y = 2.
Fase 2: Pemecahan Masalah Kontekstual Santri (35 menit)
  1. Santri berkelompok dalam halaqah (3-4 orang) berbekal lembar kerja dan kertas berpetak.
  2. Tiap kelompok menyelesaikan dua kasus kontekstual pesantren:
  • Kasus 1 (Persediaan Madu Poskestren):

Sisa madu santri menyusut tiap pekan menurut M(t) = 4 × (1/2)^t (liter, t dalam pekan). Santri membuat tabel nilai t = 0, 1, 2, 3, menggambar kurva, dan menganalisis asimtot datar y = 0.

  • Kasus 2 (Aroma Wewangian Asrama):

Intensitas aroma ruangan dimodelkan f(x) = (1/2)^x + 1 (x dalam hari). Santri menghitung f(x) untuk x = -1, 0, 1, 2, menentukan titik potong sumbu Y, serta asimtot datar y = 1.

  1. Guru berkeliling mendampingi santri dalam skala grafik dan pemetaan pecahan.
Fase 3: Diskusi dan Pembahasan (25 menit)
  1. Perwakilan halaqah menggambar grafik hasil kerjanya di papan tulis.
  2. Guru membandingkan kurva (1/2)^x dan (1/3)^x: basis 1/3 turun lebih curam saat x > 0.
  3. Guru mengoreksi kekeliruan umum, seperti menarik garis patah atau kurva menabrak asimtot.
Fase 4: Latihan Mandiri (15 menit)
  1. Santri menyelesaikan latihan individu di buku catatan untuk mengecek ketuntasan konsep.

Penutup (±10 menit)

  1. Rangkuman: Menyimpulkan fungsi f(x) = a^x (0 < a < 1) monoton turun berasimtot y = 0, serta y = a^x + c berasimtot y = c.
  2. Refleksi: Mengaitkan penyusutan waktu dengan pentingnya istiqamah memanfaatkan masa muda di pesantren.
  3. Doa & Penutup: Doa kafaratul majelis dan salam penutup.

Asesmen

1. Soal Formatif Individu

  1. Lengkapi tabel nilai f(x) = (1/2)^x untuk x ∈ {-2, -1, 0, 1, 2, 3}!
  2. Gambarkan kurva mulus f(x) = (1/2)^x pada bidang Kartesius!
  3. Diketahui g(x) = (1/2)^x + 3. Tentukan titik potong sumbu Y, asimtot datar, dan daerah hasilnya!
  4. Diketahui f(x) = (1/2)^x dan h(x) = (1/4)^x. Bandingkan f(2) dan h(2), lalu tentukan kurva mana yang lebih curam saat x > 0!
  5. Cadangan air tandon asrama dimodelkan H(t) = (1/2)^t + 1 (m³, t dalam hari). Tentukan volume air saat t = 0 dan t = 2, serta jelaskan batas minimum volume berdasarkan asimtot datar!

2. Kunci Jawaban dan Rambu Penskoringan

  1. x = -2 → 4; x = -1 → 2; x = 0 → 1; x = 1 → 1/2; x = 2 → 1/4; x = 3 → 1/8. Monoton turun. (Skor: 20)
  2. Skala rapi, titik tepat, kurva mulus kontinu mendekati sumbu X ke arah kanan tanpa memotongnya. (Skor: 20)
  3. Titik potong sumbu Y di (0, 4) karena (1/2)^0 + 3 = 4. Asimtot datar y = 3. Range: y > 3. (Skor: 20)
  4. f(2) = 1/4 = 0,25 dan h(2) = 1/16 = 0,0625. Kurva h(x) lebih curam mendekati sumbu X karena basis 1/4 < 1/2. (Skor: 20)
  5. H(0) = 2 m³ dan H(2) = 1,25 m³. Batas minimum volume adalah garis asimtot H = 1 m³. (Skor: 20)
  • Total Skor Maksimal = 100.

3. Kriteria Ketuntasan (KKTP)

  • 85 - 100: Sangat Mahir (Tuntas menggambar kurva mulus, analisis monoton turun, dan pergeseran asimtot).
  • 75 - 84: Mahir (Tuntas membuat tabel, kurva mulus, dan menentukan asimtot datar).
  • 60 - 74: Cukup (Tabel benar, kurva kurang rapi atau keliru menentukan nilai asimtot pergeseran).
  • < 60: Perlu Bimbingan (Belum menguasai pangkat pecahan negatif dan grafik).

Media dan Sumber Belajar

  • Papan tulis berpetak, spidol berwarna, dan penggaris.
  • Lembar kerja kontekstual santri dan kertas berpetak / milimeter blok.
  • Kartu soal drill hitung cepat eksponen pecahan.
  • Buku Siswa Matematika Kelas X Kurikulum Merdeka (Kemendikbudristek/Kemenag).

Catatan Refleksi Guru

  1. Apakah drill hitung cepat 3 menit di awal efektif mengaktifkan pemahaman eksponen basis pecahan?
  2. Apakah santri memahami perbedaan pengaruh basis a dan pergeseran konstanta c?
  3. Rencana tindak lanjut: Pendampingan bagi santri yang belum rapi menarik kurva asimtot.
