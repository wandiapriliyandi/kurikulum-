Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas10
Semester2
Pertemuan2
FaseFase E
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-1: Peserta didik mampu menghitung nilai sumbu simetri fungsi kuadrat, menentukan koordinat titik puncak (maksimum atau minimum) parabola, serta membuat sketsa grafik fungsi kuadrat sederhana dalam konteks pemecahan masalah kehidupan sehari-hari santri.

Materi Pokok

  1. Sumbu Simetri Parabola

Parabola f(x) = ax² + bx + c simetris terhadap garis vertikal yang membagi kurva menjadi dua bagian sebangun. Garis ini dirumuskan:

x = -b / (2a)

  1. Titik Puncak (Titik Balik Ekstrim) Parabola

Titik puncak (xp, yp) adalah titik balik atau nilai optimum parabola:

  • Absis puncak: xp = -b / (2a)
  • Ordinat puncak: yp = f(xp) = f(-b / (2a)) atau yp = -(b² - 4ac) / (4a)
  • Karakteristik titik puncak:
  • Jika a > 0, parabola terbuka ke atas dan memiliki titik balik minimum.
  • Jika a < 0, parabola terbuka ke bawah dan memiliki titik balik maksimum.
  1. Sketsa Grafik Fungsi Kuadrat Sederhana

Langkah pembuatan sketsa:

  • Periksa arah kurva dari tanda koefisien a.
  • Tentukan titik potong sumbu y pada (0, c).
  • Tentukan garis sumbu simetri x = -b / (2a).
  • Tentukan koordinat titik puncak (xp, yp).
  • Buat titik simetri dari (0, c), lalu hubungkan titik-titik tersebut menjadi kurva mulus.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru memberi salam islami, menyapa santri, dan memimpin doa menuntut ilmu bersama.
  2. Memeriksa presensi dan kesiapan belajar santri.
  3. Drill Cepat (Latihan Hitung Singkat):

Tanya jawab lisan kilat:

  • Hitung -(-6) / (2 × 1)! (Jawaban: 3)
  • Hitung -8 / (2 × (-2))! (Jawaban: 2)
  • Jika f(x) = -x² + 4x + 1, berapa nilai f(2)? (Jawaban: 5)
  • Sebutkan nilai a dan b dari f(x) = 2x² - 8x + 3! (Jawaban: a = 2, b = -8)
  1. Apersepsi: Guru mengaitkan titik puncak kurva parabola dengan lengkungan semprotan air wudu di kolam masjid asrama saat mencapai titik tertinggi sebelum jatuh ke lantai.
  2. Penyampaian Tujuan: Guru menjelaskan tujuan pembelajaran tentang sumbu simetri, titik puncak parabola, dan pembuatan sketsa grafik sederhana.

Inti (±100 menit)

Langkah 1: Eksplorasi Rumus dan Contoh Hitung (20 menit)
  • Guru menjelaskan rumus sumbu simetri x = -b / (2a) dan titik puncak (xp, yp) menggunakan f(x) = x² - 4x + 3 di papan tulis:
  • Diperoleh a = 1, b = -4, c = 3.
  • Sumbu simetri: xp = -(-4) / (2 × 1) = 2.
  • Nilai puncak: yp = f(2) = (2)² - 4(2) + 3 = -1. Titik puncak adalah (2, -1) (titik minimum karena a > 0).
  • Guru mencontohkan sketsa grafik memakai titik puncak (2, -1), titik potong sumbu y di (0, 3), dan titik simetri (4, 3).
  • Santri mencatat rumus dan langkah pembuatan sketsa di buku catatan.
Langkah 2: Pemecahan Masalah Kontekstual Santri (35 menit)
  • Santri dalam kelompok kecil (3–4 orang) menyelesaikan dua studi kasus pesantren:
  • Kasus 1 (Pancaran Selang Bersih Masjid):

Lintasan air selang saat santri mencuci serambi masjid membentuk fungsi h(t) = -t² + 6t meter (t dalam detik).

Santri menghitung sumbu simetri waktu pancaran, ketinggian air maksimum, dan koordinat titik puncak.

  • Kasus 2 (Laba Koperasi Santri):

Keuntungan harian penjualan peci dirumuskan K(x) = -2x² + 20x - 18 (puluhan ribu rupiah), dengan x jumlah lusin peci terjual.

Santri menghitung sumbu simetri penjualan, keuntungan maksimum, dan koordinat titik puncak.

  • Guru berkeliling membimbing kelompok dan mengecek ketelitian tanda minus.
Langkah 3: Menggambar Sketsa Grafik Parabola (25 menit)
  • Kelompok menggambar sketsa grafik dari kedua kasus pada buku berpetak:
  • Membuat sumbu koordinat tegak dan mendatar.
  • Menarik garis putus-putus sumbu simetri.
  • Meletakkan titik puncak ekstrim dan titik potong sumbu y.
  • Menghubungkan titik-titik tersebut membentuk parabola mulus.
  • Santri mendiskusikan arti fisik titik puncak sebagai capaian maksimum semprotan air dan laba koperasi.
Langkah 4: Diskusi Kelas dan Penguatan Konsep (20 menit)
  • Dua perwakilan kelompok menuliskan jawaban di papan tulis:
  • Kasus 1: Sumbu simetri t = 3 detik, tinggi maksimum h(3) = 9 meter, titik puncak (3, 9).
  • Kasus 2: Sumbu simetri x = 5 lusin, laba puncak K(5) = 32 (Rp320.000), titik puncak (5, 32).
  • Guru mengonfirmasi hasil hitungan, meluruskan kesalahan penulisan minus bilangan kuadrat, serta memberi penguatan materi.

Penutup (±10 menit)

  1. Guru bersama santri menyimpulkan rumus sumbu simetri x = -b / (2a) dan koordinat puncak (xp, yp).
  2. Santri merefleksikan pemahaman materi baru yang diperoleh.
  3. Guru memberikan tugas mandiri untuk dikerjakan di asrama.
  4. Menutup pembelajaran dengan hamdalah dan doa kafaratul majelis bersama.

Asesmen

1. Soal Latihan Mandiri

  1. Tentukan sumbu simetri, koordinat titik puncak, dan jenis titik balik dari f(x) = x² - 6x + 8!
  2. Diketahui kurva g(x) = -2x² + 8x - 3.

a. Tentukan persamaan sumbu simetrinya!

b. Tentukan koordinat titik puncak parabola!

c. Buatlah sketsa grafik kurva tersebut secara sederhana!

  1. Roket air santri meluncur vertikal dengan rumus h(t) = -5t² + 20t + 2 meter (t dalam detik).

a. Pada detik ke berapa roket mencapai titik puncak?

b. Berapa tinggi maksimum yang dicapai roket tersebut?

2. Kunci dan Rambu Jawaban

  1. f(x) = x² - 6x + 8 (a = 1, b = -6, c = 8):
  • Sumbu simetri: x = -(-6) / (2 × 1) = 3.
  • Nilai puncak: yp = f(3) = 9 - 18 + 8 = -1. Titik puncak (3, -1) adalah titik balik minimum (a > 0).
  1. g(x) = -2x² + 8x - 3 (a = -2, b = 8, c = -3):
  • a. Sumbu simetri: x = -8 / (2 × (-2)) = 2.
  • b. Nilai puncak: yp = g(2) = -8 + 16 - 3 = 5. Titik puncak (2, 5) adalah titik maksimum (a < 0).
  • c. Sketsa grafik: Garis sumbu simetri x = 2 putus-putus, puncak di (2, 5), titik potong sumbu y di (0, -3), kurva terbuka ke bawah melalui titik simetri (4, -3).
  1. h(t) = -5t² + 20t + 2 (a = -5, b = 20, c = 2):
  • a. Waktu puncak: t = -20 / (2 × (-5)) = 2 detik.
  • b. Tinggi maksimum: h(2) = -20 + 40 + 2 = 22 meter.

3. Kriteria Ketuntasan

  • Bobot Skor: Soal 1 = 30 poin, Soal 2 = 40 poin, Soal 3 = 30 poin (Total nilai 0–100).
  • Rentang Nilai:
  • 80–100: Sangat Mahir (tuntas mandiri dan mampu membimbing santri lain).
  • 70–79: Mahir (tuntas, menguasai langkah hitung sumbu simetri dan titik puncak).
  • 60–69: Cukup (perlu latihan ketelitian tanda negatif).
  • < 60: Perlu Remedial (bimbingan khusus perkalian dan pembagian bilangan bulat bertanda).

  • Penggaris dan spidol warna.
  • Lembar Masalah Kontekstual Pesantren (pancaran selang air dan koperasi santri).

Catatan Refleksi Guru

  • Ketercapaian Konsep: Santri dapat menerapkan rumus x = -b / (2a) dan mencari ordinat puncak secara mandiri.
  • Kendala Teknis: Masih ada beberapa santri yang perlu diingatkan agar tidak keliru dalam tanda kurung kuadrat bertanda negatif.
  • Antusiasme Santri: Pemakaian contoh kontekstual santri membuat pembelajaran lebih hidup dan aplikatif.
  • Tindak Lanjut: Memberikan klinik belajar singkat ba'da maghrib bagi santri yang membutuhkan penguatan berhitung dasar.
