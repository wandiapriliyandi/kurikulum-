Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas10
Semester2
Pertemuan3
FaseFase E
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-2: Peserta didik mampu menghitung nilai diskriminan dari fungsi kuadrat serta menentukan banyak titik potong grafik parabola terhadap sumbu X berdasarkan nilai diskriminan.

Materi Pokok

  1. Konsep Diskriminan

Fungsi kuadrat memiliki bentuk umum f(x) = ax² + bx + c dengan a ≠ 0. Nilai diskriminan dihitung dengan rumus:

D = b² - 4ac

Keterangan: a koefisien x², b koefisien x, dan c konstanta.

  1. Hubungan Nilai Diskriminan dan Titik Potong Sumbu X

Titik potong grafik terhadap sumbu X terjadi saat f(x) = 0. Karakteristik nilai D menentukan banyak titik potong kurva parabola terhadap sumbu X:

  • D > 0: Parabola memotong sumbu X di dua titik berbeda.
  • D = 0: Parabola menyinggung sumbu X di satu titik.
  • D < 0: Parabola tidak memotong maupun menyinggung sumbu X.
  1. Makna Geometris dalam Konteks Sehari-Hari

Pada lintasan melengkung (seperti pancuran air atau tali jemuran) terhadap garis tanah atau permukaan air:

  • D > 0 berarti kurva menyentuh garis acuan dua kali.
  • D = 0 berarti kurva tepat menyentuh garis acuan satu kali di puncaknya.
  • D < 0 berarti kurva melayang di atas atau di bawah garis acuan tanpa pernah menyentuhnya.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru memberi salam, memeriksa kerapian kelas, dan memimpin doa bersama santri.
  2. Memeriksa presensi santri dan kesiapan belajar.
  3. Drill Cepat (Latihan Hitung Singkat):

Tanya jawab lisan kilat melatih kecepatan hitung kuadrat dan perkalian:

  • 6² = ? (Jawaban: 36)
  • (-5)² = ? (Jawaban: 25)
  • 4 × 2 × 3 = ? (Jawaban: 24)
  • 4 × (-1) × (-4) = ? (Jawaban: 16)
  • 25 - 4(1)(6) = ? (Jawaban: 1)
  1. Apersepsi: Guru mengaitkan materi dengan lengkungan air kolam wudu di pondok: kapan air memotong permukaan bak dua kali atau tidak menyentuh sama sekali.
  2. Guru menyampaikan tujuan pembelajaran mengenai perhitungan nilai D dan penentuan banyak titik potong grafik terhadap sumbu X.

Inti (±100 menit)

Langkah 1: Eksplorasi Rumus Diskriminan (20 menit)
  • Guru menjelaskan rumus D = b² - 4ac di papan tulis dan memaparkan contoh perhitungan:

1) f(x) = x² - 6x + 8 -> a = 1, b = -6, c = 8.

D = (-6)² - 4(1)(8) = 36 - 32 = 4 (D > 0, memotong di dua titik).

2) g(x) = x² - 4x + 4 -> a = 1, b = -4, c = 4.

D = (-4)² - 4(1)(4) = 16 - 16 = 0 (D = 0, menyinggung di satu titik).

3) h(x) = x² - 2x + 5 -> a = 1, b = -2, c = 5.

D = (-2)² - 4(1)(5) = 4 - 20 = -16 (D < 0, tidak memotong sumbu X).

  • Santri berlatih mandiri menentukan koefisien dan menghitung nilai D pada buku tulis.
Langkah 2: Analisis Geometris Kurva Parabola (25 menit)
  • Santri duduk berpasangan dalam halaqah belajar.
  • Santri membandingkan bentuk sketsa grafik dari ketiga fungsi yang telah dihitung nilai D-nya.
  • Santri membuktikan bahwa nilai D secara akurat menentukan banyak perpotongan kurva terhadap sumbu X tanpa harus membuat tabel titik koordinat yang rumit.
Langkah 3: Pemecahan Masalah Kontekstual Kehidupan Santri (35 menit)
  • Santri dalam kelompok memecahkan persoalan kontekstual lingkungan pesantren:
  • Masalah 1 (Pancuran Kolam Wudu Pesantren):

Lintasan air wudu dimodelkan h(x) = -x² + 4x - 3 (dalam meter). Permukaan bibir kolam adalah garis h = 0.

Santri menghitung a = -1, b = 4, c = -3, lalu mencari nilai D = 4² - 4(-1)(-3) = 16 - 12 = 4. Karena D > 0, air melintasi bibir kolam di dua titik berbeda (saat memancar keluar dan saat jatuh ke bak).

  • Masalah 2 (Lampu Panggung Haflah Akhirussanah):

Untaian kabel lampu panggung dimodelkan k(x) = x² - 6x + 9 terhadap lantai panggung (k = 0).

Santri menghitung D = (-6)² - 4(1)(9) = 36 - 36 = 0. Karena D = 0, lengkungan kabel tepat menyinggung permukaan lantai panggung di satu titik.

  • Masalah 3 (Tali Jemuran Santri):

Tali jemuran sarung dimodelkan j(x) = x² - 2x + 3 terhadap tanah (j = 0).

Santri menghitung D = (-2)² - 4(1)(3) = 4 - 12 = -8. Karena D < 0, kain jemuran menggantung aman tanpa menyentuh permukaan tanah.

  • Guru berkeliling mendampingi santri dan mengarahkan diskusi pemecahan masalah.
Langkah 4: Diskusi Pleno dan Pembahasan (20 menit)
  • Perwakilan kelompok memaparkan penyelesaian ketiga masalah kontekstual di papan tulis.
  • Kelompok menjelaskan kaitan antara tanda nilai D dengan posisi fisik semburan air wudu, lampu panggung, dan jemuran sarung.
  • Guru mengonfirmasi ketepatan jawaban dan memberikan apresiasi atas kerja sama santri.

Penutup (±10 menit)

  1. Rangkuman: Guru bersama santri menyimpulkan: D > 0 memotong di dua titik, D = 0 menyinggung di satu titik, D < 0 tidak memotong sumbu X.
  2. Refleksi: Santri mengutarakan kemudahan menentukan titik potong kurva menggunakan diskriminan.
  3. Tindak Lanjut: Pemberian tugas mandiri untuk dikerjakan santri di asrama.
  4. Doa Penutup: Mengakhiri kegiatan belajar dengan membaca hamdalah dan doa kafaratul majelis.

Asesmen

1. Soal Latihan Mandiri

  1. Tentukan nilai diskriminan dan banyak titik potong sumbu X dari fungsi kuadrat berikut:

a. f(x) = x² - 5x + 6

b. g(x) = 4x² - 12x + 9

c. h(x) = 2x² - 3x + 5

  1. Dalam kerja bakti pondok, lemparan air selang pembersih halaman dimodelkan h(t) = -t² + 6t - 10 terhadap garis pagar asrama (h = 0).

a. Hitung nilai diskriminan D dari lintasan tersebut!

b. Berdasarkan nilai D, apakah semprotan air mengenai atau melintasi pagar asrama? Jelaskan alasan geometrisnya!

2. Kunci dan Rambu Jawaban

  1. a. a = 1, b = -5, c = 6. D = (-5)² - 4(1)(6) = 25 - 24 = 1. Karena D > 0, memotong sumbu X di dua titik berbeda.

b. a = 4, b = -12, c = 9. D = (-12)² - 4(4)(9) = 144 - 144 = 0. Karena D = 0, menyinggung sumbu X di satu titik.

c. a = 2, b = -3, c = 5. D = (-3)² - 4(2)(5) = 9 - 40 = -31. Karena D < 0, tidak memotong sumbu X.

  1. a. a = -1, b = 6, c = -10. D = 6² - 4(-1)(-10) = 36 - 40 = -4.

b. Karena D = -4 (D < 0) dan a = -1 (kurva membuka ke bawah), kurva berada di bawah garis h = 0 dan tidak pernah memotong atau menyentuh garis pagar asrama.

Pedoman Ketercapaian:

  • Skor 0 - 69: Belum tuntas, memerlukan remedial hitung b² - 4ac.
  • Skor 70 - 84: Tuntas, mampu menentukan diskriminan dan posisi titik potong.
  • Skor 85 - 100: Sangat tuntas, mampu menganalisis konteks masalah secara menyeluruh.

Media dan Sumber Belajar

  2. Alat Kontekstual: Selang air, tali jemuran lingkungan asrama santri.
