Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas10
Semester2 (Genap)
PertemuanKe-4
FaseFase E
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-2: Santri mampu menjelaskan syarat aljabar dan geometris definit positif dan definit negatif, serta membuktikan kondisi definit suatu fungsi kuadrat melalui tanda koefisien a dan diskriminan D.

Materi Pokok

1. Konsep Keterbukaan Parabola dan Nilai Ekstrim

Bentuk umum fungsi kuadrat adalah:

f(x) = ax² + bx + c, dengan a ≠ 0.

Grafik fungsi kuadrat berbentuk parabola. Karakteristik geometris kurva dipengaruhi oleh dua komponen utama:

  • Tanda koefisien a:
  • Jika a > 0, kurva terbuka ke atas sehingga memiliki titik puncak minimum.
  • Jika a < 0, kurva terbuka ke bawah sehingga memiliki titik puncak maksimum.
  • Nilai Diskriminan (D = b² - 4ac):
  • D > 0: Kurva memotong sumbu X di dua titik berbeda (memiliki dua akar riil berbeda).
  • D = 0: Kurva menyinggung sumbu X di satu titik (memiliki satu akar riil kembar).
  • D < 0: Kurva tidak memotong maupun menyinggung sumbu X (tidak memiliki akar riil).

2. Definit Positif

  • Makna Geometris: Seluruh kurva parabola berada di atas sumbu X. Artinya, untuk setiap nilai x bilangan riil, nilai f(x) selalu bernilai positif (f(x) > 0).
  • Syarat Aljabar:
  1. a > 0 (kurva terbuka ke atas).
  2. D < 0 (kurva tidak menyentuh sumbu X, b² - 4ac < 0).

3. Definit Negatif

  • Makna Geometris: Seluruh kurva parabola berada di bawah sumbu X. Artinya, untuk setiap nilai x bilangan riil, nilai f(x) selalu bernilai negatif (f(x) < 0).
  • Syarat Aljabar:
  1. a < 0 (kurva terbuka ke bawah).
  2. D < 0 (kurva tidak menyentuh sumbu X, b² - 4ac < 0).

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan dan Doa: Guru membuka pertemuan dengan salam, memeriksa kehadiran santri, dan memimpin doa sebelum belajar.
  2. Apersepsi dan Motivasi: Guru mengingatkan kembali bentuk umum fungsi kuadrat dan rumus diskriminan D = b² - 4ac yang telah dipelajari pada pertemuan sebelumnya.
  3. Drill Cepat (Latihan Berhitung Singkat):
  • Guru memberikan 3 soal lisan/papan tulis cepat untuk menghitung nilai diskriminan dan menentukan arah kurva:
  • Soal 1: f(x) = x² + 2x + 3. (Santri menjawab serentak: a = 1 > 0, D = 2² - 4(1)(3) = 4 - 12 = -8 < 0).
  • Soal 2: f(x) = -2x² + 4x - 5. (Santri menjawab: a = -2 < 0, D = 16 - 4(-2)(-5) = 16 - 40 = -24 < 0).
  • Soal 3: f(x) = x² - 4x + 4. (Santri menjawab: a = 1 > 0, D = 16 - 16 = 0).
  • Waktu drill: maksimal 4 menit.
  1. Penyampaian Tujuan: Guru menjelaskan bahwa pertemuan ini bertujuan mengidentifikasi kondisi fungsi kuadrat yang selalu bernilai positif (definit positif) atau selalu negatif (definit negatif).

Inti (±100 menit)

Tahap 1: Eksplorasi Konseptual (25 menit)
  1. Guru menggambar sketsa 6 kemungkinan grafik fungsi kuadrat pada koordinat Cartesius berdasarkan kombinasi tanda a (a > 0 atau a < 0) dan tanda D (D > 0, D = 0, D < 0).
  2. Guru memandu santri mengamati kasus khusus saat D < 0:
  • Jika a > 0 dan D < 0, posisi grafik melayang sepenuhnya di atas sumbu X. Nilai fungsi tidak pernah nol dan tidak pernah negatif. Istilah ini dinamakan definit positif.
  • Jika a < 0 dan D < 0, posisi grafik tenggelam sepenuhnya di bawah sumbu X. Nilai fungsi tidak pernah nol dan selalu negatif. Istilah ini dinamakan definit negatif.
  1. Santri mencatat kesimpulan syarat aljabar di buku catatan berhitung masing-masing.
Tahap 2: Pemecahan Masalah Kontekstual Kehidupan Santri (35 menit)

Guru menyajikan lembar kasus kontekstual lingkungan pesantren:

  • Kasus 1: Saldo Koperasi Pesantren

Pengurus santri bagian bendahara koperasi mencatat laju fluktuasi laba harian kantron santri (dalam puluhan ribu rupiah) dirumuskan oleh fungsi:

L(t) = 2t² - 4t + 7, dengan t menyatakan hari ke-t.

Bendahara ingin memastikan apakah koperasi tersebut dijamin selalu membukukan laba positif setiap harinya tanpa pernah mengalami kerugian (L(t) > 0 untuk semua t).

  • *Langkah santri*:
  • Mengidentifikasi koefisien: a = 2, b = -4, c = 7.
  • Menguji tanda a: a = 2 > 0 (kurva terbuka ke atas).
  • Menghitung diskriminan: D = (-4)² - 4(2)(7) = 16 - 56 = -40.
  • Karena D = -40 < 0 dan a > 0, maka fungsi L(t) bersifat definit positif.
  • *Kesimpulan santri*: Koperasi dipastikan selalu berlaba positif setiap hari, minimal bernilai 5 (yaitu saat t = 1, L(1) = 2 - 4 + 7 = 5).
  • Kasus 2: Efisiensi Suhu Pendingin Dapur Pesantren

Untuk menjaga kesegaran bahan makanan santri, alat pengatur suhu ruangan penyimpanan mencatat simpangan temperatur terhadap standar aman dengan model:

S(x) = -x² + 6x - 11, dengan x adalah setelan daya (1 sampai 5).

Pengurus santri ingin membuktikan bahwa suhu ruangan penyimpanan tersebut selalu berada di bawah ambang batas kritis (selalu bernilai negatif, S(x) < 0).

  • *Langkah santri*:
  • Koefisien: a = -1, b = 6, c = -11.
  • Tanda a: a = -1 < 0 (kurva terbuka ke bawah).
  • Diskriminan: D = 6² - 4(-1)(-11) = 36 - 44 = -8.
  • Karena a < 0 dan D < 0, fungsi S(x) definit negatif (selalu bernilai negatif).
  • *Kesimpulan santri*: Sistem terbukti selalu bekerja di bawah batas kritis.
Tahap 3: Kerja Kelompok & Pembuktian Parameter (25 menit)
  1. Santri dibagi berpasangan dengan teman sebangku (halaqah kecil).
  2. Diberikan soal tantangan penentuan nilai parameter p:

"Tentukan batas nilai p agar fungsi kuadrat f(x) = (p - 1)x² + 4x + (p + 2) berstatus definit positif!"

  1. Setiap kelompok mendiskusikan langkah penyelesaian:
  • Syarat 1: a > 0 => p - 1 > 0 => p > 1.
  • Syarat 2: D < 0 => b² - 4ac < 0

4² - 4(p - 1)(p + 2) < 0

16 - 4(p² + p - 2) < 0

Bagi kedua ruas dengan 4:

4 - (p² + p - 2) < 0

4 - p² - p + 2 < 0

-p² - p + 6 < 0

Kalikan -1 (tanda pertidaksamaan berbalik):

p² + p - 6 > 0

(p + 3)(p - 2) > 0

Pembuat nol: p = -3 atau p = 2.

Uji tanda: p < -3 atau p > 2.

  • Irisan syarat 1 (p > 1) dan syarat 2 (p < -3 atau p > 2):

Hasil irisan adalah p > 2.

  1. Guru berkeliling memberi bimbingan dan memeriksa ketelitian hitung santri.
Tahap 4: Presentasi dan Penguatan (15 menit)
  1. Dua perwakilan santri menuliskan jawabannya di papan tulis dan menjelaskan alur pembuktian.
  2. Guru memberikan penguatan, membetulkan kesalahan tanda atau kekeliruan perkalian aljabar.

Penutup (±10 menit)

  1. Rangkuman Bersama: Guru bersama santri menyimpulkan intisari materi:
  • Definit positif: a > 0 dan D < 0 (seluruh kurva di atas sumbu X).
  • Definit negatif: a < 0 dan D < 0 (seluruh kurva di bawah sumbu X).
  • Nilai D < 0 adalah syarat mutlak agar kurva tidak pernah menyentuh sumbu X.
  1. Refleksi Santri: Guru menanyakan santri bagian mana yang paling menantang (biasanya saat mencari irisan pertidaksamaan kuadrat pada parameter).
  2. Tindak Lanjut & Doa Penutup: Guru memberikan 1 soal pekerjaan rumah (PR), mengingatkan santri untuk menjaga ketelitian berhitung, dan menutup majelis dengan doa kafaratul majelis serta salam.

Asesmen

1. Soal Latihan Mandiri (Tes Tertulis Singkat)

  1. Buktikan apakah fungsi f(x) = 3x² - 6x + 5 merupakan fungsi definit positif, definit negatif, atau tidak keduanya!
  2. Diketahui g(x) = -2x² + 4x - 6. Tunjukkan bahwa nilai g(x) selalu negatif untuk setiap x bilangan riil!
  3. Tentukan batas nilai k agar fungsi f(x) = x² + (k - 2)x + 9 bersifat definit positif!

2. Kunci dan Rambu Jawaban

  1. Penyelesaian Soal 1:
  • a = 3, b = -6, c = 5.
  • a = 3 > 0.
  • D = b² - 4ac = (-6)² - 4(3)(5) = 36 - 60 = -24.
  • Karena a > 0 dan D < 0, terbukti f(x) adalah definit positif.

*(Skor: 30)*

  1. Penyelesaian Soal 2:
  • a = -2, b = 4, c = -6.
  • a = -2 < 0.
  • D = b² - 4ac = (4)² - 4(-2)(-6) = 16 - 48 = -32.
  • Karena a < 0 dan D < 0, terbukti g(x) bernilai definit negatif (selalu bernilai negatif).

*(Skor: 30)*

  1. Penyelesaian Soal 3:
  • a = 1, b = k - 2, c = 9.
  • Syarat 1: a > 0 (1 > 0, sudah terpenuhi).
  • Syarat 2: D < 0

(k - 2)² - 4(1)(9) < 0

k² - 4k + 4 - 36 < 0

k² - 4k - 32 < 0

(k - 8)(k + 4) < 0

Pembuat nol: k = 8 dan k = -4.

Karena tanda pertidaksamaan lebih kecil dari nol (< 0), maka daerah penyelesaiannya berada di antara kedua akar:

-4 < k < 8.

  • Jadi batas nilai k adalah -4 < k < 8.

*(Skor: 40)*

3. Kriteria Ketuntasan

  • Total Skor Maksimal: 100
  • Kategori Ketuntasan:
  • 85 - 100 : Sangat Mahir (tuntas mandiri, mampu menyelesaikan pembuktian parameter).
  • 70 - 84 : Mahir / Tuntas (memahami konsep dasar dan perhitungan diskriminan dengan benar).
  • 0 - 69 : Perlu Bimbingan (remedial pada pemfaktoran aljabar dan perhitungan tanda bilangan bulat).
