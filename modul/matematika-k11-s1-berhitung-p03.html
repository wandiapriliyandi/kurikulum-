Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas11
Semester1
Pertemuan3
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-1: Menghitung nilai fungsi komposisi pada titik tertentu serta menentukan nilai variabel input x jika nilai komposisi fungsi diketahui secara cermat.

Materi Pokok

Komposisi dua fungsi menggabungkan dua aturan pemetaan secara berurutan:

  1. Definisi Komposisi:
  • (f ∘ g)(x) = f(g(x)): input x diproses oleh g terlebih dahulu, hasilnya disubstitusikan ke f.
  • (g ∘ f)(x) = g(f(x)): input x diproses oleh f terlebih dahulu, hasilnya disubstitusikan ke g.
  1. Evaluasi Nilai Numerik pada Titik Tertentu:
  • Untuk menghitung (f ∘ g)(a), hitung nilai k = g(a), lalu cari f(k).
  1. Penentuan Nilai Prapeta (Input x):
  • Jika (f ∘ g)(x) = c, tentukan nilai x dengan menyelesaikan persamaan aljabar bertahap atau merumuskan (f ∘ g)(x) terlebih dahulu lalu menyamakan hasilnya dengan c.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru membuka kelas dengan salam, menanyakan kabar santri, memimpin doa, dan memeriksa presensi.
  2. Guru mengadakan drill cepat (hitung singkat) selama 4 menit di papan tulis:
  • Hitung f(3) jika f(x) = 2x + 5 (Jawaban: 11).
  • Hitung g(4) jika g(x) = x² - 6 (Jawaban: 10).
  • Hitung 3 × (2 × 4 - 3) (Jawaban: 15).

Santri menulis jawaban secara cepat di buku catatan buram.

  1. Guru mengaitkan konsep fungsi komposisi dengan alur bertahap kegiatan pesantren (seperti infaq dari penjualan kantin/koperasi) dan menyampaikan tujuan pembelajaran.

Inti (±100 menit)

Tahap 1: Pemodelan Konsep (±20 menit)
  1. Guru mendemonstrasikan evaluasi fungsi komposisi pada titik tertentu:
  • Diketahui f(x) = 3x - 4 dan g(x) = x² + 2.
  • (f ∘ g)(3) = f(g(3)). Nilai g(3) = 3² + 2 = 11. Maka f(11) = 3(11) - 4 = 29.
  • (g ∘ f)(3) = g(f(3)). Nilai f(3) = 3(3) - 4 = 5. Maka g(5) = 5² + 2 = 27.
  1. Guru menjelaskan cara menentukan nilai prapeta x:
  • Diketahui f(x) = 2x + 1 dan g(x) = 4x - 3. Jika (f ∘ g)(x) = 19, tentukan x.
  • (f ∘ g)(x) = 2(4x - 3) + 1 = 8x - 5.
  • Persamaan: 8x - 5 = 19 -> 8x = 24 -> x = 3.
Tahap 2: Pemecahan Masalah Terbimbing Kontekstual Santri (±25 menit)
  1. Guru menyajikan masalah koperasi pondok pesantren:
  • Pendapatan harian koperasi dinyatakan oleh R(x) = 5x + 2 (ratusan ribu rupiah, x = puluhan transaksi).
  • Alokasi dana kas sosial/infaq santri dinyatakan oleh S(R) = 2R - 1 (ratusan ribu rupiah).
  • Masalah A: Jika terjadi 40 transaksi (x = 4), hitung alokasi infaq (S ∘ R)(4).

Langkah: R(4) = 5(4) + 2 = 22. (S ∘ R)(4) = S(22) = 2(22) - 1 = 43 (Rp 4.300.000).

  • Masalah B: Jika infaq terkumpul Rp 4.900.000 (S = 49), tentukan banyak transaksi (x).

Langkah: 2(5x + 2) - 1 = 49 -> 10x + 3 = 49 -> 10x = 46 -> x = 4,6 (46 transaksi).

  1. Santri mengerjakan bersama teman sebangku dan mendiskusikan hasilnya dengan bimbingan guru.
Tahap 3: Kerja Kelompok Kontekstual Dapur Pesantren (±35 menit)
  1. Santri berkelompok (3-4 orang sesuai halaqah asrama).
  2. Santri menyelesaikan studi kasus logistik beras dapur umum pondok:
  • Perendaman beras menghasilkan massa beras basah B(x) = 1,2x + 1 (x = massa beras kering dalam kg).
  • Penanakan menghasilkan massa nasi matang N(B) = 2,5B - 0,5 (kg).
  • Tugas:
  • Hitung massa nasi matang jika beras kering mula-mula 50 kg, yaitu (N ∘ B)(50).
  • Jika kebutuhan buka puasa bersama santri adalah 372 kg nasi matang, tentukan beras kering x yang dibutuhkan.
  1. Guru berkeliling memberikan arahan dan membimbing kelompok yang memerlukan bantuan.
Tahap 4: Pembahasan dan Verifikasi (±20 menit)
  1. Dua kelompok menyajikan langkah penyelesaian di papan tulis:
  • B(50) = 1,2(50) + 1 = 61 kg; N(61) = 2,5(61) - 0,5 = 152 kg.
  • 2,5(1,2x + 1) - 0,5 = 372 -> 3x + 2,5 - 0,5 = 372 -> 3x + 2 = 372 -> 3x = 370 -> x = 123,33 kg.
  1. Santri menyamakan persepsi dan memeriksa ketepatan operasi aljabar masing-masing.

Penutup (±10 menit)

  1. Santri bersama guru menyimpulkan inti materi tentang alur evaluasi numerik fungsi dan cara mencari prapeta x.
  2. Guru memberikan umpan balik, menyampaikan tugas latihan mandiri di kamar santri, dan menutup pelajaran dengan doa kaffaratul majelis serta salam.

Asesmen

1. Soal Evaluasi Individu

  1. Diketahui f(x) = 4x - 7 dan g(x) = x² - 3x + 5. Tentukan:

a. (f ∘ g)(2)

b. (g ∘ f)(2)

  1. Diketahui f(x) = 5x + 3 dan g(x) = 2x - 1. Jika (f ∘ g)(x) = 48, tentukan nilai variabel x.
  2. Pemesanan galon air minum asrama santri: Biaya beli P(x) = 20.000x + 5.000 (rupiah, x = jumlah galon). Biaya total setelah distribusi D(P) = P + 15.000 (rupiah).

a. Hitung total biaya untuk pembelian 10 galon air minum, (D ∘ P)(10).

b. Jika total biaya yang dibayar bendahara asrama adalah Rp 420.000, tentukan banyak galon x yang dibeli.

2. Rambu Jawaban dan Penskoran

  1. Soal 1:

a. g(2) = 2² - 3(2) + 5 = 3. Maka (f ∘ g)(2) = f(3) = 4(3) - 7 = 5. (Skor: 15)

b. f(2) = 4(2) - 7 = 1. Maka (g ∘ f)(2) = g(1) = 1² - 3(1) + 5 = 3. (Skor: 15)

  1. Soal 2:

(f ∘ g)(x) = f(2x - 1) = 5(2x - 1) + 3 = 10x - 2.

10x - 2 = 48 -> 10x = 50 -> x = 5. (Skor: 30)

  1. Soal 3:

a. P(10) = 20.000(10) + 5.000 = 205.000 rupiah.

(D ∘ P)(10) = 205.000 + 15.000 = 220.000 rupiah. (Skor: 20)

b. (D ∘ P)(x) = 20.000x + 20.000 = 420.000.

20.000x = 400.000 -> x = 20 galon. (Skor: 20)

Total Skor = 100.

3. Kriteria Ketuntasan

  • Santri dinyatakan tuntas apabila mencapai nilai Kriteria Ketuntasan Tujuan Pembelajaran (KKTP) minimal 75.
  • Santri dengan nilai di bawah 75 mengikuti bimbingan remedial pada operasi substitusi dan persamaan linear satu variabel. Santri dengan nilai minimal 85 menerima tugas pengayaan berupa komposisi tiga fungsi berantai.

Catatan Refleksi Guru

  1. Apakah kegiatan drill cepat di awal pertemuan berhasil memusatkan perhatian santri sebelum pembelajaran inti?
  2. Apakah santri mengalami kesulitan saat mencari nilai prapeta x dibandingkan saat mengevaluasi nilai numerik langsung?
  3. Sejauh mana konteks kegiatan pesantren (koperasi santri, dapur umum, air minum) membantu pemahaman konsep fungsi komposisi?
  4. Perbaikan apa yang diperlukan pada metode penyampaian aljabar untuk pertemuan berikutnya?
