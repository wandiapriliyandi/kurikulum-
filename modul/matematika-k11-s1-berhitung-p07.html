Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas11
Semester1
Pertemuan7
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-3: Menentukan rumus invers dari fungsi linear dan fungsi pecahan linear melalui manipulasi aljabar menukar variabel x dan y, serta menentukan daerah asal alaminya.

Materi Pokok

1. Konsep Invers Fungsi

Jika fungsi f memetakan y = f(x), maka inversnya f⁻¹ memetakan x = f⁻¹(y). Langkah aljabar pokok:

  1. Nyatakan fungsi sebagai persamaan y = f(x).
  2. Manipulasi persamaan hingga variabel x terisolasi di satu ruas: x = g(y).
  3. Tukar variabel x dan y sehingga didapat rumus invers f⁻¹(x) = g(x).

2. Invers Fungsi Linear

Bentuk umum: f(x) = ax + b, dengan a ≠ 0.

Langkah penentuan:

  • y = ax + b
  • ax = y - b
  • x = (y - b) / a
  • Rumus invers: f⁻¹(x) = (x - b) / a
  • Daerah asal alami f⁻¹(x) adalah semua bilangan real.

3. Invers Fungsi Pecahan Linear dan Daerah Asal Alami

Bentuk umum: f(x) = (ax + b) / (cx + d), dengan cx + d ≠ 0.

Langkah penentuan:

  • y = (ax + b) / (cx + d)
  • Kali silang: y(cx + d) = ax + b
  • Jabarkan: cxy + dy = ax + b
  • Kumpulkan suku ber-x di satu ruas: cxy - ax = b - dy
  • Faktorkan x: x(cy - a) = b - dy
  • Isolasi x: x = (b - dy) / (cy - a) atau x = (-dy + b) / (cy - a)
  • Rumus invers: f⁻¹(x) = (-dx + b) / (cx - a)
  • Daerah asal alami f⁻¹(x): Penyebut pecahan tidak boleh nol (cx - a ≠ 0), sehingga domain alaminya adalah semua bilangan real x dengan syarat x ≠ a/c.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru mengucapkan salam, memimpin doa bersama, dan memeriksa kehadiran santri.
  2. Drill Cepat (3 menit):
  • Guru memberikan 3 soal hitung cepat di papan tulis:
  • Soal 1: Tentukan x jika 3x - 12 = 0 (Jawaban: x = 4).
  • Soal 2: Nyatakan x dalam y jika y = 2x + 10 (Jawaban: x = (y - 10) / 2).
  • Soal 3: Faktorkan x dari xy - 4x (Jawaban: x(y - 4)).
  • Santri menyelesaikan soal di buku corat-coret hitung secara serentak.
  1. Apersepsi: Guru mengaitkan konsep invers dengan kehidupan pesantren, seperti menghitung kembali harga asli barang koperasi pondok atau kuota beras dapur santri, lalu membacakan tujuan pembelajaran.

Inti (±100 menit)

Tahap 1: Orientasi Masalah Kontekstual Santri (15 menit)
  1. Guru menyajikan masalah logistik dapur pesantren:

"Kebutuhan beras harian regu piket dirumuskan y = (2x + 6) / (x - 3), dengan x adalah jumlah regu jaga piket (x > 3) dan y adalah jatah beras (kg). Bagaimana pengurus menentukan jumlah regu x jika diketahui jatah beras y?"

  1. Santri mengidentifikasi bahwa mencari x dari nilai y merupakan proses inversi aljabar.
Tahap 2: Demonstrasi Aljabar Guru (25 menit)
  1. Guru memodelkan langkah manipulasi aljabar secara runtut di papan tulis:
  • Tuliskan: y = (2x + 6) / (x - 3)
  • Kali silang: y(x - 3) = 2x + 6
  • Uraikan bentuk aljabar: xy - 3y = 2x + 6
  • Kelompokkan suku ber-x ke ruas kiri: xy - 2x = 3y + 6
  • Faktorkan variabel x: x(y - 2) = 3y + 6
  • Isolasi variabel x: x = (3y + 6) / (y - 2)
  • Tuliskan rumus invers: f⁻¹(x) = (3x + 6) / (x - 2)
  1. Guru menekankan penentuan daerah asal alami: penyebut tidak boleh nol, sehingga x - 2 ≠ 0 atau x ≠ 2.
Tahap 3: Latihan Terbimbing Halaqah Sebangku (30 menit)
  1. Santri bekerja berpasangan (halaqah berdua) menyelesaikan dua persoalan:
  • Kasus A (Linear): Invers fungsi kas asrama f(x) = 4x - 8.
  • Kasus B (Pecahan): Invers dan domain alami alokasi air wudu f(x) = (3x + 4) / (2x - 8).
  1. Guru berkeliling memberikan pendampingan, terutama memastikan ketepatan perubahan tanda saat pindah ruas dan pemfaktoran.
Tahap 4: Pembahasan dan Verifikasi Bersama (20 menit)
  1. Dua santri menuliskan hasil kerja di papan tulis mewakili Kasus A dan Kasus B.
  2. Kelas bersama-sama membedah alur aljabar dan memastikan ketepatan domain alami.
  3. Guru memberikan penguatan atas ketelitian santri dalam manipulasi simbol.
Tahap 5: Latihan Mandiri Singkat (10 menit)
  1. Santri mengerjakan 1 soal mandiri di selembar kertas:

"Tentukan rumus invers dan daerah asal alami dari f(x) = (5x - 2) / (x + 4)!"

  1. Lembar kerja dikumpulkan untuk penilaian capaian pembelajaran hari ini.

Penutup (±10 menit)

  1. Rangkuman: Guru bersama santri menyimpulkan teknik aljabar: pemisalan y, kali silang, pengelompokan suku, pemfaktoran, isolasi x, serta pengecekan penyebut.
  2. Apresiasi: Guru memuji ketelitian kerja santri selama latihan berhitung.
  3. Tugas Lanjutan: Pemberian 2 soal pemantapan untuk diselesaikan mandiri di asrama.
  4. Penutup: Pembacaan doa kafaratul majelis dan salam penutup.

Asesmen

1. Instrumen Asesmen Singkat

  1. Tentukan rumus fungsi invers f⁻¹(x) dari f(x) = 5x - 15!
  2. Diketahui fungsi pecahan linear g(x) = (4x + 3) / (x - 2) dengan x ≠ 2.

a. Tentukan rumus fungsi invers g⁻¹(x)!

b. Tentukan daerah asal alami dari g⁻¹(x)!

2. Pedoman Penilaian dan Kunci Jawaban

  1. Soal 1:
  • y = 5x - 15 -> 5x = y + 15 -> x = (y + 15) / 5
  • Rumus invers: f⁻¹(x) = (x + 15) / 5 (Skor: 35)
  1. Soal 2:
  • a. y = (4x + 3) / (x - 2) -> y(x - 2) = 4x + 3 -> xy - 2y = 4x + 3

xy - 4x = 2y + 3 -> x(y - 4) = 2y + 3 -> x = (2y + 3) / (y - 4)

Rumus invers: g⁻¹(x) = (2x + 3) / (x - 4) (Skor: 45)

  • b. Syarat penyebut: x - 4 ≠ 0 -> x ≠ 4

Daerah asal alami: semua bilangan real x dengan x ≠ 4 (Skor: 20)

  • Total Skor: 100

3. Kriteria Ketuntasan

  • Kriteria Ketercapaian Tujuan Pembelajaran (KKTP): Skor minimal 75.
  • Tindak Lanjut:
  • Nilai < 75: Remedial pemfaktoran aljabar variabel x.
  • Nilai ≥ 75: Tuntas dan berhak mengikuti materi pengayaan.

Media dan Sumber Belajar

  • Media: Papan tulis putih, spidol warna, kartu drill hitung kilat, buku berhitung santri.
  • Sumber Belajar: Buku Teks Matematika SMA/MA Kelas 11 Kurikulum Merdeka, lembar data kontekstual logistik asrama pesantren.

Catatan Refleksi Guru

  1. Efektivitas drill pembuka: Santri terpantau lebih cepat mengoperasikan pindah ruas setelah drill kilat.
  2. Kesulitan dominan: Sebagian santri masih membutuhkan penguatan pada pemfaktoran saat variabel x berada pada dua suku di ruas berbeda.
  3. Rencana pertemuan berikutnya: Memberikan penekanan visual warna pada variabel yang akan diisolasi.
