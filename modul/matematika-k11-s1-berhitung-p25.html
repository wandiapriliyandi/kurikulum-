Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)

PertemuanKe-25
FaseFase F

Jenis PertemuanPertemuan pembelajaran biasa

Tujuan Pembelajaran

  • TP-9: Menyusun matriks koefisien, matriks variabel, dan matriks konstanta dari sistem persamaan linear dua variabel (SPLDV) serta mengonfirmasi kesetaraan persamaan aljabar dengan persamaan matriks bentuk AX = B.

Materi Pokok

1. Bentuk Umum Sistem Persamaan Linear Dua Variabel (SPLDV)

Sistem persamaan linear dua variabel dengan variabel x dan y secara umum dinyatakan sebagai berikut:

  • Persamaan 1: a₁x + b₁y = c₁
  • Persamaan 2: a₂x + b₂y = c₂

Keterangan komponen:

  • a₁, b₁, a₂, b₂ adalah koefisien aljabar.
  • x dan y adalah variabel (peubah).
  • c₁ dan c₂ adalah nilai konstanta.

2. Pengubahan SPLDV ke Bentuk Persamaan Matriks AX = B

Sistem aljabar di atas dapat dinyatakan secara ekuivalen dalam persamaan perkalian matriks berordo 2×2 dikalikan matriks berordo 2×1 yang menghasilkan matriks berordo 2×1:

A · X = B

Di mana:

  • Matriks Koefisien (A) berordo 2×2:

[a₁ b₁]

[a₂ b₂]

  • Matriks Variabel (X) berordo 2×1:

[x]

[y]

  • Matriks Konstanta (B) berordo 2×1:

[c₁]

[c₂]

Bentuk perkalian matriks lengkap:

[a₁ b₁] [x] = [c₁]

[a₂ b₂] [y] [c₂]

3. Konfirmasi Kesetaraan Melalui Operasi Perkalian Matriks

Berdasarkan aturan perkalian baris dikali kolom:

  • Baris pertama dikalikan kolom variabel: a₁ · x + b₁ · y = a₁x + b₁y
  • Baris kedua dikalikan kolom variabel: a₂ · x + b₂ · y = a₂x + b₂y

Hasil perkalian matriks ruas kiri adalah:

[a₁x + b₁y]

[a₂x + b₂y]

Dengan prinsip kesamaan dua matriks, ruas kiri bernilai sama persis dengan matriks ruas kanan [c₁ ; c₂]:

  • a₁x + b₁y = c₁
  • a₂x + b₂y = c₂

Langkah ini membuktikan bahwa persamaan matriks AX = B memiliki kesetaraan mutlak dengan sistem persamaan linear aljabar semula.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan & Doa: Guru membuka kelas dengan salam, menyapa santri, memeriksa kehadiran, dan memimpin doa bersama sebelum belajar.
  2. Apersepsi & Motivasi: Guru menyampaikan relevansi representasi matriks dalam menyederhanakan perhitungan data logistik dan perbelanjaan di lingkungan madrasah/pesantren.
  3. Drill Cepat (Latihan Hitung Singkat):
  • Guru memberikan drill hitung mental perkalian dan penjumlahan matriks sederhana (durasi 3 menit):
  • Hitung: 3(4) + 2(5) = 12 + 10 = 22
  • Hitung hasil perkalian baris [2 5] dengan kolom [3 ; 4]: 2(3) + 5(4) = 6 + 20 = 26
  • Tentukan nilai elemen baris 2 kolom 1 dari matriks: [7 9 ; 4 1] (Jawaban: 4)
  • Santri menjawab serentak atau ditunjuk cepat untuk mengaktifkan fokus dan kesiapan berhitung.
  1. Penyampaian Tujuan: Guru menguraikan target pembelajaran hari ini, yaitu mengubah sistem persamaan linear dari kasus belanja santri menjadi model matriks AX = B.

Inti (±100 menit)

Fase 1: Eksplorasi Masalah Kontekstual Pesantren (±20 menit)
  • Guru menyajikan narasi kontekstual koperasi pesantren:

*Studi Kasus Koperasi Santri:*

"Kang Ahmad dan Kang Zaid ditugaskan oleh pengurus asrama untuk berbelanja perlengkapan kebersihan kamar santri di koperasi madrasah.

Kang Ahmad membeli 3 batang sabun mandi dan 2 botol sampo kecil dengan total belanja Rp24.000.

Kang Zaid membeli 4 batang sabun mandi dan 5 botol sampo kecil sejenis dengan total belanja Rp46.000."

  • Santri dibimbing menentukan peubah (variabel):

Misalkan harga 1 batang sabun mandi = x rupiah, dan harga 1 botol sampo = y rupiah.

  • Santri menuliskan model aljabar SPLDV:

3x + 2y = 24.000

4x + 5y = 46.000

Fase 2: Dekonstruksi Komponen dan Penyusunan Matriks (±25 menit)
  • Guru mendemonstrasikan cara memisahkan bagian koefisien, peubah, dan konstanta:
  • Angka pengali (koefisien sabun dan sampo): baris pertama 3 dan 2; baris kedua 4 dan 5.
  • Peubah yang dicari (variabel): x dan y.
  • Nilai hasil belanja (konstanta): 24.000 dan 46.000.
  • Guru memodelkan ke dalam bentuk AX = B:

[3 2] [x] = [24.000]

[4 5] [y] [46.000]

  • Penegasan istilah:
  • A = [3 2 ; 4 5] dinamakan Matriks Koefisien (ordo 2×2).
  • X = [x ; y] dinamakan Matriks Variabel (ordo 2×1).
  • B = [24.000 ; 46.000] dinamakan Matriks Konstanta (ordo 2×1).
Fase 3: Pembuktian dan Konfirmasi Kesetaraan (±20 menit)
  • Santri secara berpasangan memverifikasi kembali dengan melakukan perkalian matriks AX:

Baris 1 × Kolom: 3 · x + 2 · y = 3x + 2y

Baris 2 × Kolom: 4 · x + 5 · y = 4x + 5y

  • Menguji kesamaan matriks:

[3x + 2y] = [24.000]

[4x + 5y] [46.000]

  • Santri menyimpulkan bahwa persamaan aljabar dan persamaan matriks memuat informasi matematis yang identik dan setara.
Fase 4: Latihan Terbimbing Berkelompok (±25 menit)
  • Santri dibagi ke dalam kelompok kecil (3–4 santri). Setiap kelompok mengerjakan lembar tugas kontekstual kedua:

*Kasus Dapur Umum Pesantren:*

"Bagian konsumsi dapur santri mencatat pembelian bahan makanan pada dua hari berbeda:

Hari Senin: 5 karung beras dan 3 jeriken minyak goreng seharga Rp850.000.

Hari Selasa: 2 karung beras dan 4 jeriken minyak goreng seharga Rp620.000."

  • Tugas kelompok:
  1. Buat pemisalan variabel harga satuan beras (x) dan minyak goreng (y).
  2. Susun sistem persamaan linear dua variabel (SPLDV).
  3. Bentuk matriks koefisien (A), matriks variabel (X), dan matriks konstanta (B).
  4. Tuliskan bentuk utuh persamaan matriks AX = B.
  5. Lakukan uji perkalian matriks untuk mengonfirmasi kesetaraan.
  • Guru berkeliling memberikan scaffolding (bimbingan terarah) bagi kelompok yang menemui kendala perataan letak elemen matriks.
Fase 5: Presentasi & Diskusi Kelas (±10 menit)
  • Dua perwakilan kelompok mempresentasikan hasil pemodelan di papan tulis.
  • Kelompok lain menanggapi dan memeriksa kesesuaian letak baris dan kolom.
  • Guru mengklarifikasi kekeliruan umum (misalnya tertukarnya posisi baris koefisien atau peletakan variabel).

Penutup (±10 menit)

  1. Rangkuman Pembelajaran: Guru bersama santri menyimpulkan intisari pembelajaran:
  • Setiap SPLDV dapat diubah menjadi bentuk AX = B.
  • Posisi baris pada matriks koefisien harus selaras dengan urutan persamaan dan variabel.
  1. Refleksi Santri: Guru menanyakan santri: "Bagian mana yang paling mudah dipahami? Mengapa representasi matriks membuat penulisan persamaan aljabar yang panjang menjadi lebih ringkas?"
  2. Pemberian Tugas Mandiri Singkat: Guru memberikan 1 butir soal untuk diselesaikan sebelum jam asrama dimulai.
  3. Doa Penutup & Salam: Pembelajaran diakhiri dengan doa kafaratul majelis dan salam penutup.

Asesmen

1. Instrumen Asesmen Formatif (Latihan Mandiri)

Soal 1 (Konseptual & Pemodelan):

Ubahlah sistem persamaan linear dua variabel berikut ke dalam bentuk persamaan matriks AX = B:

  • Persamaan 1: 7x - 4y = 31
  • Persamaan 2: 2x + 5y = 19

Tentukan secara rinci:

a. Matriks koefisien (A)

b. Matriks variabel (X)

c. Matriks konstanta (B)

d. Persamaan matriks AX = B

Soal 2 (Kontekstual Pesantren):

Di kantin asrama putra, Ustaz Ridwan membeli 2 mangkuk soto dan 3 gelas teh hangat seharga Rp31.000. Ustaz Hasan membeli 3 mangkuk soto dan 1 gelas teh hangat seharga Rp36.000.

a. Nyatakan dalam bentuk SPLDV dengan variabel s (harga semangkuk soto) dan t (harga segelas teh).

b. Susun model persamaan matriks AX = B dari masalah tersebut.

c. Buktikan kesetaraannya dengan melakukan operasi perkalian baris kali kolom pada ruas kiri.

2. Kunci & Rambu Jawaban

Jawaban Soal 1:

a. Matriks koefisien:

A = [ 7 -4 ]

[ 2 5 ]

b. Matriks variabel:

X = [ x ]

[ y ]

c. Matriks konstanta:

B = [ 31 ]

[ 19 ]

d. Bentuk persamaan matriks:

[ 7 -4 ] [ x ] = [ 31 ]

[ 2 5 ] [ y ] [ 19 ]

Jawaban Soal 2:

a. Model aljabar SPLDV:

2s + 3t = 31.000

3s + 1t = 36.000

b. Model persamaan matriks:

[ 2 3 ] [ s ] = [ 31.000 ]

[ 3 1 ] [ t ] [ 36.000 ]

c. Pembuktian kesetaraan:

Ruas kiri:

[ 2 3 ] [ s ] = [ 2 · s + 3 · t ] = [ 2s + 3t ]

[ 3 1 ] [ t ] [ 3 · s + 1 · t ] [ 3s + t ]

Karena ruas kiri sama dengan ruas kanan:

[ 2s + 3t ] = [ 31.000 ]

[ 3s + t ] [ 36.000 ]

Maka diperoleh kembali sistem persamaan semula:

2s + 3t = 31.000 dan 3s + t = 36.000 (Terbukti setara).

*Pedoman Penskoran:*

  • Nilai Akhir = (Total Skor Perolehan ÷ 12) × 100
  • Interval Ketuntasan:
  • 0 – 60: Belum tuntas, memerlukan bimbingan remedial individual pada konsep dasar elemen matriks.
  • 61 – 74: Cukup tuntas, remedial pada pembuktian kesetaraan perkalian matriks.
  • 75 – 89: Tuntas (mencapai target pembelajaran).
  • 90 – 100: Tuntas istimewa, diberikan soal pengayaan pemodelan sistem 3 variabel (SPLTV).

Catatan Refleksi Guru

  1. Efektivitas Drill Awal: Apakah alokasi waktu drill hitung 3–5 menit di awal efektif mengembalikan kesiapan kognitif santri setelah beraktivitas di asrama/halaqah pagi?
  2. Identifikasi Hambatan Belajar: Apakah masih ditemukan santri yang menempatkan matriks variabel X berbentuk baris mendatar [x y] alih-alih matriks kolom tegak [x ; y]? Strategi visual apa yang paling efektif untuk mengoreksinya?
  3. Keterlibatan Santri: Apakah konteks perbelanjaan koperasi santri dan dapur umum asrama mempermudah santri dalam memahami transisi dari narasi verbal menuju simbol matriks formal?
  4. Rencana Tindak Lanjut: Bagi santri yang belum menguasai operasi dasar baris kali kolom pada matriks, perlu diadakan klinik berhitung singkat selama 15 menit pasca shalat berjamaah atau sebelum pertemuan ke-26 dimulai.
