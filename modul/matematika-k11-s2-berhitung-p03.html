Modul Ajar — Matematika (Berhitung)

Identitas

KomponenKeterangan
Mata PelajaranMatematika (Berhitung)
Kelas11
Semester2
Pertemuan3
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-1: Mengubah bentuk baku persamaan lingkaran ke bentuk umum; mengidentifikasi nilai parameter A, B, dan C pada bentuk umum persamaan lingkaran serta mengaitkannya dengan titik pusat dan jari-jari.

Materi Pokok

1. Penjabaran Bentuk Baku ke Bentuk Umum

Bentuk baku lingkaran dengan pusat P(a, b) dan jari-jari r:

(x - a)² + (y - b)² = r²

Dijabarkan:

x² - 2ax + a² + y² - 2by + b² = r²

x² + y² - 2ax - 2by + (a² + b² - r²) = 0

Ditetapkan parameter:

  • A = -2a
  • B = -2b
  • C = a² + b² - r²

Bentuk umum persamaan lingkaran:

x² + y² + Ax + By + C = 0

2. Kaitan Nilai A, B, C dengan Pusat dan Jari-Jari

Hubungan balik parameter terhadap lingkaran:

  • Titik pusat: P(a, b) = P(-A/2, -B/2)
  • Jari-jari lingkaran:

r = akar((A/2)² + (B/2)² - C)

Sifat geometri:

  • Nilai di dalam akar > 0: lingkaran nyata.
  • Nilai di dalam akar = 0: lingkaran titik (r = 0).
  • Nilai di dalam akar < 0: lingkaran imajiner.

3. Contoh Pengubahan Bentuk

  • Mengubah ke bentuk umum:

(x - 3)² + (y + 4)² = 25

x² - 6x + 9 + y² + 8y + 16 = 25

x² + y² - 6x + 8y = 0

Diperoleh A = -6, B = 8, C = 0.

  • Menentukan pusat dan jari-jari:

x² + y² + 4x - 6y - 12 = 0

A = 4, B = -6, C = -12.

Pusat: P(-4/2, -(-6)/2) = P(-2, 3).

Jari-jari: r = akar((-2)² + 3² - (-12)) = akar(25) = 5 satuan.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Guru mengucap salam, berdoa, dan mengecek presensi santri.
  2. Guru menyampaikan tujuan pembelajaran hari ini.
  3. Drill Cepat Berhitung (5 menit):

Latihan lisan cepat di papan tulis:

  • Kuadrat aljabar: (x - 4)², (y + 5)²
  • Pembagian negatif: -8 ÷ 2, -(-10) ÷ 2, 14 ÷ (-2)
  • Hitung kombinasi: (-3)² + 4² - 9, (-4)² + (-2)² - (-5)
  1. Apersepsi: mengaitkan bentuk lingkaran dengan jangkauan lampu dan batas fasilitas pondok.

Inti (±100 menit)

Langkah 1: Penjabaran Rumus (±20 menit)
  • Guru menuliskan bentuk baku (x - a)² + (y - b)² = r².
  • Bersama santri menguraikan bentuk kuadrat menjadi x² + y² - 2ax - 2by + (a² + b² - r²) = 0.
  • Menetapkan parameter A = -2a, B = -2b, C = a² + b² - r² sehingga menjadi x² + y² + Ax + By + C = 0.
  • Menurunkan rumus pusat P(-A/2, -B/2) dan r = akar((A/2)² + (B/2)² - C).
Langkah 2: Contoh Terbimbing (±20 menit)
  • Membahas contoh 1: Mengubah (x + 2)² + (y - 5)² = 16 menjadi x² + y² + 4x - 10y + 13 = 0, dengan A = 4, B = -10, C = 13.
  • Membahas contoh 2: Menentukan pusat dan jari-jari dari x² + y² - 8x + 4y - 5 = 0, didapat pusat P(4, -2) dan r = 5.
  • Mengingatkan santri agar teliti membagi tanda negatif pada A dan B.
Langkah 3: Masalah Kontekstual Santri (±35 menit)

Santri berkelompok (3-4 orang) menuntaskan masalah kehidupan pesantren:

  • Masalah 1 (Lampu Lapangan Madrasah):

Lampu sorot terpasang di titik P(2, -3) dengan radius r = 6 meter. Santri menyusun bentuk baku (x - 2)² + (y + 3)² = 36, menjabarkannya menjadi x² + y² - 4x + 6y - 23 = 0, lalu menentukan A = -4, B = 6, C = -23.

  • Masalah 2 (Radar Pos Keamanan Pondok):

Radar pengawas gerbang pondok memiliki sinyal x² + y² + 6x - 8y - 11 = 0 (satuan puluhan meter). Santri menentukan A = 6, B = -8, C = -11, posisi antena P(-3, 4), dan jangkauan r = akar(9 + 16 - (-11)) = 6 satuan.

  • Guru mendampingi kelompok yang membutuhkan bantuan hitung.
Langkah 4: Pembahasan Pleno (±15 menit)
  • Perwakilan kelompok menuliskan jawaban di papan tulis.
  • Kelompok lain menanggapi dan memeriksa tanda perhitungan.
  • Guru mengonfirmasi kebenaran penyelesaian.
Langkah 5: Latihan Mandiri (±10 menit)
  • Santri mengerjakan soal latihan formatif individu secara tertulis.

Penutup (±10 menit)

  1. Guru dan santri merangkum simpulan: rumus bentuk umum, koordinat pusat, dan jari-jari.
  2. Refleksi pembelajaran terkait pemahaman tanda aljabar.
  3. Guru memberi tugas rumah (PR) untuk asrama.
  4. Kelas ditutup dengan doa kafaratul majelis dan salam.

Asesmen

1. Soal Latihan Mandiri

  1. Ubahlah bentuk baku (x - 5)² + (y + 1)² = 49 ke bentuk umum, lalu tentukan nilai A, B, dan C!
  2. Diberikan persamaan x² + y² - 10x + 6y - 2 = 0:

a. Tentukan nilai A, B, dan C!

b. Tentukan titik pusatnya!

c. Hitung panjang jari-jarinya!

  1. Kolam wudhu pondok dibatasi lingkaran x² + y² + 4x - 12y + 15 = 0 (meter). Tentukan titik pusat dan diameter kolam tersebut!

2. Kunci dan Rambu Jawaban

  1. Penjabaran:

x² - 10x + 25 + y² + 2y + 1 = 49

x² + y² - 10x + 2y - 23 = 0.

Parameter: A = -10, B = 2, C = -23.

  1. Jawaban nomor 2:

a. A = -10, B = 6, C = -2.

b. Pusat: P(-(-10)/2, -6/2) = P(5, -3).

c. Jari-jari: r = akar(5² + (-3)² - (-2)) = akar(36) = 6 satuan.

  1. Jawaban nomor 3:
  • A = 4, B = -12, C = 15.
  • Pusat: P(-4/2, -(-12)/2) = P(-2, 6).
  • Jari-jari: r = akar((-2)² + 6² - 15) = akar(25) = 5 meter.
  • Diameter: d = 2 × 5 meter = 10 meter.

3. Kriteria Ketuntasan

  • Sangat Mahir (85 - 100): Tepat menjabarkan bentuk umum, benar menentukan A, B, C, serta tepat menghitung pusat dan jari-jari soal kontekstual.
  • Mahir / Tuntas (70 - 84): Mampu menjabarkan bentuk umum dan menentukan pusat serta jari-jari dengan benar, dengan sedikit kesalahan hitung kecil.
  • Cukup / Perlu Bimbingan (55 - 69): Mengetahui rumus, tetapi masih keliru tanda negatif pada titik pusat atau perhitungan nilai C.
  • Kurang / Remedial (< 55): Belum mampu menguraikan kuadrat suku dua dan belum memahami kaitan parameter.

  • Apakah konteks fasilitas pesantren membantu santri memahami kegunaan materi?
  • Santri mana yang memerlukan remedial penjabaran aljabar pada pertemuan berikutnya?
