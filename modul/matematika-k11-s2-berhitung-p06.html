Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas11
Semester2
PertemuanKe-6
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-2: Menyusun persamaan kuadrat persekutuan antara persamaan garis dan lingkaran; menganalisis kedudukan garis terhadap lingkaran berdasarkan nilai diskriminan (D > 0, D = 0, D < 0).

Materi Pokok

Kedudukan garis lurus y = mx + c terhadap lingkaran x² + y² = r² atau bentuk umum x² + y² + Ax + By + C = 0 ditentukan melalui persamaan kuadrat persekutuan dan nilai diskriminan (D).

1. Pembentukan Persamaan Kuadrat Persekutuan

Substitusikan persamaan garis y = mx + c ke dalam persamaan lingkaran, lalu kelompokkan suku-sukunya ke dalam bentuk baku:

ax² + bx + c = 0 (dengan a ≠ 0)

2. Nilai Diskriminan dan Kriteria Kedudukan

Nilai diskriminan dihitung dengan rumus:

D = b² - 4ac

Kriteria geometris:

  • D > 0: Garis memotong lingkaran di dua titik berbeda. Persamaan memiliki dua akar real berlainan.
  • D = 0: Garis menyinggung lingkaran di satu titik. Persamaan memiliki akar kembar real.
  • D < 0: Garis di luar lingkaran (tidak memotong dan tidak menyinggung). Persamaan tidak memiliki akar real.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan (2 menit): Guru membuka kelas dengan salam, memeriksa kesiapan santri, dan memimpin doa.
  2. Apersepsi (3 menit): Guru mengaitkan materi dengan situasi pesantren, seperti membentangkan pipa air atau kawat pagar melewati area taman melingkar.
  3. Drill Cepat Berhitung (5 menit): Santri menyelesaikan 5 latihan hitung cepat di buku catatan:
  • Hitung: 4² - 4(1)(3) = ... (4)
  • Hitung: (-6)² - 4(1)(9) = ... (0)
  • Hitung: 2² - 4(2)(5) = ... (-36)
  • Jabarkan: (x - 3)² = ... (x² - 6x + 9)
  • Jabarkan: (2x + 1)² = ... (4x² + 4x + 1)

Inti (±100 menit)

Tahap 1: Eksplorasi Konsep Terbimbing (20 menit)
  • Guru mendemonstrasikan substitusi garis ke lingkaran pada papan tulis:
  • Garis y = x + 1 dan lingkaran x² + y² = 25.
  • Substitusi: x² + (x + 1)² = 25 → 2x² + 2x - 24 = 0 atau x² + x - 12 = 0.
  • a = 1, b = 1, c = -12.
  • Diskriminan: D = 1² - 4(1)(-12) = 1 + 48 = 49.
  • Karena D = 49 > 0, garis memotong lingkaran di dua titik.
  • Guru mengaitkan interpretasi grafis untuk nilai D > 0, D = 0, dan D < 0.
Tahap 2: Pemecahan Masalah Kontekstual Pesantren (35 menit)

Santri berkelompok dalam halaqah (3-4 santri) menyelesaikan masalah kontekstual:

  • Kasus 1 (Jalur Pipa Air Kolam Wudhu):

Kolam wudhu bundar pesantren memiliki batas koordinat x² + y² = 25 (satuan meter). Jalur pipa air dipasang mengikuti garis lurus y = 2x - 5.

Santri menyusun persamaan kuadrat persekutuan, menghitung D, dan menentukan apakah pipa memotong, menyinggung, atau di luar kolam wudhu.

  • Kasus 2 (Bentangan Kabel Listrik Lampu Taman):

Taman santri berbentuk lingkaran x² + y² = 10. Pengurus sarpras menarik kabel listrik lurus dengan persamaan y = 3x + 10.

Santri menentukan kedudukan kabel listrik terhadap batas taman menggunakan diskriminan.

Tahap 3: Diskusi dan Pendampingan (20 menit)
  • Santri berdiskusi aktif dalam halaqah, menguji penjabaran aljabar dan perhitungan diskriminan.
  • Guru berkeliling mendampingi kelompok, terutama dalam ketelitian tanda negatif pada rumus -4ac.
Tahap 4: Presentasi dan Pembahasan Bersama (15 menit)
  • Perwakilan halaqah menuliskan jawaban di papan tulis:
  • Kasus 1: x² + (2x - 5)² = 25 → 5x² - 20x = 0 → D = (-20)² - 4(5)(0) = 400. Karena D > 0, pipa memotong kolam di dua titik.
  • Kasus 2: x² + (3x + 10)² = 10 → 10x² + 60x + 90 = 0 (atau x² + 6x + 9 = 0) → D = 6² - 4(1)(9) = 0. Karena D = 0, kabel menyinggung taman di satu titik.
  • Guru memberikan penguatan konsep dan memvalidasi hasil kerja santri.
Tahap 5: Latihan Mandiri Singkat (10 menit)

Santri secara mandiri menguji kedudukan garis y = -x + 6 terhadap lingkaran x² + y² = 16.

Penyelesaian singkat: x² + (6 - x)² = 16 → 2x² - 12x + 20 = 0 (x² - 6x + 10 = 0). D = (-6)² - 4(1)(10) = -4 < 0 (garis di luar lingkaran).

Penutup (±10 menit)

  1. Rangkuman (4 menit): Santri dan guru menyimpulkan: D > 0 memotong di dua titik, D = 0 menyinggung di satu titik, D < 0 di luar lingkaran.
  2. Umpan Balik dan Arahan (4 menit): Guru mengapresiasi keaktifan santri dan memberikan tugas latihan mandiri di asrama.
  3. Doa dan Salam (2 menit): Pembelajaran ditutup dengan membaca hamdalah, doa kafaratul majelis, dan salam.

Asesmen

1. Soal Latihan Formatif

  1. Tentukan kedudukan garis y = 2x + 1 terhadap lingkaran x² + y² = 5!
  2. Tentukan kedudukan garis y = x + 4 terhadap lingkaran x² + y² = 8!
  3. Sebuah jalur jalan setapak di pondok mengikuti persamaan y = x + 5, sedangkan batas kolam ikan berbentuk lingkaran x² + y² = 9. Tentukan kedudukan jalan setapak tersebut terhadap kolam!

2. Kunci dan Pedoman Jawaban

  1. Soal 1:

x² + (2x + 1)² = 5 → 5x² + 4x - 4 = 0.

a = 5, b = 4, c = -4.

D = 4² - 4(5)(-4) = 16 + 80 = 96.

Karena D = 96 > 0, garis memotong lingkaran di dua titik berbeda.

  1. Soal 2:

x² + (x + 4)² = 8 → 2x² + 8x + 8 = 0 (x² + 4x + 4 = 0).

a = 1, b = 4, c = 4.

D = 4² - 4(1)(4) = 16 - 16 = 0.

Karena D = 0, garis menyinggung lingkaran tepat di satu titik.

  1. Soal 3:

x² + (x + 5)² = 9 → 2x² + 10x + 16 = 0 (x² + 5x + 8 = 0).

a = 1, b = 5, c = 8.

D = 5² - 4(1)(8) = 25 - 32 = -7.

Karena D = -7 < 0, jalan setapak berada di luar kolam (tidak memotong maupun menyinggung).

Media dan Sumber Belajar

Catatan Refleksi Guru

  • Ketercapaian Konsep: Mayoritas santri mampu memahami hubungan nilai diskriminan dengan banyaknya titik potong geometris.
  • Catatan Teknis: Perlu penguatan berkala pada penjabaran aljabar kuadrat suku dua (mx + c)² agar suku tengah tidak terlewat.
  • Rencana Tindak Lanjut: Memberikan pendampingan tambahan saat belajar malam di asrama bagi santri yang belum tuntas aljabar kuadrat, serta pengayaan penentuan titik potong bagi santri yang telah tuntas.
