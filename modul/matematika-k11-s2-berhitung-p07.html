Modul Ajar — Matematika (Berhitung)

Identitas

KomponenKeterangan
Mata PelajaranMatematika (Berhitung)
Kelas11
Semester2 (Genap)
Pertemuan7
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

Pertemuan ini berfokus pada pencapaian Tujuan Pembelajaran (TP-3):

  • Santri mampu menentukan persamaan garis singgung lingkaran berpusat di (0,0) melalui titik singgung (x1, y1) pada lingkaran menggunakan metode bagi adil.
  • Santri mampu menentukan persamaan garis singgung lingkaran berpusat di (a,b) melalui titik singgung (x1, y1) pada lingkaran menggunakan metode bagi adil.
  • Santri mampu menyelesaikan masalah kontekstual kehidupan sehari-hari santri di lingkungan pesantren terkait garis singgung lingkaran.

Materi Pokok

Garis singgung lingkaran adalah garis yang menyentuh lingkaran tepat di satu titik dan tegak lurus jari-jari lingkaran di titik tersebut. Ketika titik singgung P(x1, y1) terletak pada lingkaran, persamaan garis singgung diperoleh dengan metode bagi adil.

Aturan Metode Bagi Adil

  1. x² diganti x1 · x
  2. y² diganti y1 · y
  3. (x - a)² diganti (x1 - a)(x - a)
  4. (y - b)² diganti (y1 - b)(y - b)
  5. x diganti 0,5(x + x1)
  6. y diganti 0,5(y + y1)

Rumus Garis Singgung

  • Pusat (0,0): Lingkaran x² + y² = r² menjadi:

x1 · x + y1 · y = r²

  • Pusat (a,b) Bentuk Baku: Lingkaran (x - a)² + (y - b)² = r² menjadi:

(x1 - a)(x - a) + (y1 - b)(y - b) = r²

  • Pusat (a,b) Bentuk Umum: Lingkaran x² + y² + Ax + By + C = 0 menjadi:

x1 · x + y1 · y + 0,5 · A(x + x1) + 0,5 · B(y + y1) + C = 0

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Salam, presensi santri, dan pembacaan doa pembuka.
  2. Motivasi: Guru mengaitkan materi dengan roda gerobak dorong dapur pesantren atau tandon air bundar yang menyentuh lantai datar di satu garis batas.
  3. Drill Cepat Berhitung (5 menit):
  • Hitung: 3² + 4² = ... (Jawaban: 25)
  • Nilai y positif jika titik (6, y) pada x² + y² = 100 (Jawaban: 8)
  • Bentuk sederhana (5 - 2)(x - 2) (Jawaban: 3x - 6)
  • Nilai 3(4) + 4(3) - 24 (Jawaban: 0)
  1. Guru menjelaskan tujuan dan indikator pembelajaran hari ini.

Inti (±100 menit)

Tahap 1: Penurunan Konsep Bagi Adil (25 menit)
  1. Guru menggambar lingkaran x² + y² = r² dengan titik singgung P(x1, y1).
  2. Menentukan gradien garis singgung: karena jari-jari memiliki gradien m1 = y1 / x1, garis singgung tegak lurus sehingga m2 = -x1 / y1.
  3. Dari y - y1 = (-x1 / y1)(x - x1), diperoleh x1 · x + y1 · y = x1² + y1². Karena titik pada lingkaran, maka x1² + y1² = r², menghasilkan x1 · x + y1 · y = r².
  4. Guru menjelaskan analogi serupa pada lingkaran berpusat di (a,b).
Tahap 2: Pemodelan Masalah Pesantren (25 menit)
  1. Contoh 1: Drum minyak goreng pesantren dengan irisan x² + y² = 100 ditopang bilah lurus tepat di titik (6, 8).

Penerapan bagi adil: 6x + 8y = 100, disederhanakan menjadi 3x + 4y - 50 = 0.

  1. Contoh 2: Kolam wudu berpenampang bundar (x - 2)² + (y + 1)² = 25 dipasangi pipa lurus di titik (5, 3).

Penerapan bagi adil:

(5 - 2)(x - 2) + (3 + 1)(y + 1) = 25

3(x - 2) + 4(y + 1) = 25

3x - 6 + 4y + 4 = 25

3x + 4y - 27 = 0.

Tahap 3: Latihan Kelompok Terbimbing (30 menit)
  1. Santri dibentuk kelompok beranggotakan 3-4 orang.
  2. Setiap kelompok menyelesaikan lembar masalah:
  • Menentukan garis singgung kubah tandon x² + y² = 25 di titik (-4, 3).
  • Menentukan garis batas taman (x + 1)² + (y - 2)² = 20 di titik (3, 4).
  • Menentukan garis singgung roda x² + y² - 4x + 6y - 12 = 0 di titik (5, 1).
  1. Guru berkeliling mendampingi santri, menekankan ketelitian perhitungan bertanda negatif.
Tahap 4: Diskusi dan Konfirmasi (20 menit)
  1. Perwakilan kelompok memaparkan jawaban di papan tulis.
  2. Guru dan santri mengevaluasi serta menyepakati kebenaran langkah aljabar.

Penutup (±10 menit)

  1. Guru dan santri menyimpulkan aturan metode bagi adil.
  2. Refleksi pembelajaran: santri mengingat kembali langkah penting yaitu menguji titik pada lingkaran sebelum menerapkan rumus.
  3. Guru memberikan tugas mandiri asrama dan menutup pertemuan dengan doa serta salam.

Asesmen

Soal Latihan Mandiri

  1. Tentukan persamaan garis singgung lingkaran x² + y² = 169 di titik A(5, -12).
  2. Tentukan persamaan garis singgung lingkaran (x - 1)² + (y - 3)² = 25 di titik B(4, 7).
  3. Tentukan persamaan garis singgung lingkaran x² + y² - 6x + 2y - 15 = 0 di titik C(7, 2).

Kunci dan Rambu Jawaban

  1. Titik A(5, -12) pada lingkaran: 5² + (-12)² = 25 + 144 = 169.

Metode bagi adil:

5x + (-12)y = 169

5x - 12y - 169 = 0.

(Skor: 30)

  1. Titik B(4, 7) pada lingkaran: (4 - 1)² + (7 - 3)² = 3² + 4² = 25.

Metode bagi adil:

(4 - 1)(x - 1) + (7 - 3)(y - 3) = 25

3(x - 1) + 4(y - 3) = 25

3x - 3 + 4y - 12 - 25 = 0

3x + 4y - 40 = 0.

(Skor: 35)

  1. Titik C(7, 2) pada lingkaran: 7² + 2² - 6(7) + 2(2) - 15 = 49 + 4 - 42 + 4 - 15 = 0.

Metode bagi adil:

7x + 2y - 3(x + 7) + 1(y + 2) - 15 = 0

7x + 2y - 3x - 21 + y + 2 - 15 = 0

4x + 3y - 34 = 0.

(Skor: 35)
