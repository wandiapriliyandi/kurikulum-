Modul Ajar — Matematika (Berhitung)

Identitas

KomponenKeterangan
Mata PelajaranMatematika (Berhitung)
Kelas / Semester11 / Semester 2
PertemuanKe-14
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)
Jenis PertemuanPertemuan pembelajaran biasa

Tujuan Pembelajaran

  • TP-5: Santri mampu menentukan matriks transformasi dilatasi dengan faktor skala k berpusat di (0,0), serta menghitung bayangan titik dan bangun datar akibat dilatasi terhadap pusat (0,0) maupun pusat (a,b).

Materi Pokok

1. Konsep Dasar Dilatasi dan Faktor Skala k

Dilatasi adalah transformasi geometri yang mengubah ukuran (memperbesar atau memperkecil) objek tanpa mengubah bentuk aslinya. Perubahan ukuran ditentukan oleh titik pusat dan faktor skala k:

  • k > 1: Bangun diperbesar searah pusat.
  • 0 < k < 1: Bangun diperkecil searah pusat.
  • -1 < k < 0: Bangun diperkecil berlawanan arah.
  • k < -1: Bangun diperbesar berlawanan arah.

2. Matriks Dilatasi Pusat (0,0)

Titik awal P(x, y) didilatasikan terhadap pusat O(0,0) dengan faktor skala k menghasilkan bayangan P'(x', y'):

  • x' = k × x
  • y' = k × y

Bentuk matriks:

[x'] = [k 0] [x]

[y'] [0 k] [y]

Matriks dilatasi [O, k] bernilai [k, 0; 0, k].

3. Dilatasi Pusat C(a,b)

Jika pusat dilatasi berada pada titik C(a,b), koordinat awal dikurangi pusat sebelum dikalikan faktor skala k:

  • x' = k(x - a) + a
  • y' = k(y - b) + b

Representasi matriks:

[x'] = [k 0] [x - a] + [a]

[y'] [0 k] [y - b] [b]

Notasi transformasi ini ditulis [C(a,b), k].

4. Perubahan Luas Bangun Datar

Jika bangun berluas L didilatasikan dengan faktor skala k, luas bayangannya:

L' = k² × L

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru memberi salam, memeriksa kesiapan santri, dan memimpin doa bersama.
  2. Drill Cepat Berhitung (5 menit): Guru menuliskan 4 soal hitung cepat di papan tulis:
  • 3 × (-4) = ...
  • 0,5 × 18 = ...
  • 2 × [4, -1; 3, 2] = ...
  • 2 × (8 - 3) + 3 = ...

Santri menjawab cepat di buku buram secara serempak.

  1. Apersepsi: Mengaitkan konsep skala dengan pembuatan denah komplek santri dan ornamen sajadah masjid.

Inti (±100 menit)

Fase 1: Eksplorasi Pusat (0,0) — Pengecilan Denah Lapangan Pondok (25 menit)
  1. Guru menyajikan kasus denah lapangan pondok dengan tiang bendera di titik O(0,0). Titik batas paving berada di A(6, 4) dan B(10, 8) meter.
  2. Pengurus membuat miniatur denah dengan faktor skala k = 1/2 terhadap pusat tiang O(0,0).
  3. Guru memandu pemodelan matriks dilatasi:

[x'] = [1/2 0 ] [6] = [3]

[y'] [ 0 1/2] [4] [2]

Diperoleh A'(3, 2).

  1. Santri menghitung titik B' secara mandiri dan menemukan B'(5, 4).
Fase 2: Perluasan Pusat C(a,b) — Pola Ornamen Karpet Masjid (30 menit)
  1. Diberikan kasus saf salat di masjid. Titik sudut mimbar berada di C(2, 3) sebagai acuan pusat dilatasi. Titik ornamen sajadah berada di P(5, 7).
  2. Ornamen diperbesar dengan faktor k = 2 berpusat di C(2, 3).
  3. Guru membimbing rumus matriks:

[x'] = [2 0] [5 - 2] + [2] = [2 0] [3] + [2] = [6] + [2] = [8]

[y'] [0 2] [7 - 3] [3] [0 2] [4] [3] [8] [3] [11]

Diperoleh titik P'(8, 11).

  1. Santri berlatih menentukan bayangan titik Q(1, 5) dengan dilatasi yang sama:

x' = 2(1 - 2) + 2 = 0

y' = 2(5 - 3) + 3 = 7

Diperoleh Q'(0, 7).

Fase 3: Pemecahan Masalah Berkelompok (30 menit)
  1. Santri berkelompok (3-4 santri) menyelesaikan lembar tugas:
  • Taman toga pondok berbentuk segitiga dengan koordinat K(1, 1), L(5, 1), dan M(1, 4) meter.
  • Luas awal taman = 1/2 × 4 × 3 = 6 m².
  • Taman didilatasi dengan k = -2 berpusat di titik sumur S(2, 1).
  1. Setiap kelompok menghitung bayangan koordinat titik K', L', M':
  • K': x' = -2(1 - 2) + 2 = 4; y' = -2(1 - 1) + 1 = 1 --> K'(4, 1)
  • L': x' = -2(5 - 2) + 2 = -4; y' = -2(1 - 1) + 1 = 1 --> L'(-4, 1)
  • M': x' = -2(1 - 2) + 2 = 4; y' = -2(4 - 1) + 1 = -5 --> M'(4, -5)
  1. Kelompok menghitung luas baru: L' = (-2)² × 6 m² = 24 m².
  2. Guru mendampingi kelompok yang membutuhkan penguatan perhitungan skalar negatif.
Fase 4: Pembahasan dan Verifikasi (15 menit)
  1. Perwakilan kelompok menuliskan hasil perhitungan di papan tulis.
  2. Guru memberi penegasan mengenai arti faktor skala negatif: arah bayangan berlawanan 180 derajat terhadap titik acuan, sedangkan luas bayangan selalu bernilai positif karena dikalikan k².

Penutup (±10 menit)

  1. Refleksi Bersama: Guru bersama santri menyimpulkan aturan perkalian matriks dilatasi pusat (0,0) dan pusat (a,b).
  2. Kuis Ringkas: Santri mengerjakan satu soal hitung bayangan secara mandiri.
  3. Doa dan Salam: Mengingatkan materi berikutnya dan menutup sesi dengan doa kafaratul majelis.

Asesmen

1. Soal Latihan dan Kuis

Soal 1:

Tentukan matriks transformasi dilatasi berpusat di O(0,0) dengan faktor skala k = 3, lalu tentukan bayangan titik A(-2, 4)!

Soal 2:

Tentukan bayangan titik B(6, 1) akibat dilatasi dengan faktor skala k = -2 berpusat di titik P(2, 3)!

Soal 3:

Sebuah karpet masjid memiliki luas 2 m². Jika didilatasi dengan faktor k = 3, hitung luas karpet baru!

2. Kunci Jawaban dan Rambu Penilaian

  • Soal 1:
  • Matriks = [3, 0; 0, 3].
  • [x'] = [3 0] [-2] = [-6]

[y'] [0 3] [ 4] [12]

  • Bayangan A'(-6, 12). (Skor: 30)
  • Soal 2:
  • Pusat (2, 3), k = -2.
  • [x'] = [-2 0] [6 - 2] + [2] = [-2 0] [ 4] + [2] = [-8] + [2] = [-6]

[y'] [ 0 -2] [1 - 3] [3] [ 0 -2] [-2] [3] [ 4] [3] [ 7]

  • Bayangan B'(-6, 7). (Skor: 40)
  • Soal 3:
  • L' = k² × L = 3² × 2 m² = 18 m². (Skor: 30)
