Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi

Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • Santri dapat menentukan bayangan persamaan garis lurus hasil transformasi matriks menggunakan metode substitusi matriks invers secara teliti.
  • Santri dapat menentukan bayangan persamaan lingkaran atau kurva aljabar akibat komposisi transformasi matriks menggunakan substitusi matriks invers dengan sistematis.
  • Ketercapaian TP: TP-6.

Materi Pokok

1. Transformasi Persamaan Garis dan Kurva dengan Matriks Invers

Pada transformasi titik dengan matriks T = [a b; c d], koordinat bayangan dinyatakan oleh:

[x'; y'] = [a b; c d] [x; y]

Untuk mencari persamaan bayangan dari kurva f(x, y) = 0, koordinat awal (x, y) dinyatakan dalam koordinat bayangan (x', y') menggunakan invers matriks T:

[x; y] = T⁻¹ [x'; y']

Dengan determinan det(T) = (ad - bc) ≠ 0:

T⁻¹ = (1 / det(T)) × [d -b; -c a]

Diperoleh hubungan:

x = (1 / det(T)) × (d·x' - b·y')

y = (1 / det(T)) × (-c·x' + a·y')

Substitusikan nilai x dan y tersebut ke persamaan awal kurva, lalu sederhanakan persamaan aljabar yang terbentuk tanpa tanda aksen.

2. Komposisi Transformasi Matriks

Jika kurva ditransformasikan berurutan oleh matriks T1 lalu matriks T2, maka matriks komposisinya adalah:

T_total = T2 × T1

Hubungan substitusi variabel kurva diperoleh dari:

[x; y] = (T_total)⁻¹ [x'; y']

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru mengucapkan salam, menyapa santri, memimpin doa, dan memeriksa kehadiran.
  2. Drill Cepat (5 menit):

Guru memberikan latihan hitung singkat di papan tulis:

  • Hitung determinan matriks M = [2 1; 5 3]! (Jawaban: 2×3 - 1×5 = 1)
  • Tentukan invers dari matriks M! (Jawaban: [3 -1; -5 2])
  • Nyatakan x dan y jika [x; y] = [3 -1; -5 2] [x'; y']! (Jawaban: x = 3x' - y', y = -5x' + 2y')
  1. Apersepsi: Guru mengaitkan materi transformasi matriks dengan pemetaan tata letak bangunan dan jalur pipa air di lingkungan pesantren.

Inti (±100 menit)

Langkah 1: Eksplorasi Konsep Pemetaan Garis (25 menit)
  • Guru menyajikan masalah kontekstual: Jalur pipa air asrama santri membentuk garis lurus 2x - 3y + 6 = 0. Jalur dipetakan dengan transformasi matriks T = [1 2; 0 1].
  • Guru mendemonstrasikan metode substitusi matriks invers:

det(T) = 1×1 - 2×0 = 1

T⁻¹ = [1 -2; 0 1]

Diperoleh: x = x' - 2y' dan y = y'.

  • Substitusikan ke persamaan garis:

2(x' - 2y') - 3(y') + 6 = 0

2x' - 4y' - 3y' + 6 = 0

2x - 7y + 6 = 0.

Langkah 2: Diskusi Kelompok Masalah Kurva Pesantren (35 menit)
  • Santri dibagi ke dalam kelompok halaqah (3-4 orang).
  • Setiap kelompok menyelesaikan masalah kontekstual:

Taman santri memiliki kolam wudu berbentuk lingkaran dengan persamaan x² + y² = 16. Denah taman ditransformasikan berturut-turut oleh matriks rotasi T1 = [0 -1; 1 0] lalu dilanjutkan transformasi T2 = [2 0; 0 2].

  • Santri berdiskusi menentukan matriks komposisi T_total = T2 × T1 = [0 -2; 2 0], mencari inversnya, dan mensubstitusikan ke persamaan lingkaran.
  • Guru mendampingi kelompok yang membutuhkan bimbingan aljabar.
Langkah 3: Presentasi dan Pembahasan Bersama (25 menit)
  • Perwakilan kelompok mempresentasikan langkah penyelesaian di papan tulis.
  • Kelompok lain menanggapi dan memeriksa ketelitian perhitungan.
  • Guru mengklarifikasi bahwa hasil pemetaan lingkaran kolam wudu menghasilkan x² + y² = 64 karena mengalami pembesaran skala.
Langkah 4: Latihan Mandiri Terbimbing (15 menit)
  • Santri menyelesaikan latihan individu: Tentukan bayangan garis 3x + 2y - 6 = 0 oleh transformasi matriks T = [2 1; 1 1].
  • Guru mengecek pemahaman santri secara langsung.

Penutup (±10 menit)

  1. Guru membimbing santri menyimpulkan prosedur substitusi invers matriks pada kurva.
  2. Guru memberikan apresiasi atas kesungguhan belajar santri dalam diskusi halaqah.
  3. Guru memberi tugas latihan terarah untuk dikerjakan di asrama.
  4. Kelas ditutup dengan membaca doa kafaratul majelis dan salam.

Asesmen

1. Soal Latihan

Soal 1 (Garis Lurus):

Tentukan persamaan bayangan garis lurus 3x - 2y + 8 = 0 oleh transformasi matriks T = [3 1; 5 2]!

Soal 2 (Komposisi Kurva Lingkaran):

Tentukan persamaan bayangan kurva lingkaran x² + y² = 9 oleh transformasi matriks T1 = [0 -1; 1 0] dilanjutkan T2 = [1 0; 0 1]!

2. Kunci Jawaban

Kunci Soal 1:

  • det(T) = (3×2) - (1×5) = 1
  • T⁻¹ = [2 -1; -5 3]
  • Hubungan koordinat: x = 2x' - y' dan y = -5x' + 3y'
  • Substitusi:

3(2x' - y') - 2(-5x' + 3y') + 8 = 0

6x' - 3y' + 10x' - 6y' + 8 = 0

16x - 9y + 8 = 0.

  • Persamaan bayangan garis: 16x - 9y + 8 = 0.

Kunci Soal 2:

  • Komposisi matriks: T_total = T2 × T1 = [0 -1; 1 0]
  • det(T_total) = 0 - (-1) = 1
  • Invers: (T_total)⁻¹ = [0 1; -1 0]
  • Hubungan koordinat: x = y' dan y = -x'
  • Substitusi: (y')² + (-x')² = 9 sehingga x² + y² = 9.
  • Persamaan bayangan lingkaran: x² + y² = 9.
