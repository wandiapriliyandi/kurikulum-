Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas12
Semester1
Pertemuan1
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-1: Mengidentifikasi pola nilai fungsi dari arah kiri dan arah kanan suatu titik serta menjelaskan pengertian intuitif limit fungsi di suatu titik secara lisan maupun tertulis melalui tabel hampiran nilai.

Materi Pokok

Pendekatan Intuitif Konsep Limit Fungsi Aljabar

  1. Pengertian Intuitif Limit:

Limit fungsi menjelaskan perilaku nilai f(x) ketika variabel x bergerak mendekati suatu bilangan tertentu c, baik dari arah nilai yang lebih kecil daripada c (hampiran kiri) maupun dari arah nilai yang lebih besar daripada c (hampiran kanan). Limit memperhatikan kecenderungan nilai yang "dihampiri" atau "dituju", bukan semata-mata nilai fungsi tepat di titik c.

  1. Notasi dan Makna:
  • Limit kiri: Jika x mendekati c dari arah kiri (x < c), nilai f(x) mendekati nilai L1.
  • Limit kanan: Jika x mendekati c dari arah kanan (x > c), nilai f(x) mendekati nilai L2.
  • Keberadaan limit: Suatu fungsi f(x) dikatakan memiliki nilai limit L di titik x mendekati c jika dan hanya jika hampiran dari arah kiri sama dengan hampiran dari arah kanan (L1 = L2 = L).
  1. Metode Tabel Nilai (Tabel Hampiran):

Menganalisis barisan masukan nilai x yang semakin rapat menuju titik c:

  • Dari kiri: c - 0,1; c - 0,01; c - 0,001; ...
  • Dari kanan: c + 0,1; c + 0,01; c + 0,001; ...

Kemudian mengamati apakah nilai luaran f(x) berkonvergen (menuju) ke satu bilangan riil yang pasti.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Orientasi dan Pembiasaan:
  • Guru membuka pertemuan dengan salam, doa bersama, dan memeriksa kehadiran santri.
  • Guru mengaitkan semangat menuntut ilmu dengan kebiasaan berdisiplin dan ketelitian dalam berhitung.
  1. Apersepsi & Drill Cepat (Latihan Hitung Singkat 4 Menit):

Guru memberikan 4 soal kilat di papan tulis untuk dijawab serempak atau acak oleh santri:

  • Soal 1: Berapakah hasil dari (2² - 4) ÷ (2 - 2)? (Santri diarahkan menyadari bentuk 0 ÷ 0 tak tentu).
  • Soal 2: Hitung nilai x² - 1 untuk x = 1,1. (Jawaban: 1,21 - 1 = 0,21).
  • Soal 3: Hitung nilai x + 1 untuk x = 0,99. (Jawaban: 1,99).
  • Soal 4: Hitung nilai x + 1 untuk x = 1,01. (Jawaban: 2,01).
  1. Motivasi:

Guru menyampaikan: "Bagaimana jika suatu pembagian menghasilkan penyebut nol di suatu titik, tetapi kita tetap ingin mengetahui ke mana nilai itu mengarah saat mendekati titik tersebut? Hari ini kita mempelajari rahasia konsep limit melalui hampiran kiri dan kanan."

Inti (±100 menit)

Fase 1: Eksplorasi Masalah Kontekstual Pesantren (20 menit)
  • Guru menyajikan narasi kontekstual kehidupan asrama:

"Di dapur umum pesantren, santri piket bertugas menyalurkan kuah sayur dari tong tandon ke panci saji melalui keran pengatur bertekanan. Debit aliran dinyatakan oleh fungsi f(t) = (t² - 9) ÷ (t - 3) liter/menit, dengan t adalah waktu pembukaan keran dalam menit. Pada saat tepat t = 3 menit, jarum sensor mendadak macet dan terbaca 0 ÷ 0. Santri piket ingin mengetahui perkiraan pasti debit aliran tepat sebelum dan sesaat setelah menit ke-3 agar kuah tidak tumpah."

  • Santri diminta mendiskusikan apakah tepat pada t = 3 nilainya dapat dihitung langsung secara aritmetika biasa.
Fase 2: Pembentukan Kelompok & Penyelidikan Tabel Hampiran (30 menit)
  • Santri dibagi ke dalam kelompok kecil (3-4 orang per kelompok halaqah).
  • Tiap kelompok dibagikan lembar kerja untuk melengkapi tabel nilai fungsi f(t) = (t² - 9) ÷ (t - 3) di sekitar t = 3:
  • Tabel Hampiran Kiri (t mendekati 3 dari arah lebih kecil):
  • t = 2,8 -> f(t) = (7,84 - 9) ÷ (2,8 - 3) = -1,16 ÷ -0,2 = 5,8
  • t = 2,9 -> f(t) = (8,41 - 9) ÷ (2,9 - 3) = -0,59 ÷ -0,1 = 5,9
  • t = 2,99 -> f(t) = (8,9401 - 9) ÷ (2,99 - 3) = -0,0599 ÷ -0,01 = 5,99
  • t = 2,999 -> f(t) = 5,999
  • Tabel Hampiran Kanan (t mendekati 3 dari arah lebih besar):
  • t = 3,2 -> f(t) = (10,24 - 9) ÷ (3,2 - 3) = 1,24 ÷ 0,2 = 6,2
  • t = 3,1 -> f(t) = (9,61 - 9) ÷ (3,1 - 3) = 0,61 ÷ 0,1 = 6,1
  • t = 3,01 -> f(t) = (9,0601 - 9) ÷ (3,01 - 3) = 0,0601 ÷ 0,01 = 6,01
  • t = 3,001 -> f(t) = 6,001
  • Guru berkeliling memberikan scaffolding bagi kelompok yang mengalami kendala teknis desimal.
Fase 3: Analisis dan Perumusan Konsep (25 menit)
  • Setiap kelompok menganalisis pola angka yang dihasilkan:
  • Dari kiri: 5,8 -> 5,9 -> 5,99 -> 5,999 (mendekati bilangan 6).
  • Dari kanan: 6,2 -> 6,1 -> 6,01 -> 6,001 (mendekati bilangan 6).
  • Guru memandu perumusan:

"Meskipun saat t = 3 menghasilkan bentuk tak tentu (0 ÷ 0), ketika t didekati sedekat-dekatnya dari kiri maupun kanan, nilai fungsi menuju angka yang sama, yaitu 6 liter/menit. Inilah yang disebut limit fungsi."

  • Santri menyederhanakan aljabar: untuk t tidak sama dengan 3, berlaku (t² - 9) ÷ (t - 3) = (t - 3)(t + 3) ÷ (t - 3) = t + 3. Jika t mendekati 3, maka t + 3 mendekati 3 + 3 = 6.
Fase 4: Latihan Mandiri dan Presentasi Halaqah (25 menit)
  • Santri mengerjakan kasus kedua secara mandiri:

Menganalisis nilai f(x) = (x² - 4) ÷ (x - 2) saat x mendekati 2 menggunakan tabel hampiran kiri (x = 1,9; 1,99) dan hampiran kanan (x = 2,1; 2,01).

  • Dua perwakilan santri menuliskan hasil tabel di papan tulis dan mempresentasikan kesimpulan dengan bahasa sendiri.

Penutup (±10 menit)

  1. Rangkuman Bersama:

Guru bersama santri menyimpulkan dua intisari pembelajaran:

  • Nilai limit bukan melihat nilai f(x) tepat pada x = c, melainkan nilai yang dituju oleh f(x) ketika x bergerak sangat dekat ke c.
  • Limit ada jika nilai hampiran kiri sama dengan nilai hampiran kanan.
  1. Refleksi Santri:

Guru menanyakan: "Apa perbedaan mendasar antara menghitung f(c) langsung dengan mencari limit f(x) untuk x mendekati c?"

  1. Tindak Lanjut & Doa:
  • Guru memberikan arahan untuk membaca materi sifat-sifat limit fungsi aljabar pada pertemuan berikutnya.
  • Kelas ditutup dengan doa kafaratul majelis dan salam.

Asesmen

1. Instrumen Asesmen Formatif (Tugas Individu Singkat)

Soal 1:

Diberikan fungsi g(x) = (x² - 16) ÷ (x - 4).

a. Buatlah tabel nilai hampiran kiri untuk x = 3,9 dan x = 3,99.

b. Buatlah tabel nilai hampiran kanan untuk x = 4,1 dan x = 4,01.

c. Berdasarkan kedua tabel, berapakah perkiraan nilai limit g(x) ketika x mendekati 4?

Soal 2:

Jelaskan dengan kalimat Anda sendiri, mengapa nilai limit suatu fungsi saat x mendekati titik c dapat bernilai ada meskipun f(c) tidak terdefinisi (berbentuk 0 ÷ 0)!

2. Kunci dan Rambu Jawaban

  • Soal 1:
  • Bentuk penyederhanaan untuk x ≠ 4: (x - 4)(x + 4) ÷ (x - 4) = x + 4.
  • a. Nilai hampiran kiri:
  • x = 3,9 -> g(3,9) = 3,9 + 4 = 7,9
  • x = 3,99 -> g(3,99) = 3,99 + 4 = 7,99
  • b. Nilai hampiran kanan:
  • x = 4,1 -> g(4,1) = 4,1 + 4 = 8,1
  • x = 4,01 -> g(4,01) = 4,01 + 4 = 8,01
  • c. Dari kiri nilai mendekati 8 dan dari kanan mendekati 8. Maka limit g(x) untuk x mendekati 4 adalah 8.
  • Soal 2:
  • Konsep limit tidak menuntut nilai fungsi terdefinisi tepat di titik c. Limit hanya memantau kecenderungan atau arah nilai f(x) ketika x berada di persekitaran sangat dekat dengan c (hampiran kiri dan kanan). Selama nilai hampiran kiri dan kanan menuju satu bilangan riil yang sama, maka nilai limit tetap ada dan terdefinisi secara konsep limit.
