Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas12
Semester1
Pertemuan9
FaseFase F
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • Santri mampu merasionalkan selisih bentuk akar kuadrat pada limit fungsi aljabar di ketakhinggaan melalui perkalian bentuk sekawan rasional.
  • Santri mampu menghitung nilai limit selisih bentuk akar kuadrat aljabar di ketakhinggaan dengan teliti dan tepat.

Materi Pokok

1. Bentuk Limit Selisih Akar Kuadrat di Tak Hingga

Bentuk umum:

lim (x → ∞) [√(ax² + bx + c) - √(px² + qx + r)]

Substitusi langsung menghasilkan bentuk tak tentu (∞ - ∞). Bentuk ini diselesaikan dengan mengalikan bentuk sekawan rasional.

2. Metode Perkalian Bentuk Sekawan Rasional

Bentuk selisih akar dikalikan sekawannya:

[√(ax² + bx + c) + √(px² + qx + r)] / [√(ax² + bx + c) + √(px² + qx + r)]

Mengingat (u - v)(u + v) = u² - v², pembilang menjadi:

(ax² + bx + c) - (px² + qx + r) = (a - p)x² + (b - q)x + (c - r)

Kemudian pembilang dan penyebut dibagi x (di dalam akar dibagi x²).

3. Kaidah Praktis (a = p)

Jika koefisien a = p:

  • Nilai limit = (b - q) / (2√a)
  • Jika a > p, limit = ∞; jika a < p, limit = -∞

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru mengucap salam, menyapa santri, memeriksa kehadiran, dan memimpin doa belajar.
  2. Apersepsi: Mengaitkan konsep limit tak hingga dengan keteraturan alam dan pemodelan kestabilan fasilitas di pondok pesantren.
  3. Drill Cepat (5 Menit):
  • Guru memberikan 3 soal hitung cepat di papan tulis:
  • Hitung: √16x² - √9x² untuk x = 5.
  • Tentukan sekawan dari [√(x + 4) - √x].
  • Hitung nilai: (8x - 2x) / 3x untuk x → ∞.
  • Santri menjawab cepat di buku coretan, guru memberi umpan balik langsung.
  1. Penyampaian Tujuan: Guru menyampaikan fokus materi hari ini, yaitu merasionalkan selisih akar kuadrat dan menentukan nilai limitnya.

Inti (±100 menit)

Langkah 1: Orientasi Masalah Kontekstual Pesantren (15 menit)
  • Guru menyajikan masalah nyata kebutuhan tandon air wudhu santri sebelum Subuh:

Pasokan pompa utama: V1(t) = √(4t² + 8t + 5) m³. Pemakaian santri: V2(t) = √(4t² - 4t + 1) m³ setelah t menit.

  • Guru memantik: "Berapa selisih volume air antara pasokan dan pemakaian jika pompa bekerja sangat lama (t mendekati tak hingga)?"
Langkah 2: Pemodelan Aljabar dan Demonstrasi (25 menit)
  • Guru mendemonstrasikan metode perkalian sekawan di papan tulis:
  1. Tulis limit: lim (t → ∞) [√(4t² + 8t + 5) - √(4t² - 4t + 1)]
  2. Kalikan sekawan:

[√(4t² + 8t + 5) + √(4t² - 4t + 1)] / [√(4t² + 8t + 5) + √(4t² - 4t + 1)]

  1. Sederhanakan pembilang:

(4t² + 8t + 5) - (4t² - 4t + 1) = 8t - (-4t) + 5 - 1 = 12t + 4

  1. Bagi dengan t (di dalam akar dibagi t²):

Pembilang: 12 + 4/t

Penyebut: √(4 + 8/t + 5/t²) + √(4 - 4/t + 1/t²)

  1. Nilai limit t → ∞:

(12 + 0) / (√4 + √4) = 12 / (2 + 2) = 12 / 4 = 3 m³.

  • Santri menyimpulkan sisa tandon air stabil di angka 3 m³.
Langkah 3: Latihan Kelompok Halaqah (35 menit)
  • Santri belajar dalam kelompok halaqah (4-5 santri per kelompok):
  • Kelompok A: lim (x → ∞) [√(9x² + 18x - 2) - √(9x² - 6x + 5)]
  • Kelompok B: lim (x → ∞) [√(x² + 6x + 4) - √(x² - 2x + 1)]
  • Kelompok C: lim (x → ∞) [√(4x² + 5x) - 2x]
  • Santri berdiskusi aktif dan saling memeriksa tanda aljabar. Guru berkeliling mendampingi.
Langkah 4: Pembahasan dan Verifikasi Rumus Praktis (25 menit)
  • Perwakilan halaqah menuliskan jawaban di papan tulis.
  • Guru memverifikasi hasil dengan rumus (b - q) / (2√a):

Untuk Kelompok A: a = 9, b = 18, q = -6 → L = (18 - (-6)) / (2√9) = 24 / 6 = 4.

  • Santri membuktikan bahwa hasil rasionalisasi sekawan selaras dengan rumus praktis.

Penutup (±10 menit)

  1. Rangkuman: Guru bersama santri merangkum metode perkalian sekawan dan ketelitian tanda aljabar.
  2. Kuis Mandiri: Santri mengerjakan satu soal kilat di buku masing-masing.
  3. Penutup: Doa penutup majelis dan salam.

Asesmen

1. Soal Latihan Mandiri

  1. Hitung nilai limit:

lim (x → ∞) [√(x² + 8x - 2) - √(x² + 2x + 6)]

  1. Hitung nilai limit:

lim (x → ∞) [√(9x² + 12x + 3) - √(9x² - 6x + 2)]

  1. Masalah Pesantren: Model stok beras dapur (kg) terhadap jumlah santri x:

B(x) = √(16x² + 40x + 7) - √(16x² - 8x + 1)

Tentukan nilai limit B(x) saat x mendekati tak hingga.

2. Kunci dan Rambu Jawaban

  • Nomor 1:

Pembilang sekawan: (x² + 8x - 2) - (x² + 2x + 6) = 6x - 8.

Bagi x: Limit = 6 / (√1 + √1) = 6 / 2 = 3.

(Verifikasi rumus: (8 - 2) / (2√1) = 3).

  • Nomor 2:

Pembilang sekawan: (9x² + 12x + 3) - (9x² - 6x + 2) = 18x + 1.

Bagi x: Limit = 18 / (√9 + √9) = 18 / 6 = 3.

(Verifikasi rumus: (12 - (-6)) / (2√9) = 3).

  • Nomor 3:

Pembilang sekawan: (16x² + 40x + 7) - (16x² - 8x + 1) = 48x + 6.

Bagi x: Limit = 48 / (√16 + √16) = 48 / 8 = 6 kg beras.

(Verifikasi rumus: (40 - (-8)) / (2√16) = 6 kg).

3. Kriteria Ketuntasan

  • Tuntas Penuh (Skor 85 - 100): Langkah sekawan lengkap, pembagian variabel x runtut, hasil akhir benar ketiga soal.
  • Tuntas (Skor 75 - 84): Memahami langkah sekawan, hitungan benar minimal 2 soal (KKTP ≥ 75).
  • Belum Tuntas (Skor < 75): Salah konsep sekawan atau keliru tanda aljabar; diberikan bimbingan halaqah asrama malam.

Media dan Sumber Belajar

  • Papan Tulis dan Spidol: Untuk demonstrasi hitung aljabar dan drill cepat.
  • Lembar Kerja Santri (LKS): Memuat soal kontekstual tandon air dan logistik dapur pesantren.
  • Buku Matematika SMA/MA Kelas 12: Materi Limit Fungsi Aljabar di Ketakhinggaan.

Catatan Refleksi Guru

  • Apakah seluruh santri aktif dalam diskusi halaqah atau masih didominasi santri tertentu?
  • Apakah santri sudah teliti pada operasi pengurangan tanda aljabar di dalam kurung?
  • Apakah pemahaman rasionalisasi sekawan sudah mantap sebelum santri memakai rumus cepat?
  • Rencana tindak lanjut: Pendampingan tutor sebaya di asrama bagi santri yang belum tuntas.
