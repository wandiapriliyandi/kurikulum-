Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-4: Peserta didik mampu menguji tiga syarat kekontinuan fungsi aljabar di suatu titik tertentu serta mengidentifikasi grafik fungsi kontinu dan diskontinu (lubang/terlepas, loncatan, dan asimtotik/tak terhingga) dalam konteks pemecahan masalah kehidupan sehari-hari santri.

Materi Pokok

Kekontinuan fungsi di suatu titik merupakan konsep dasar kalkulus yang menjamin tidak adanya jeda, patahan, lubang, maupun lompatan mendadak pada nilai fungsi.

1. Tiga Syarat Kekontinuan Fungsi di Suatu Titik

Suatu fungsi aljabar f(x) dikatakan kontinu di titik x = c jika dan hanya jika memenuhi tiga syarat berikut secara serentak:

  1. Nilai fungsi terdefinisi di x = c: f(c) ada dan bernilai bilangan riil tertentu.
  2. Nilai limit fungsi ada di x = c: limit (x → c) f(x) ada, yang berarti limit kiri sama dengan limit kanan, yaitu:

limit (x → c⁻) f(x) = limit (x → c⁺) f(x) = L.

  1. Nilai limit sama dengan nilai fungsi:

limit (x → c) f(x) = f(c).

Apabila minimal satu dari ketiga syarat tersebut tidak terpenuhi, maka fungsi f(x) dikatakan diskontinu (tidak kontinu) di titik x = c.

2. Interpretasi Grafis dan Jenis-Jenis Diskontinuitas

Secara grafis, kurva fungsi kontinu dapat digambar secara utuh tanpa mengangkat ujung pena dari kertas. Jika kurva terputus di x = c, terdapat tiga karakteristik utama diskontinuitas:

  • Diskontinuitas Titik / Lubang (Removable Discontinuity):

Limit fungsi limit (x → c) f(x) ada, namun nilai fungsi f(c) tidak terdefinisi atau f(c) ≠ limit (x → c) f(x). Grafiknya tampak memiliki lubang (lingkaran kosong) pada kurva.

  • Diskontinuitas Loncatan (Jump Discontinuity):

Limit kiri dan limit kanan keduanya ada tetapi nilainya tidak sama (limit x → c⁻ f(x) ≠ limit x → c⁺ f(x)). Grafiknya tampak terputus dengan lompatan nilai secara vertikal. Sering ditemui pada fungsi tangga atau fungsi sepotong-sepotong (piecewise).

  • Diskontinuitas Asimtotik / Tak Hingga (Infinite Discontinuity):

Nilai fungsi menuju positif tak hingga (+∞) atau negatif tak hingga (-∞) saat x mendekati c dari salah satu atau kedua sisi. Grafiknya terpisah oleh garis asimtot tegak x = c.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru membuka kelas dengan salam, doa bersama, sapaan santun, dan memeriksa kehadiran santri di kelas.
  2. Drill Cepat Berhitung (±5 menit):

Guru memberikan 4 soal hitung kilat di papan tulis untuk dijawab langsung secara lisan/cepat oleh santri:

  • Hitung nilai f(2) untuk f(x) = 3x² - 5x + 1. (Jawaban: 3)
  • Tentukan nilai limit (x → 3) [(x² - 9) / (x - 3)]. (Jawaban: 6)
  • Tentukan apakah pecahan f(1) = (2x + 4) / (x - 1) terdefinisi saat x = 1. (Jawaban: Tidak terdefinisi / penyebut nol)
  • Jika limit kiri bernilai 4 dan limit kanan bernilai 7 di titik x = 2, apakah nilai limitnya ada? (Jawaban: Tidak ada)
  1. Apersepsi & Motivasi: Guru mengaitkan konsep kontinu dengan aliran air wudu pondok atau kontinuitas daya listrik pesantren yang tidak boleh terputus atau melonjak mendadak.

Inti (±100 menit)

Fase 1: Orientasi Masalah Kontekstual Santri (15 menit)

Guru memaparkan dua kasus kontekstual di lingkungan pondok pesantren:

  1. Kasus 1: Pengisian Bak Mandi Asrama Santri

Sebuah kran otomatis mengalirkan air ke bak mandi asrama. Ketinggian air h(t) dalam satuan cm setelah t menit dimodelkan oleh fungsi:

  • h(t) = 4t + 10 untuk 0 ≤ t < 5
  • h(t) = 6t untuk 5 ≤ t ≤ 10

Santri diajak meneliti: Apakah proses pengisian air ini berjalan mulus dan kontinu saat tepat menit ke-5, atau terjadi lonjakan mendadak?

  1. Kasus 2: Tarif Iuran Paket Beras Koperasi Santri

Koperasi pesantren membuat fungsi biaya subsidi beras f(x) = (x² - 16) / (x - 4) ribu rupiah per kilogram untuk pembelian x kg, dengan penetapan khusus di meja kasir bahwa untuk pembelian x = 4 kg ditetapkan seharga 8 ribu rupiah. Apakah sistem perhitungan kasir ini kontinu di x = 4?

Fase 2: Eksplorasi Terbimbing dalam Halaqah (25 menit)
  1. Santri duduk dalam kelompok kecil (halaqah belajar) yang terdiri atas 3–4 santri.
  2. Guru membagikan lembar kerja kelompok untuk membedah syarat kekontinuan pada Kasus 1:
  • Menguji Syarat 1: Menghitung h(5) = 6(5) = 30 cm (terdefinisi).
  • Menguji Syarat 2: Menghitung limit kiri limit (t → 5⁻) (4t + 10) = 4(5) + 10 = 30, dan limit kanan limit (t → 5⁺) (6t) = 6(5) = 30. Karena limit kiri = limit kanan = 30, maka limit (t → 5) h(t) = 30 (limit ada).
  • Menguji Syarat 3: Memeriksa apakah limit (t → 5) h(t) = h(5). Karena 30 = 30, maka ketiga syarat terpenuhi.
  • Kesimpulan: Aliran air kontinu di t = 5 menit (tidak ada genangan meluap atau penurunan mendadak).
  1. Santri mendiskusikan grafik Kasus 2: Mengidentifikasi lubang pada x = 4 dari kurva f(x) = (x² - 16) / (x - 4) yang ditambal tepat oleh nilai f(4) = 8.
Fase 3: Analisis Jenis-Jenis Diskontinuitas & Uji Tiga Syarat (30 menit)
  1. Guru menyajikan tiga fungsi aljabar yang mewakili tiga model kurva:
  • Model Lubang: g(x) = (x² - 1) / (x - 1). Di titik x = 1, nilai g(1) tidak terdefinisi (0/0), padahal limit (x → 1) g(x) = 2. Kurva memiliki lubang di (1, 2).
  • Model Loncatan: Fungsi pembagian jadwal piket dapur P(x):

P(x) = 2x + 1 untuk x < 3, dan P(x) = x² - 4 untuk x ≥ 3.

Uji di x = 3: limit kiri = 2(3) + 1 = 7, sedangkan limit kanan = 3² - 4 = 5. Karena 7 ≠ 5, nilai limit tidak ada. Terjadi diskontinuitas loncatan setinggi 2 satuan.

  • Model Asimtotik: k(x) = 2 / (x - 4). Di titik x = 4, nilai fungsi tidak terdefinisi, dan limit mendekati +∞ atau -∞. Garis x = 4 adalah asimtot tegak kurva.
  1. Setiap halaqah menggambarkan sketsa grafik kasar masing-masing model di kertas plano atau papan kecil halaqah.
Fase 4: Presentasi Halaqah & Verifikasi (20 menit)
  1. Dua perwakilan halaqah maju ke depan kelas untuk mempresentasikan pengujian 3 syarat pada fungsi yang diberikan dan menunjukkan bentuk grafiknya di papan tulis grid.
  2. Halaqah lain saling menanggapi, memeriksa ketelitian faktorisasi aljabar, dan memvalidasi penulisan uji tiga syarat kekontinuan.
  3. Guru memberikan penguatan konsep, meluruskan kekeliruan umum (seperti menyamakan nilai fungsi f(c) dengan nilai limit limit x → c), serta mengapresiasi keaktifan santri.
Fase 5: Latihan Mandiri / Latihan Terfokus (10 menit)

Santri secara mandiri mengerjakan 2 soal latihan cepat di buku catatan masing-masing:

  • Uji kekontinuan fungsi f(x) = x² - 3x + 2 di titik x = 2.
  • Tentukan nilai konstanta k agar fungsi g(x) = {kx + 1 untuk x ≤ 2; 3x - 1 untuk x > 2} menjadi kontinu di x = 2.

Penutup (±10 menit)

  1. Rangkuman Bersama: Guru bersama santri menyimpulkan intisari materi:
  • Tiga syarat kekontinuan: f(c) ada, limit f(x) ada, dan f(c) = limit f(x).
  • Tiga tipe diskontinu: lubang (dapat diperbaiki), loncatan (limit sepihak beda), dan asimtotik (meledak ke tak hingga).
  1. Refleksi Santri: Guru menanyakan satu pertanyaan refleksi santri: "Apa perbedaan paling mendasar antara nilai f(a) dan limit f(x) saat x mendekati a?"
  2. Tindak Lanjut: Guru memberikan instruksi penugasan rumah pengayaan dan menyampaikan topik pertemuan selanjutnya.
  3. Penutup Doa: Sesi belajar diakhiri dengan melafalkan doa kafaratul majelis bersama-sama dan salam penutup.

Asesmen

1. Soal Latihan & Evaluasi

  1. Soal 1 (Uji Syarat Kekontinuan):

Diberikan fungsi rasional f(x) = (x² - 4) / (x - 2).

Ujilah apakah f(x) kontinu di titik x = 2 dengan memeriksa ketiga syarat kekontinuan! Jika diskontinu, sebutkan jenis ketak-kontinuannya!

  1. Soal 2 (Fungsi Sepotong-sepotong / Kontekstual Pesantren):

Daya tampung air di bak wudu santri dinyatakan dengan fungsi:

  • V(x) = x² + 2 untuk x < 3
  • V(x) = 4x - 1 untuk x ≥ 3

Selidikilah apakah fungsi V(x) kontinu di titik peralihan x = 3!

  1. Soal 3 (Penentuan Parameter Kontinuitas):

Tentukan nilai k agar fungsi berikut kontinu di x = 1:

  • g(x) = 3x + k untuk x ≤ 1
  • g(x) = 2x² + 5 untuk x > 1
  1. Soal 4 (Identifikasi Grafik):

Diberikan fungsi h(x) = 1 / (x - 2). Jelaskan mengapa fungsi h(x) diskontinu di x = 2 dan sebutkan bentuk grafiknya di sekitar titik tersebut!

2. Kunci dan Rambu Jawaban

  • Rambu Jawaban Soal 1:
  • Syarat 1: f(2) = (2² - 4) / (2 - 2) = 0/0 (tidak terdefinisi). Syarat 1 gagal.
  • Syarat 2: limit (x → 2) [(x - 2)(x + 2) / (x - 2)] = limit (x → 2) (x + 2) = 2 + 2 = 4 (limit ada).
  • Syarat 3: Karena f(2) tidak terdefinisi, f(2) ≠ limit (x → 2) f(x).
  • Kesimpulan: Fungsi f(x) diskontinu di x = 2 dengan jenis diskontinuitas lubang (removable/titik). (Skor: 25)
  • Rambu Jawaban Soal 2:
  • Syarat 1: V(3) = 4(3) - 1 = 12 - 1 = 11 (terdefinisi).
  • Syarat 2:
  • Limit kiri: limit (x → 3⁻) (x² + 2) = 3² + 2 = 11.
  • Limit kanan: limit (x → 3⁺) (4x - 1) = 4(3) - 1 = 11.
  • Karena limit kiri = limit kanan = 11, maka limit (x → 3) V(x) = 11 (limit ada).
  • Syarat 3: limit (x → 3) V(x) = V(3) = 11.
  • Kesimpulan: Fungsi V(x) kontinu di titik x = 3. (Skor: 25)
  • Rambu Jawaban Soal 3:
  • Agar kontinu di x = 1, syarat yang harus dipenuhi: limit (x → 1⁻) g(x) = limit (x → 1⁺) g(x) = g(1).
  • Nilai g(1) = 3(1) + k = 3 + k.
  • Limit kiri: limit (x → 1⁻) (3x + k) = 3 + k.
  • Limit kanan: limit (x → 1⁺) (2x² + 5) = 2(1)² + 5 = 7.
  • Samakan limit kiri dan limit kanan: 3 + k = 7, diperoleh k = 7 - 3 = 4.
  • Kesimpulan: Nilai k yang memenuhi adalah 4. (Skor: 25)
  • Rambu Jawaban Soal 4:
  • Pada x = 2, nilai h(2) = 1 / 0 (tidak terdefinisi dalam bilangan riil).
  • Limit kiri limit (x → 2⁻) 1 / (x - 2) = -∞, limit kanan limit (x → 2⁺) 1 / (x - 2) = +∞. Nilai limit tidak ada karena membesar tanpa batas.
  • Kesimpulan: Fungsi h(x) mengalami diskontinuitas asimtotik (tak hingga) di titik x = 2 dengan garis x = 2 sebagai asimtot tegak kurva. (Skor: 25)
