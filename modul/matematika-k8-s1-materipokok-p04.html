Modul Ajar — Matematika (Materi Pokok)

Identitas

KomponenKeterangan
Mata PelajaranMatematika (Materi Pokok)
Kelas8
Semester1
PertemuanKe-4
FaseFase D
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-2: Peserta didik mampu menentukan rumus suku ke-n pada barisan bilangan bertingkat konstan sederhana untuk memprediksi nilai suku berikutnya.
  • Indikator Ketercapaian TP:
  1. Menghitung nilai selisih tingkat pertama dan selisih konstan tingkat kedua.
  2. Memprediksi nilai suku ke-n barisan bertingkat dua secara sistematis.

Materi Pokok

Barisan bertingkat dua merupakan barisan bilangan yang selisih antarsukunya belum tetap pada tingkat pertama, namun bernilai konstan pada tingkat kedua.

Bentuk umum rumus suku ke-n:

Un = a × n² + b × n + c

Hubungan nilai koefisien dengan suku barisan:

  1. 2a = selisih konstan tingkat kedua
  2. 3a + b = selisih pertama pada tingkat ke-1 (U2 - U1)
  3. a + b + c = suku pertama barisan (U1)

Langkah menentukan rumus dan prediksi suku:

  • Hitung selisih antarsuku berurutan (tingkat ke-1).
  • Hitung selisih dari deretan selisih tersebut (tingkat ke-2) hingga diperoleh nilai konstan.
  • Tentukan nilai a dari 2a, lalu nilai b dari 3a + b, dan nilai c dari a + b + c.
  • Tuliskan rumus Un = a × n² + b × n + c, lalu substitusikan nilai n untuk memprediksi suku yang dicari.

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan: Guru memberi salam, memeriksa kehadiran, dan memimpin doa bersama santri.
  2. Drill Cepat (Hitung Singkat):
  • Guru memberikan latihan hitung lisan dan cepat di papan tulis:
  • 4² = 16, 5² = 25, 6² = 36.
  • Hitung selisih: 11 - 4 = 7; 20 - 11 = 9; selisih lanjut: 9 - 7 = 2.
  • Drill bertujuan menyegarkan kemampuan operasi hitung dasar santri.
  1. Apersepsi: Guru mengaitkan materi pola bilangan aritmetika bertingkat dengan keteraturan susunan benda di asrama/pesantren. Guru menyampaikan tujuan pembelajaran hari ini.

Inti (±100 menit)

1. Orientasi Masalah Kontekstual Pesantren (15 menit)

Guru menyajikan persoalan penataan kitab kuning di maktabah (perpustakaan) pesantren:

"Santri menyusun kitab pada rak bertingkat untuk haul madrasah. Baris ke-1 memuat 2 kitab, baris ke-2 memuat 6 kitab, baris ke-3 memuat 12 kitab, dan baris ke-4 memuat 20 kitab. Berapakah kitab pada baris ke-10?"

Santri mencermati susunan angka: 2, 6, 12, 20.

2. Eksplorasi Selisih Bertingkat (20 menit)

Santri dalam kelompok meneliti selisih antarsuku:

  • Barisan awal: 2, 6, 12, 20
  • Selisih tingkat 1: 6 - 2 = 4; 12 - 6 = 6; 20 - 12 = 8
  • Selisih tingkat 2: 6 - 4 = 2; 8 - 6 = 2

Santri menemukan bahwa selisihnya bernilai konstan (2) pada tingkat kedua.

3. Perumusan Formula Kuadrat (25 menit)

Guru membimbing santri merumuskan Un = a × n² + b × n + c:

  • 2a = 2, sehingga a = 1
  • 3a + b = 4 -> 3(1) + b = 4 -> b = 1
  • a + b + c = 2 -> 1 + 1 + c = 2 -> c = 0

Didapatkan rumus: Un = n² + n.

Santri menguji nilai rumus: U1 = 1² + 1 = 2; U2 = 2² + 2 = 6 (sesuai).

Santri memprediksi baris ke-10: U10 = 10² + 10 = 100 + 10 = 110 kitab.

4. Latihan Terbimbing Kehidupan Santri (25 menit)

Santri menyelesaikan masalah formasi shaf halaqah santri dengan barisan: 3, 8, 15, 24, ...

  • Selisih tingkat 1: 5, 7, 9
  • Selisih tingkat 2: 2, 2 (konstan)
  • Perhitungan koefisien:

2a = 2 -> a = 1

3(1) + b = 5 -> b = 2

1 + 2 + c = 3 -> c = 0

  • Rumus suku ke-n: Un = n² + 2n
  • Prediksi suku ke-7 (U7): 7² + 2(7) = 49 + 14 = 63 santri.
5. Evaluasi Formatif Singkat (15 menit)

Santri mengerjakan soal latihan mandiri untuk mengukur pemahaman perumusan barisan bertingkat dua. Guru berkeliling memberi arahan bagi santri yang membutuhkan bantuan.

Penutup (±10 menit)

  1. Refleksi & Simpulan: Santri menyimpulkan langkah mencari rumus kuadrat suku ke-n barisan bertingkat dua menggunakan nilai 2a, 3a + b, dan a + b + c.
  2. Umpan Balik: Guru mengapresiasi partisipasi santri dan menegaskan pentingnya ketelitian berhitung.
  3. Doa Penutup: Pembelajaran ditutup dengan membaca hamdalah, doa kafaratul majelis, dan salam.

Asesmen

1. Soal Latihan Mandiri

Soal 1:

Diberikan barisan bilangan: 4, 9, 16, 25, ...

a. Hitung selisih tingkat pertama dan selisih konstan tingkat kedua!

b. Tentukan rumus suku ke-n (Un)!

c. Prediksikan nilai suku ke-10 (U10)!

Soal 2:

Jumlah sajadah pada barisan sholat tarawih bertambah dengan pola: 5, 11, 19, 29, ...

a. Hitung selisih tingkat pertama dan selisih konstan tingkat kedua!

b. Tentukan rumus suku ke-n (Un)!

c. Prediksikan banyak sajadah pada baris ke-8 (U8)!

2. Kunci dan Rambu Jawaban

Kunci Soal 1:

a. Selisih tingkat 1: 5, 7, 9. Selisih tingkat 2: 2, 2 (konstan bernilai 2).

b. Mencari koefisien:

  • 2a = 2 -> a = 1
  • 3(1) + b = 5 -> b = 2
  • 1 + 2 + c = 4 -> c = 1

Rumus: Un = n² + 2n + 1

c. Prediksi U10:

  • U10 = 10² + 2(10) + 1 = 100 + 20 + 1 = 121.

Kunci Soal 2:

a. Selisih tingkat 1: 6, 8, 10. Selisih tingkat 2: 2, 2 (konstan bernilai 2).

b. Mencari koefisien:

  • 2a = 2 -> a = 1
  • 3(1) + b = 6 -> b = 3
  • 1 + 3 + c = 5 -> c = 1

Rumus: Un = n² + 3n + 1

c. Prediksi U8:

  • U8 = 8² + 3(8) + 1 = 64 + 24 + 1 = 89 sajadah.
