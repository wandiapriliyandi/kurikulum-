Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas9
Semester1 (Ganjil)
PertemuanKe-10
FaseFase D
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-5: Santri mampu mengidentifikasi bentuk umum persamaan kuadrat satu variabel serta menentukan nilai koefisien a, b, dan konstanta c dari berbagai bentuk persamaan kuadrat secara teliti dan mandiri.

Materi Pokok

1. Definisi dan Bentuk Umum Persamaan Kuadrat

Persamaan kuadrat satu variabel adalah kalimat terbuka matematika yang menyatakan hubungan sama dengan (=) dan memiliki variabel dengan pangkat tertinggi adalah dua.

Bentuk baku (umum) persamaan kuadrat dinyatakan sebagai:

ax² + bx + c = 0

Keterangan:

  • x adalah variabel (peubah).
  • a adalah koefisien dari x², dengan syarat mutlak a ≠ 0 dan a bilangan real.
  • b adalah koefisien dari x, dengan b bilangan real.
  • c adalah konstanta (suku tetap), dengan c bilangan real.

2. Mengubah Persamaan ke Bentuk Baku

Sering kali persamaan kuadrat tidak tersaji langsung dalam bentuk baku ax² + bx + c = 0. Untuk menentukan koefisien a, b, dan konstanta c dengan tepat, persamaan harus diubah terlebih dahulu menggunakan operasi aljabar (penjumlahan, pengurangan, perkalian distributif, pengelompokan suku sejenis) hingga ruas kanan bernilai 0.

Contoh transformasi:

  1. Bentuk: 2x² = 5x - 3

Pindahkan semua suku ke ruas kiri:

2x² - 5x + 3 = 0

Maka diperoleh: a = 2, b = -5, c = 3.

  1. Bentuk: x(x + 4) = 12

Jabarkan perkalian distributif terlebih dahulu:

x² + 4x = 12

Kurangkan 12 pada kedua ruas:

x² + 4x - 12 = 0

Maka diperoleh: a = 1, b = 4, c = -12.

  1. Bentuk persamaan kuadrat tidak lengkap:
  • x² - 9 = 0 → a = 1, b = 0, c = -9 (tidak memiliki suku x).
  • 3x² + 6x = 0 → a = 3, b = 6, c = 0 (tidak memiliki konstanta c).

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Pembukaan & Doa (2 menit): Guru membuka pertemuan dengan salam, memeriksa kehadiran santri, dan memimpin doa bersama agar pembelajaran membawa berkah dan kemudahan pemahaman.
  2. Drill Cepat Berhitung (5 menit):
  • Guru memberikan 5 butir soal hitung cepat secara lisan/tulis di papan tulis mengenai operasi bilangan bulat dan perkalian aljabar dasar:
  1. (-7) + 12 = ... (Jawaban: 5)
  2. 4 × (-6) = ... (Jawaban: -24)
  3. 3x × 2x = ... (Jawaban: 6x²)
  4. 5(x - 3) = ... (Jawaban: 5x - 15)
  5. Nilai 4² - 3² = ... (Jawaban: 7)
  • Santri menjawab langsung di buku catatan kecil secara sigap dalam tempo 3 menit, lalu dicocokkan bersama selama 2 menit.
  1. Apersepsi & Motivasi (3 menit):
  • Guru mengaitkan materi aljabar linear sebelumnya dengan bentuk aljabar berpangkat dua.
  • Guru menyampaikan tujuan pembelajaran hari ini, yaitu mengenali bentuk umum persamaan kuadrat dan menentukan nilai a, b, dan c.

Inti (±100 menit)

Tahap 1: Orientasi Masalah Kontekstual Pesantren (15 menit)
  1. Guru menyajikan studi kasus kontekstual yang akrab dalam kehidupan pondok pesantren:

*Masalah*: Santri bagian kebersihan dan pertamanan pondok hendak membuat pembatas taman apotek hidup di samping asrama santri. Taman tersebut dirancang berbentuk persegi panjang. Luas area taman yang direncanakan adalah 60 m². Panjang taman tersebut dibuat 4 meter lebih panjang daripada lebarnya.

  1. Guru memandu santri memodelkan masalah ke dalam matematika:
  • Misalkan lebar taman = x meter.
  • Maka panjang taman = (x + 4) meter.
  • Rumus luas persegi panjang: Panjang × Lebar = Luas
  • (x + 4) × x = 60
  • x² + 4x = 60
  1. Guru mengajukan pertanyaan pemantik: *"Bagaimana bentuk persamaan ini jika ruas kanan dijadikan nol? Mengapa persamaan ini berbeda dengan persamaan linear satu variabel yang dipelajari di kelas 7 dan 8?"*
  2. Santri mengamati bahwa variabel x berpangkat dua dan persamaan dapat ditulis menjadi x² + 4x - 60 = 0.
Tahap 2: Pembahasan Konsep & Bentuk Baku ax² + bx + c = 0 (25 menit)
  1. Guru membedah struktur bentuk baku ax² + bx + c = 0 di papan tulis.
  2. Santri diperkenalkan pada komponen utama:
  • Koefisien x² adalah a (tidak boleh nol).
  • Koefisien x adalah b (bisa bernilai nol jika suku x tidak ada).
  • Konstanta adalah c (bisa bernilai nol jika suku tanpa variabel tidak ada).
  1. Guru mendemonstrasikan beberapa contoh pemindahan ruas dan perkalian aljabar:
  • Kasus koefisien bertanda negatif: -x² + 7x - 10 = 0 → a = -1, b = 7, c = -10.
  • Kasus pecahan aljabar sederhana: x + (6 ÷ x) = 5 (dikalikan x pada kedua ruas) menjadi x² - 5x + 6 = 0 → a = 1, b = -5, c = 6.
  1. Guru menekankan ketelitian tanda positif (+) dan negatif (-) di depan angka saat menentukan nilai a, b, dan c.
Tahap 3: Kerja Kelompok & Pemecahan Masalah Aljabar (30 menit)
  1. Santri dibagi menjadi beberapa kelompok halaqah kecil yang terdiri atas 3–4 orang santri.
  2. Guru membagikan lembar kerja berisi masalah kontekstual pesantren dan latihan manipulasi bentuk aljabar:
  • *Kasus Halaqah 1*: Panitia qurban pondok mengukur terpal penampungan rumput berbentuk persegi panjang seluas 40 m². Panjang terpal 3 meter lebih dari lebarnya. Nyatakan dalam bentuk umum ax² + bx + c = 0 dan tentukan nilai a, b, dan c!
  • *Kasus Halaqah 2*: Koperasi santri memesan rak buku. Hasil kali dua nomor rak berurutan adalah 156. Modelkan ke bentuk umum persamaan kuadrat satu variabel!
  • *Latihan Keterampilan Bentuk Baku*:

a. 3x² = 12 - 5x

b. (2x - 1)(x + 3) = 0

c. 4x² - 25 = 0

d. 2x(x - 4) = x + 7

  1. Santri berdiskusi aktif dalam halaqah masing-masing, saling mengecek tanda bilangan dan perpindahan ruas aljabar.
  2. Guru berkeliling memberikan scaffolding (bimbingan terarah) bagi kelompok yang menemui kendala pada penjabaran distributif atau tanda negatif.
Tahap 4: Presentasi & Verifikasi Kelas (20 menit)
  1. Dua perwakilan kelompok halaqah maju ke depan untuk menuliskan proses penyelesaian dan bentuk baku dari soal kontekstual dan latihan teknis.
  2. Santri dari kelompok lain memberikan tanggapan, mencocokkan hasil perhitungan kelompoknya, serta mengkritisi ketepatan penentuan nilai a, b, dan c.
  3. Guru mengklarifikasi miskonsepsi umum, seperti anggapan bahwa koefisien x² adalah 0 jika tertulis x² saja (seharusnya 1), atau lupa menyertakan tanda minus pada koefisien/konstanta.
Tahap 5: Latihan Mandiri / Asesmen Formatif Singkat (10 menit)
  1. Santri kembali ke bangku masing-masing.
  2. Guru memberikan 3 butir soal latihan mandiri untuk menguji pemahaman individu tanpa bantuan teman satu halaqah.

Penutup (±10 menit)

  1. Rangkuman (4 menit):
  • Guru bersama santri menyimpulkan intisari materi:
  • Persamaan kuadrat satu variabel berpangkat tertinggi 2.
  • Bentuk baku selalu beruas kanan nol: ax² + bx + c = 0 dengan syarat a ≠ 0.
  • Penentuan koefisien a, b, dan c harus teliti menyertakan tanda di depan bilangannya.
  1. Refleksi Santri (3 menit):
  • Santri menyampaikan bagian yang paling mudah dipahami dan bagian yang masih membutuhkan latihan tambahan (misalnya perkalian dua suku aljabar).
  1. Tindak Lanjut & Penutup (3 menit):
  • Guru memberikan informasi materi pertemuan ke-11: Menyelesaikan persamaan kuadrat dengan metode pemfaktoran.
  • Pembelajaran ditutup dengan doa kafaratul majelis dan salam.

Asesmen

1. Soal Latihan Mandiri (Formatif Singkat)

Ubahlah persamaan-persamaan berikut ke dalam bentuk baku ax² + bx + c = 0, kemudian tentukan nilai a, b, dan c!

  1. 2x² = 7x - 6
  2. x(3x + 5) = 8
  3. 5x² - 20 = 0
  4. (x - 2)(x + 4) = 7

2. Kunci dan Rambu Jawaban

  1. Soal 1:
  • Persamaan: 2x² = 7x - 6
  • Pindahkan ke ruas kiri: 2x² - 7x + 6 = 0
  • Nilai: a = 2, b = -7, c = 6.
  1. Soal 2:
  • Persamaan: x(3x + 5) = 8
  • Kalikan distributif: 3x² + 5x = 8
  • Pindahkan ke ruas kiri: 3x² + 5x - 8 = 0
  • Nilai: a = 3, b = 5, c = -8.
  1. Soal 3:
  • Persamaan: 5x² - 20 = 0
  • Bentuk baku: 5x² + 0x - 20 = 0
  • Nilai: a = 5, b = 0, c = -20.
  • *(Catatan: jika disederhanakan dengan membagi 5 menjadi x² - 4 = 0, maka a = 1, b = 0, c = -4; keduanya dibenarkan).*
  1. Soal 4:
  • Persamaan: (x - 2)(x + 4) = 7
  • Jabarkan: x² + 4x - 2x - 8 = 7
  • Sederhanakan: x² + 2x - 8 = 7
  • Kurangkan 7 pada kedua ruas: x² + 2x - 15 = 0
  • Nilai: a = 1, b = 2, c = -15.
