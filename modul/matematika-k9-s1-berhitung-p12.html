Modul Ajar — Matematika (Berhitung)

Identitas

KomponenDeskripsi
Mata PelajaranMatematika (Berhitung)
Kelas9
Semester1
PertemuanKe-12
FaseFase D
Alokasi Waktu120 menit (4 JP × 30 menit)

Tujuan Pembelajaran

  • TP-5: Memfaktorkan persamaan kuadrat dengan nilai koefisien utama a selain 1 serta menentukan akar-akar penyelesaian persamaan kuadrat secara teliti.

Materi Pokok

Persamaan kuadrat bentuk baku: ax² + bx + c = 0 dengan a ≠ 0 dan a ≠ 1.

Langkah faktorisasi suku tengah (metode ac):

  1. Menghitung nilai hasil kali a × c.
  2. Menentukan pasangan bilangan bulat p dan q dengan kriteria:

p × q = a × c serta p + q = b

  1. Menguraikan suku tengah bx menjadi px + qx:

ax² + px + qx + c = 0

  1. Mengelompokkan suku dan menarik faktor persekutuan terbesar:

(ax² + px) + (qx + c) = 0 menjadi bentuk (mx + n)(rx + s) = 0

  1. Menyelesaikan akar dengan prinsip hasil kali nol:

mx + n = 0 atau rx + s = 0 sehingga didapat nilai x₁ dan x₂.

Contoh faktorisasi:

2x² + 7x + 3 = 0

  • a = 2, b = 7, c = 3
  • a × c = 6
  • Pasangan bilangan: 1 dan 6 (karena 1 × 6 = 6 dan 1 + 6 = 7)
  • Uraikan: 2x² + 6x + x + 3 = 0
  • Kelompokkan: 2x(x + 3) + 1(x + 3) = 0
  • Bentuk faktor: (2x + 1)(x + 3) = 0
  • Akar penyelesaian: x₁ = -1/2 atau x₂ = -3

Kegiatan Pembelajaran

Pendahuluan (±10 menit)

  1. Salam, presensi santri, dan pembacaan doa pembuka pembelajaran bersama.
  2. Drill Cepat (Apersepsi Singkat ±5 menit):

Guru menguji kelincahan berhitung mental santri mencari pasangan bilangan ac:

  • "Dua bilangan dikali menghasilkan 12 dan dijumlah menghasilkan 7?" (Santri: 3 dan 4)
  • "Dua bilangan dikali menghasilkan -15 dan dijumlah menghasilkan 2?" (Santri: 5 dan -3)
  • "Dua bilangan dikali menghasilkan 24 dan dijumlah menghasilkan -11?" (Santri: -3 dan -8)
  1. Penyampaian tujuan materi pemfaktoran a ≠ 1 dan penerapannya dalam pengukuran lahan fasilitas pondok.

Inti (±100 menit)

  1. Eksplorasi Konsep (20 menit):
  • Guru membahas persamaan 3x² + 10x + 8 = 0.
  • Santri mengidentifikasi a = 3, b = 10, c = 8, dan a × c = 24.
  • Menemukan pasangan bilangan 6 dan 4 (6 × 4 = 24, 6 + 4 = 10).
  • Penguraian suku tengah: 3x² + 6x + 4x + 8 = 0.
  • Pengelompokan: 3x(x + 2) + 4(x + 2) = 0 → (3x + 4)(x + 2) = 0.
  • Menentukan akar persamaan: x₁ = -4/3 atau x₂ = -2.
  1. Pemecahan Masalah Kontekstual Pesantren (25 menit):
  • Kasus: Santri pengurus asrama merapikan lahan jemuran sajadah dan sarung berbentuk persegi panjang dengan panjang (2x + 1) meter, lebar (x + 3) meter, dan luas 36 m².
  • Pemodelan:

(2x + 1)(x + 3) = 36

2x² + 7x + 3 = 36

2x² + 7x - 33 = 0

  • Nilai a × c = 2 × (-33) = -66. Pasangan bilangan adalah 11 dan -6.
  • Pemfaktoran: 2x² - 6x + 11x - 33 = 0 → 2x(x - 3) + 11(x - 3) = 0 → (2x + 11)(x - 3) = 0.
  • Akar: x₁ = -11/2 (tidak berlaku untuk ukuran fisik) dan x₂ = 3 (memenuhi).
  • Ukuran nyata lahan: panjang = 2(3) + 1 = 7 meter, lebar = 3 + 3 = 6 meter.
  1. Latihan Kolaboratif (35 menit):
  • Santri berkelompok berpasangan menyelesaikan lembar kerja:

Kasus A (Panggung Aula): 3x² + 11x - 4 = 0.

Kasus B (Rak Kitab Perpustakaan): 2x² - 9x + 10 = 0.

  • Guru memantau ketelitian tanda positif dan negatif serta penarikan FPB.
  1. Evaluasi dan Pembahasan (20 menit):
  • Perwakilan santri memaparkan penyelesaian di papan tulis.
  • Uji silang kebenaran hasil bersama kelompok lain dan penguatan konsep oleh guru.

Penutup (±10 menit)

  1. Rangkuman bersama mengenai tahapan perkalian ac, pemecahan suku tengah, pemfaktoran, dan pencarian akar.
  2. Refleksi pembelajaran dan kendala berhitung santri.
  3. Pemberian tugas tindak lanjut mandiri.
  4. Doa kafaratul majelis dan salam penutup.

Asesmen

1. Soal Latihan Mandiri

  1. Tentukan akar penyelesaian dari: 2x² + 13x + 15 = 0.
  2. Tentukan akar penyelesaian dari: 3x² - 8x + 4 = 0.
  3. Soal Kontekstual: Kolam ikan lele santri berukuran panjang (3x - 2) meter dan lebar x meter memiliki luas 16 m². Tentukan nilai x dan ukuran panjang serta lebarnya!

2. Kunci dan Rambu Jawaban

  1. Soal 1:
  • a × c = 30; pasangan bilangan: 10 dan 3.
  • 2x² + 10x + 3x + 15 = 0 → 2x(x + 5) + 3(x + 5) = 0 → (2x + 3)(x + 5) = 0.
  • Akar: x₁ = -3/2 dan x₂ = -5.
  1. Soal 2:
  • a × c = 12; pasangan bilangan: -6 dan -2.
  • 3x² - 6x - 2x + 4 = 0 → 3x(x - 2) - 2(x - 2) = 0 → (3x - 2)(x - 2) = 0.
  • Akar: x₁ = 2/3 dan x₂ = 2.
  1. Soal 3:
  • x(3x - 2) = 16 → 3x² - 2x - 16 = 0.
  • a × c = -48; pasangan bilangan: -8 dan 6.
  • 3x² + 6x - 8x - 16 = 0 → 3x(x + 2) - 8(x + 2) = 0 → (3x - 8)(x + 2) = 0.
  • Nilai x₁ = 8/3 (memenuhi) dan x₂ = -2 (tidak memenuhi).
  • Ukuran kolam: lebar = 8/3 meter dan panjang = 6 meter.

3. Kriteria Ketuntasan

  • Sangat Mahir (86 - 100): Menentukan pasangan ac tepat, pemfaktoran benar, dan akar dihitung teliti.
  • Mahir (75 - 85): Langkah pemfaktoran benar dengan sedikit kekeliruan aritmetika sederhana.
  • Cukup (60 - 74): Memahami konsep ac namun kesulitan mengelompokkan suku aljabar.
  • Perlu Bimbingan (< 60): Belum menguasai penentuan faktor perkalian dan manipulasi aljabar.

Ketuntasan minimal ditetapkan pada nilai 75.

Media dan Sumber Belajar

  1. Media: Papan tulis, spidol warna, kartu angka drill hitung cepat, lembar aktivitas santri.
  2. Sumber Belajar: Buku Guru dan Siswa Matematika Kelas 9 Kurikulum Merdeka, modul aljabar pesantren.

Catatan Refleksi Guru

  1. Efektivitas drill hitung cepat dalam memperlancar pencarian pasangan faktor ac.
  2. Ketelitian santri dalam menangani tanda positif dan negatif saat pemfaktoran kelompok.
  3. Rencana tindak lanjut: Pendampingan intensif bagi santri yang membutuhkan penguatan dasar perkalian.
